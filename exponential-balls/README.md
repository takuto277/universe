# BLOOM（exponential-balls）

音楽に合わせてボールが **1 → 2 → 4 → … → 2,048** と倍々に増える、縦画面のオーディオビジュアル体験です。120 BPM / 4/4。12小節（24秒）で1サイクルし、キーが変わってループします。UIは英語のみです。

## モード

ホーム画面で2つのモードを選べます。

1. **AUTO** — 1小節ごとに自動で分裂。1 → 2,048 を12小節で駆け抜ける、拍に完全に同期したモード。
2. **FRAME** — 上部のフレームにボールが入ると、その場で2個に増える。ボールは360度のどれかの方向へ動き続け、壁で跳ね返る。増え方は毎回変わる。

## 遊び方

1. ホームで **AUTO** か **FRAME** を選び、**BEGIN** を押す。
2. 音が鳴り、1個のボールから始まる。
3. AUTOでは小節ごとに、FRAMEではフレームに入るたびにボールが倍々に増える。
4. 2,048個に達するとサイクルが切り替わり、1個に戻ってキーが変わる。
5. **MODES** でホームに戻り、モードを選び直せる。**SOUND** でミュート。

タップでボールを押す操作はありません。観るための映像体験です。

## 音楽と同期

外部の音源ファイルは使わず、WebAudioでプロシージャルに鳴らしています。

- 120 BPM、16分ステップを先読みしてスケジュール
- キック、ハット、ベース、アルペジオ、パッド、ライザー、インパクト
- 小節が進むほど層が増え、12小節でサイクル
- サイクルごとにキーが変わる（C / E♭ / F / G minor）
- FRAMEの回収音は次の16分に量子化し、現在のキーの2度/3度上で鳴らす
- FRAMEのフレームは拍で脈打ち、回収の瞬間に波紋が広がる

**音ハメの考え方:** AUTOは小節頭の分裂とキックが一致するため、最も強く拍にハマります。FRAMEは「ボールが入る瞬間」が入力になるため、増加そのものは拍に固定できません。代わりに回収音を16分に量子化し、フレームの拍パルスで音楽との接点を作っています。完全な拍同期を優先するならAUTO、映像の偶然性を優先するならFRAMEです。

AI生成の音源を使う場合は、音源ファイルとBPM・拍の開始位置を用意すれば差し替えできます。

## 映像

- AUTO: 1小節ごとに各ボールが2個に分裂
- FRAME: 上部フレームに入ったボールを回収し、2個を放出
- ボールの半径は数が増えるほど小さくなり、画面全体が群れになる
- 加算合成の軌跡、波紋、拍のパルス、サイクル切替のフラッシュ
- 色はキーと小節で変化
- キャンバスは縦画面。PCでは中央の縦パネルとして表示

## 設計の要点

- **AUTOは時間と小節だけ**: ボール数は `2^bar`。1サイクル12小節、24秒。描画と音は状態から決まる。
- **FRAMEは位置と速度**: ボールは常に速度を持ち、フレーム内に入った瞬間に回収される。回収後はフレーム下から2個を放出し、0.4秒の免疫で連鎖回収を防ぐ。
- **映像の時計を基準に音を組む**: ゲームの時刻は `performance.now`。AudioContextが止まっても映像は進み、復帰後は現在の小節から音を再開する。長時間の不在時は欠落ステップを捨て、音が一気に鳴らないようにする。
- **2,048でリセット**: 上限に達すると1個に戻り、キーが変わる。FRAMEでは回収イベントとしてフラッシュと波紋を出す。
- **タップなし**: 入力はモード選択とサウンドのみ。ボールは自律的に動く。

## テスト

```sh
cd exponential-balls
jsc test-engine.js
jsc test-audio.js
jsc test-ui.js
jsc test-renderer.js
jsc test-smoke.js
jsc test-frame-smoke.js
```

リポジトリ全体では `./tools/verify.sh` です。`test-engine.js` はAUTOの小節ごとの1→2,048、サイクル境界、時計の巻き戻り、時間ジャンプ、FRAMEの回収・上限を検証します。`test-audio.js` はダミーのAudioContextでスケジューラの安全（長時間不在・停止/復帰・ミュート）と回収音を確認します。`test-ui.js` はモード選択・MODES・HUDを確認します。`test-renderer.js` は分裂・リセット・FRAME描画を確認します。`test-smoke.js` はAUTOを2サイクル、`test-frame-smoke.js` はFRAMEを自動再生し、HUDとボールの運動を確認します。

## 既知の制限と次に試すこと

- FRAMEの増加は拍に固定されない。回収音の16分量子化とフレームの拍パルスで補っているが、AUTOほどの音ハメはない。
- 一時停止ボタンはない。止める場合はMODESでホームに戻るか、タブを閉じる。
- 2,048個の描画は端末によって負荷がある。必要なら最大数を下げる、軌跡を軽くする、描画を間引く。
- AI生成の音源への差し替え、BPM変更、サイクルごとのテンポ変化は未実装。
- スコアやゲームオーバーはない。観るための映像体験として作っている。
