# BLOOM（exponential-balls）

音楽に合わせてボールが **1 → 2 → 4 → … → 2,048** と倍々に増える縦画面のオーディオビジュアル体験です。120 BPM / 4/4。12小節（24秒）で1サイクルし、キーが変わってループします。UIは英語のみです。

## モード

ホーム画面で3つのモードを選べます。

1. **AUTO** — 1小節ごとに自動で分裂。1 → 2,048 を12小節で駆け抜ける、拍に完全に同期したモード。
2. **FRAME** — 上部のラインにボールが触れると、そのボールが2個に増えてラインと逆の下向き180度のどこかへ飛ぶ。ボールは360度のどれかの方向へ動き続け、壁で跳ね返る。ラインで増えた子ボールだけ、倍になるたびに色が濃くなる。
3. **RACE** — 1球で縦下りの60秒レース。3つのゲートを抜け、ゴーストより先にゴールを目指す。タップ位置で加速・ブレーキ・ステアを操作する。

## 遊び方

1. ホームで **AUTO / FRAME / RACE** のカードを選び、**START** を押す。
2. AUTO/FRAMEでは音が鳴り、1個のボールから始まる。RACEでは1球とゴーストがスタートする。
3. AUTOは小節ごと、FRAMEは上部ラインに触れるたびにボールが倍々に増える。
4. RACEは **玉の後ろをタップ＝加速**、**玉の前をタップ＝ブレーキ**、**玉の横をタップ＝ステア**。拍ジャストのタップは少し強くなる。3つのゲートを抜けて60秒以内にゴールすると結果画面が出る。
5. AUTO/FRAMEは2,048個でサイクルが切り替わり、1個に戻ってキーが変わる。**HOME** でホームに戻り、**SOUND** でミュート。

画面をタップすると、AUTO/FRAMEでは近くのボールを押し返せます。RACEでは自分の球を押し出します。タップ音も鳴ります。

## 音楽と同期

外部の音源ファイルは使わず、WebAudioでプロシージャルに鳴らしています。

- 120 BPM、16分ステップを先読みしてスケジュール
- キック、ハット、ベース、アルペジオ、パッド、ライザー、インパクト
- 小節が進むほど層が増え、12小節でサイクル
- サイクルごとにキーが変わる（C / E♭ / F / G minor）
- FRAMEのライン通過音は次の16分に量子化し、現在のキーの2度/3度上で鳴らす
- RACEのゲート通過音も同じく16分に量子化し、ゴールはインパクトで鳴らす
- FRAMEのラインとRACEのゲートは拍で脈打つ

**音ハメの考え方:** AUTOは小節頭の分裂とキックが一致するため、最も強く拍にハマります。FRAMEは「ラインに触れる瞬間」、RACEは「タップとゲート通過」が入力になるため、増加そのものは拍に固定できません。代わりに通過音を16分に量子化し、拍ジャストのタップに小さなブーストを掛けています。

AI生成の音源を使う場合は、音源ファイルとBPM・拍の開始位置を用意すれば差し替えできます。

## 映像

- AUTO: 1小節ごとに各ボールが2個に分裂
- FRAME: 上部ラインに触れたボールを2個に分け、下向き180度へ放出
- RACE: 縦下りのトラック、3つのゲート、ゴースト、チェッカーのフィニッシュライン
- ボールの半径は数が増えるほど小さくなり、画面全体が群れになる
- FRAMEでラインを通過して生まれたボールは、倍になるたびに色が濃くなる
- 加算合成の軌跡、波紋、拍のパルス、サイクル切替のフラッシュ
- 色はキーと小節で変化
- キャンバスは縦画面。PCでは中央の縦パネルとして表示

## 設計の要点

- **AUTOは時間と小節だけ**: ボール数は `2^bar`。1サイクル12小節、24秒。描画と音は状態から決まる。
- **FRAMEはラインと速度**: ボールは常に速度を持つ。上部ラインを通過した瞬間に2個へ増え、ラインと逆の下向き180度のどこかへ飛ぶ。0.35秒の免疫で連鎖通過を防ぎ、子ボールは親より色が濃くなる。
- **RACEは押し出しとゲート**: 1球が重力で下り、タップ位置の反対方向へ押される。前タップでブレーキ、後ろタップで加速、横タップでステア。3つのゲートは幅110の隙間を通る必要があり、外すと上に弾かれる。ゴーストはゲートの隙間をなぞるペースランナー。
- **映像の時計を基準に音を組む**: ゲームの時刻は `performance.now`。AudioContextが止まっても映像は進み、復帰後は現在の小節から音を再開する。長時間の不在時は欠落ステップを捨て、音が一気に鳴らないようにする。
- **2,048でリセット**: AUTO/FRAMEの上限。FRAMEではライン通過イベントとしてフラッシュと波紋を出す。RACEは60秒またはゴールで結果画面に移る。
- **タップ**: AUTO/FRAMEは群れの押し返し、RACEは自分の球の加速・ブレーキ・ステア。タップ音は現在のキーで鳴る。

## テスト

```sh
cd exponential-balls
jsc test-engine.js
jsc test-audio.js
jsc test-ui.js
jsc test-renderer.js
jsc test-smoke.js
jsc test-frame-smoke.js
```

リポジトリ全体では `./tools/verify.sh` です。`test-engine.js` はAUTOの1→2,048、FRAMEのライン通過、RACEのタップ・ゲート・ゴースト・結果を検証します。`test-audio.js` はスケジューラの安全とタップ/通過音を確認します。`test-ui.js` は3モード選択・START・HOME・RACE結果を確認します。`test-renderer.js` はFRAME/RACE描画を確認します。`test-smoke.js` はAUTOを2サイクル、`test-frame-smoke.js` はFRAME、`test-race-smoke.js` はRACEを自動再生します。

## 既知の制限と次に試すこと

- RACEはMVP。1コース・3ゲート・ゴースト1で、ライン倍々やコース分岐はまだない。
- RACEのゴーストは記録再生ではなく、ゲートの隙間をなぞるスクリプト。ベスト走行のゴースト化は次に試す。
- FRAMEの増加は拍に固定されない。ライン通過音の16分量子化とラインの拍パルスで補っているが、AUTOほどの音ハメはない。
- 一時停止ボタンはない。止める場合はHOMEでホームに戻るか、タブを閉じる。
- 2,048個の描画は端末によって負荷がある。必要なら最大数を下げる、軌跡を軽くする、描画を間引く。
- AI生成の音源への差し替え、BPM変更、サイクルごとのテンポ変化は未実装。
- AUTO/FRAMEはスコアなし。RACEはタイムと勝敗のみで、スコアや周回はまだない。
