# 倍々

音楽の小節に合わせて、ボールが **1 → 2 → 4 → … → 2,048** と倍々に増える、縦画面のオーディオビジュアル体験です。120 BPM / 4/4。12小節（24秒）で1サイクルし、キーが変わってループします。

## 遊び方

1. **はじめる** — 音が鳴り、1個のボールから始まります。
2. **観る** — 1小節ごとにボールが分裂して倍々に増え、音楽もキック → ハット → ベース → アルペジオ → パッド → ライザーと層が増えます。
3. **タップする** — 画面をタップすると、その場所からボールを押し返せます。タップ音も鳴ります。
4. **12小節** — 2,048個まで増えると、サイクルが切り替わって1個に戻り、キーが変わります。
5. **音** — 右上の「音 ON/OFF」でミュートできます。スタート画面でも切り替えられます。

## 音楽

外部の音源ファイルは使わず、WebAudioでプロシージャルに鳴らしています。

- 120 BPM、16分ステップを先読みしてスケジュール
- キック、ハット、ベース、アルペジオ、パッド、ライザー、インパクト
- 小節が進むほど層が増え、12小節でサイクル
- サイクルごとにキーが変わる（C / E♭ / F / G minor）
- タップ音は現在のキーの2度/3度上

AI生成の音源を使いたい場合は、音源ファイルとBPM・拍の開始位置を用意すれば、差し替え/同期のモードを追加できます。

## 映像

- 1小節ごとに各ボールが2個に分裂
- ボールの半径は数が増えるほど小さくなり、画面全体が群れになる
- 加算合成の軌跡、中央の波紋、拍のパルス、サイクル切替のフラッシュ
- 色はキーと小節で変化
- キャンバスは縦画面。PCでは中央の縦パネルとして表示

## ファイル構成

```text
exponential-balls/
├── index.html      # 縦画面の骨格・スタート画面
├── style.css       # HUD・スタート画面・縦パネル
├── engine.js       # BPM、小節、倍々スケジュール、タップ
├── audio.js        # WebAudioのプロシージャル音楽
├── renderer.js     # Canvasのボール分裂・軌跡・波紋
├── ui.js           # HUD、サウンド、タップ入力
├── game.js         # 起動・描画ループ・window.__GAME__
├── test-engine.js   # 時間・小節・倍々スケジュール
├── test-audio.js    # WebAudioスケジューラの安全確認
├── test-renderer.js # 分裂・リセット・タップの描画状態
└── test-smoke.js    # 2サイクルの自動再生
```

## 設計の要点

- **エンジンは時間と小節だけ**: ボール数は `2^bar`。1サイクル12小節、24秒。描画と音は状態から決まる。
- **映像の時計を基準に音を組む**: ゲームの時刻は `performance.now`。AudioContextが止まっても映像は進み、復帰後は現在の小節から音を再開する。長時間の不在時は欠落ステップを捨て、音が一気に鳴らないようにする。
- **分裂は小節の頭**: エンジンが小節の変わり目を検出し、レンダラーが各ボールを2個に分ける。音楽のキックと同じタイミング。
- **2,048でリセット**: 最後の小節でピークを迎え、次のサイクルで1個に戻る。キーが変わり、色も変わる。
- **タップは環境に干渉する**: 画面を押すとボールが押し返され、タップ音が鳴る。観るだけでも、触っても成立する。

## テスト

```sh
cd exponential-balls
jsc test-engine.js
jsc test-audio.js
jsc test-renderer.js
jsc test-smoke.js
```

リポジトリ全体では `./tools/verify.sh` です。`test-engine.js` は小節ごとの 1→2,048、サイクル境界、タップ、時計の巻き戻り、時間ジャンプを検証します。`test-audio.js` はダミーのAudioContextでスケジューラの安全（長時間不在・停止/復帰・ミュート）を確認します。`test-renderer.js` は分裂・リセット・タップ後のボール数を確認します。`test-smoke.js` は2サイクルを自動再生し、最大2,048個・HUD・スタート画面の非表示を確認します。

## 既知の制限と次に試すこと

- 一時停止・停止ボタンはない。止める場合はタブを閉じるか再読み込み。
- 2,048個の描画は端末によって負荷がある。必要なら最大数を下げる、軌跡を軽くする、描画を間引く。
- AI生成の音源への差し替え、BPM変更、サイクルごとのテンポ変化は未実装。
- スコアやゲームオーバーはない。観る/触るための映像体験として作っている。
- 音の出ない環境、自動再生制限、実機のスピーカーでの音量バランスは今後調整したい。
