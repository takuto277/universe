# projects/

このディレクトリは、ゲームと検証用プロジェクトを **保守・利用の目的** で分類して置く場所です。リポジトリ全体の役割は [ADR 0010](../docs/decisions/0010-monorepo-role.md) を参照してください。

## 分類

| パス | 用途 | 判断基準 |
| --- | --- | --- |
| `projects/<name>/` | 継続保守・公開対象 | デプロイする、または通常の開発対象として維持する |
| `projects/_labs/<name>/` | 実験・検証・試作 | 今後も発展させる、または再利用する可能性がある |
| `projects/_samples/<name>/` | サンプル・教材・テンプレート | 最小実装、教材、CI/CD の検証用 |

`main` 相当のプロジェクトにはカテゴリ用の中間ディレクトリを作りません。迷った場合は「公開・継続保守か」「発展・再利用の見込みがあるか」「教材・検証が主目的か」の順で判断します。

## 移行メモ

- ゲームはすべて `projects/` 配下に移動済みです。旧URLはルートのリダイレクトで維持しています。
- `tools/` は稼働中の無人開発基盤としてルートに残しています。LaunchAgent と既存パスへの影響を避けるため、必要になった段階で互換ラッパーと一緒に移行します。
