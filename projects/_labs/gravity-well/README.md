# GRAVITY WELL / 盤面回転テトリス

12×12 の正方形ウェルを使った、120 秒のスコアアタック型テトリスです。
最大の特徴は **操作中テトロミノを直接回転できない** こと。代わりに盤面全体を 90° 回すと、積み上がったブロックと操作中ピースが一緒に回り、そのあと重力で浮いたセルが落ちて整地されます。

## 遊び方

- START で開始。120 秒経過するか、積み上がりが天井に達すると終了。
- 左右移動・ソフトドロップ・ハードドロップでピースを落とす。
- Q / E（または画面下の ⟲ / ⟳）で盤面を反時計回り / 時計回りに回転。
- 回転は 1 回 +10 点。回転中は約 160ms のアニメーションがあり、その間は入力できません。
- ラインは「固定直後」と「盤面回転後の整地後」に消えます。
- 連続してラインを消すとコンボボーナスが付きます。

### キーボード

| キー | 動作 |
| --- | --- |
| ← / →（A / D） | 左右移動 |
| ↓（S） | ソフトドロップ |
| Space | ハードドロップ |
| Q | 盤面を反時計回りに回転 |
| E | 盤面を時計回りに回転 |
| Enter / Space（開始・終了画面） | 開始・リトライ |

### タッチ

画面下のボタンで移動・ソフトドロップ・ハードドロップ・盤面回転ができます。

## ルールとスコア

- 7-bag ランダムライザー。7 種類のピースが 1 セットずつ出現します。
- ライン消去点: 1 ライン 100 / 2 ライン 300 / 3 ライン 500 / 4 ライン 800。
- コンボ: 連続でラインを消すたびに `(コンボ数 - 1) × 50` 点を加算。消せなかった固定でコンボはリセット。
- 盤面回転 1 回につき +10 点。
- 自己ベストは `localStorage` の `gravitywell-best` に保存します。

## 設計メモ

- `engine.js` は描画や DOM に依存しません。`createGame()` が返すゲームオブジェクトの `update(dt)`、`moveLeft()`、`rotateBoard(dir)` などを通じて状態を進めます。
- 盤面回転は「スタックと操作中ピースを同じ変換で回す → ピースを障害物としてスタックを下詰め → ピースを落下」の順で処理します。これにより回転前後で重なりが起きません。
- `getState()` は `grid` / `active` / `queue` / `score` / `lines` / `phase` / `timeLeft` / `rotation` などを返します。描画側はこのスナップショットだけを見ます。
- 回転アニメーションはエンジン側では入力ロック用のタイマーとして持ち、描画側は進行度に応じて盤面を逆回転させて旧姿勢から新姿勢へ見せるだけにしています。
- `window.__GAME__` の `autoPlayStep()` は入力だけを行い、`update()` は呼びません。AI は現在の盤面とピースから各列への着地をシミュレーションし、必要なら盤面回転も比較します。ピースごとの回転回数に上限を設けて必ず終了するようにしています。
- `localStorage` と `AudioContext` は存在チェック付きで扱い、`jsc` のハーネスでも安全に動くようにしています。

## テスト

```sh
cd projects/_labs/gravity-well

# ロジック
/System/Library/Frameworks/JavaScriptCore.framework/Versions/A/Helpers/jsc test-engine.js

# スモーク（AIで1プレイ）
/System/Library/Frameworks/JavaScriptCore.framework/Versions/A/Helpers/jsc test-smoke.js
```

`test-engine.js` はシード固定の 7-bag、移動、回転と入力ロック、整地、ライン消去、コンボ、時間切れ、トップアウト、リスタートを確認します。
`test-smoke.js` は `tools/harness.js` 上で `game.js` を起動し、AI が制限ステップ内にゲームを終了させること、スコアとエンド画面が一致すること、`console.error` が出ないことを確認します。

## 既知の制限

- 回転アニメーション中は重力も止まります。テンポを優先した仕様です。
- 盤面回転後の整地はスタックのみを対象にし、操作中ピースは障害物として扱います。
- サムネイルや `apps.json` はこのアプリ単体の変更では更新していません（共有ファイルを触らない指示のため）。
