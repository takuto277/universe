# グラフクロス

x が自動で進むグラフの上で、関数を切り替えながら自分の曲線を描き、右から流れてくる敵の曲線と交差させて大爆発を起こす 2D アクションです。13 種類の関数から 3 つを選んでデッキを組み、2つの関数を合成したカスタムカードも作れます、`x^p + bx` (p=2〜6) と波の形(sin / cos / 三角 / 角丸 / 減衰 / のこぎり / 矩形 / スパイク)をスライダーで自分好みに調整できます。通常のステージモードに加えて、ライフ無限・敵大量の **ストレス解消モード**、3ステップ・図解付きで操作を学べる **チュートリアル**、関数を集める **ローカル関数ガチャ** があります。交差角度が急なほど高得点で、敵と同じ系統(直線/累乗/波)で交差すると弱点ボーナス。一定数交差するとボスが出現し、倒すとステージクリアです。コンボが伸びると BGM の音が重なって速くなります。曲線は「攻撃範囲」でもあり、自分が描いたグネグネした形がそのまま罠になります。依存ゼロの静的ファイルで動きます。

## 遊ぶ

universe のルートで次を実行し、http://localhost:8000/projects/_labs/graph-cross/ を開きます。

```sh
python3 -m http.server 8000
```

## 関数ガチャ

- 開始画面の「関数ガチャ」から、関数ポイントを使って関数を解放
- スターターは `y=0 / x/2 / -x/2 / x²`。最初から4種が使え、デッキは3枠
- ステージクリアごとに **関数ポイント +100**
- 1回100pt。スターター分は排出対象外で、未所持のレアリティだけで重みを再計算（初期は UNCOMMON 66.7% / RARE 26.7% / EPIC 6.7%）
- レア+天井10回、EPIC天井20回
- 全解放までは未所持の関数だけを排出（重複なし）
- 所持関数・ポイント・天井・直近の結果は `localStorage` に保存（DBなし）
- ガチャで解放した関数だけがデッキ・ステージクリアの入れ替え候補・スロット追加候補に出る
- 合成カードは素材の関数が解放済みのときだけ作れる

## チュートリアル

- 開始画面の「はじめての遊び方」から開始。未クリアの間は金色で強調される
- 関数切替 → 敵との交差 → アイテム取得 の3ステップを、インラインSVGの図解と実操作で学ぶ
- 押す関数ボタンは赤枠と「ここを押す」ラベルで強調される
- チュートリアル用の敵はその場に留まり、当たるまで同じ敵が表示される
- チュートリアル用のアイテムは、拾うまで繰り返し出現する
- チュートリアル中はライフ∞・ボスなし。スコアはベストに保存されない
- スキップ／`Esc`／「やめる」で開始画面に戻れる
- 完了後は「このデッキではじめる」で通常ゲームへ。完了状態は `localStorage` に保存される

## ルール

- x が自動で増え、プレイヤーの曲線が左から右へ伸びていく
- 開始前に解放済みの関数から **3 つを選んでデッキ**を組む。関数は **上昇 / 下降 / その他** のジャンルに分かれる
- デッキ画面の「関数合成」で2つの関数を選ぶと、`y = x² + sin(x)` のような **合成カード** を作れる。合成カードは1枠としてデッキに入り、入れ替えの対象外
- ステージクリア時の入れ替えは **同じジャンル内の3択** から選ぶ。上昇関数が全部消えて詰む、を防ぐ
- 固定関数として `y = e^x - 1` / `y = ln(x+1)` / `y = sigmoid(x)` / `y = e^{-x²}` / `y = -1 + e^{-x}` も追加
- 開始画面の「関数をつくる」で `y = a x^p + b x` (p=2〜6) / `y = -a x^p + b x` / `y = a·wave(bx + c)` の係数をスライダーで調整できる
- 調整できるのは解放済みの対象関数（quad / quadDown / wave）。デッキに入れていなくても調整でき、後からデッキに追加できる
- 関数合成の下に合成後の軌道プレビューを表示する
- 波は **sin / cos / 三角波 / 角丸スクエア / 減衰サイン / のこぎり波 / 矩形波 / スパイク** から選べる。形を変えると軌道プレビューと説明もリアルタイムに変わる
- 通常の敵を一定数交差すると **ボス** が出現。ボスを倒すと **ステージクリア** で、次のステージへ進む
  - `y = 0`: その場をキープ
  - `y = x/2` / `y = -x/2`: 一定の速さで上下へ
  - `y = 2x` / `y = -2x`: 速い上下移動
  - `y = x²` / `y = -x²`: 上下に加速するカーブ
  - `y = sin x`: 上下に揺れるウェーブ
- `1`〜`3`(または下のボタン / 画面タップ)でデッキの関数を切り替え、これから描く曲線の形を変える
- 画面右上の `PAUSE` または `P` で一時停止。`P` / `Esc` / 「再開」で再開できる。ポーズ中は BGM も止まる
- ゲームオーバー時は `R` または「ステージをやり直す」で、ステージ開始時点へ戻る（スコア・ライフ・デッキ・強化を復元）
- 右から流れてくる敵の曲線と自分の曲線が交差すると、大爆発・得点・コンボ
- **0.55秒以内に連続で交差すると MULTI** が発生し、最大5連鎖まで得点倍率アップ
- フィールドにはアイテムが流れてくる。曲線で拾うと **G: 非対称グラフを追加 / +: ライフ回復 / S: スコア**
- 追加された非対称グラフは画面をまたぐ一時的な罠として、上下に揺れながら敵を迎撃する
- **交差角度が急なほどボーナス倍率アップ**(最大 1.8 倍)。真横から斬り込むと大きなエフェクトになる
- 敵の曲線には系統がある: 直線(青) / 累乗(金) / 波(ピンク)。**プレイヤーの曲線の色と敵の色が同じ**ときに交差すると弱点ボーナス **1.5 倍**
- 曲線は描いた時点の関数の色で残る。ウェーブを置いてから別の関数に切り替えても、その区間は波として弱点を突ける
- 通常の敵を交差させずに画面左へ逃がすとライフ -1。ライフ 0 でゲームオーバー。終了画面の「ステージをやり直す」または `R` で、そのステージ開始時点のスコア・ライフ・デッキ・強化から再開できる
- ボスは一定時間ごとに弱点の系統を変える。ボスを逃がすとライフ -1 で、少し後に再出現する
- ステージクリアで **軌道プレビュー付きの同じジャンル関数3択** から1つ選び、デッキ1枠を入れ替える。その後に **強化を3択から1つ選択**。次のステージは敵の目標数とボスHPが増える
- 強化は「最大ライフ+1」「判定+2」「コンボ猶予+0.8秒」「スコア+20%」「ボスHP-3」「関数スロット+1」「プリズムクロス（撃破時に縦ビーム）」「アイテム磁石」「リバイブ」「コンボガード」「ボスブレイカー」など
- 5 コンボごとにライフが 1 回復(最大 3)
- コンボは 2.6 秒以内に次の交差を決めると継続。得点は `(100 + (コンボ-1) × 50) × 角度ボーナス × 弱点ボーナス`
- コンボが伸びると BGM にハモリ・高音・カウンターが重なり、テンポも少し上がる。ミスでコンボが切れると元に戻る
- 音は画面下の「音 ON / OFF」でミュートできる。設定は保存される

## ステージとボス

- 通常フェーズの目標は `6 + ステージ × 2` 体。目標を満たすと通常敵の生成を止めてボスを出す
- ボスHPは `7 + ステージ × 3`。交差の角度と弱点で1回のダメージが1〜3変わる
- ボスの弱点は直線→累乗→波の順に、2回ダメージを与えるたびに切り替わる
- **STAGE 10 が最終ステージ**。通常より強い最終ボスを倒すとエンディングになり、`PLAY AGAIN` / `TITLE` を選べる
- ステージクリアで `1000 × ステージ` のボーナス。デッキと係数は持ち越す

## ストレス解消モード

- 開始画面の「ストレス解消モード」から開始。ライフは **∞**、ミスしても減らない
- 敵が通常より高密度で出現し、ボス・ステージクリア・強制入れ替えはない
- スコア・コンボ・MULTI・アイテム・追加グラフはそのまま使える
- 「やめる」ボタンまたは `Esc` で開始画面に戻る

## ステージ間アップグレードとデッキ変動

- ステージクリア時に、デッキの1枠が **同じジャンルの別の関数** に強制的に入れ替わる。上昇なら上昇、下降なら下降、その他ならその他の関数が選ばれる
- クリア画面に「DECK CHANGE」として交換先3択が表示され、各候補の軌道プレビューを見ながら同じジャンルから選ぶ
- 入れ替え対象のスロット番号を表示し、画面下の該当スロットを金色で強調。選択後は緑色で表示する
- 選択後に「デッキ変動 [上昇]: y=... → y=...」が表示され、下のスロットも新しいデッキになる
- 入れ替え後に強化3択から1つ選び、次のステージへ進む
- ライフは最大5まで、判定は+6、コンボ猶予は+2.0秒、スコア倍率は2.0倍、ボスHP軽減は-12まで重ねられる
- **プリズムクロス**を取ると、敵を倒した位置に縦ビームが落ちる。ビームは縦線上の通常敵をまとめて撃ち抜くが、ビームで倒した敵はビームを発動しない（連鎖なし）。クールダウン0.65秒
- **アイテム磁石**を取ると、曲線から240px以内のアイテムが曲線へ吸い寄せられる
- **リバイブ**を取ると、1ラン1回だけライフ0から1で復活する
- **コンボガード**を取ると、1ステージ1回だけミスしてもコンボが切れない（ライフは減る）
- **ボスブレイカー**を取ると、ボスへの1回のダメージが+1される
- 「関数スロット+1」を選ぶと、デッキ外の関数からランダム3択が表示され、選んだ関数を4枠目に追加できる。4枠目はキー`4`でも切り替えられる
- 強化はそのラン限り。ゲームオーバー時は「このステージからやり直す」でステージ開始時点に戻れる。ステージクリア画面に「このランの強化」が表示される
- 交換先3択は、同じジャンルに3候補以上ある枠を優先する。候補が少ない場合は表示できる候補だけになる
- プレビューは `modePreview` で関数の軌道オフセットをサンプリングし、カード内のSVGとして描画する

## 難易度調整

- スクロール速度は開始 220px/s から、時間経過＋ステージ進行で最大 380px/s まで上がる
- ステージが1つ進むごとに速度+8px/s（最大+32）、敵の生成/振幅に効く難易度+0.035（最大+0.28）。ステージ1は従来と同じ
- ステージごとの目標数+2、ボスHP+3は従来どおり。時間とステージの両方で少しずつ圧が上がる
- 敵の生成間隔は約 1.5 秒から約 0.8 秒へ短くなる
- 難易度は `time / RAMP_TIME + (stage - 1) * 0.035` を 0〜1 にクランプして使う。速度だけは時間ランプにステージ補正を足す
- 敵の曲線は `sin` / `x²` / 直線`x/2` の 3 種類で、振幅と長さをランダムに変える。系統ごとに色と弱点が決まっている
- 開始直後に 3 本の敵曲線を画面内へ置き、最初の数秒から交差チャンスがあるようにしている
- ライフの回復条件を「5コンボ」にすることで、逃げ切るより攻める方が得になる
- ボスは通常敵より遅い速度で流れ、画面外に出るとライフを失って再出現する。時間切れではなく「倒すまで続く」区切りにしている

## 設計メモ

- プレイヤーの曲線は「画面座標の点列」として持つ。毎フレーム点を左へスクロールさせ、ヘッド位置に新しい点を足すので、描いた形がそのまま残って敵を迎え撃つ
- 交差判定は「曲線の点列」と「敵の曲線のサンプル点」を同じ x で比べる。どちらも y = f(x) の形なので、線分交差より単純で安定する
- 敵が画面左へ抜けたときだけミスにする。ヘッドより後ろの曲線にも当たり判定があるため、後ろに罠を張る戦略が成立する
- 関数は速度・加速度として曲線に反映する。`x²` は加速度、`sin x` は上下する速度、`x/2` は一定速度
- デッキは 3 枠に制限し、`setMode` をデッキ内の関数だけに制限する。13 種類から 3 つを選ぶことで、上下の移動力・カーブ・ウェーブ・指数/対数/S字/山/減速下降のどれを取るかがプレイスタイルになる
- 係数は `PARAM_SPECS` で範囲と刻みを定義し、`normalizeParams` でクランプ・スナップする。UI とエンジンで同じ仕様を使う
- 弱点は曲線の点ごとに保存した「描いた時のモード」から判定する。現在のモードではなく、その区間を描いた関数で判定するのがポイント
- BGM は AudioContext の時計で先読みスケジュールする。コンボ強度は音のレイヤーと1ステップの長さに反映する
- 係数プレビューは実際のゲームと同じ式で1.6秒分をシミュレーションし、画面端に届くかも判定する
- 累乗は速度(微分)を積分して軌道にする。波は形を直接 y に反映し、モード切替時に基準の高さをずらして軌道が飛ばないようにしている
- スマホは viewport の拡大を無効化し、`touch-action` とスライダーUIで入力時のズームを防いでいる
- ステージクリアはエンジン側で `stageCleared` を立てて更新を止め、ゲーム側が900ms後にクリア画面を出す。次のステージは `nextStage` でスコアとライフを保持したままステージ固有の状態だけをリセットする
- ステージ開始時点のスコア・ライフ・デッキ・強化・難易度を `makeCheckpoint` で保存し、ゲームオーバー時は `restoreCheckpoint` でその時点から再開する
- 強化は `applyUpgrade` で状態に反映する。ライフ・判定・コンボ猶予・スコア倍率・ボスHP・デッキ枠・プリズムクロス・アイテム磁石・リバイブ・コンボガード・ボスブレイカーを個別に持ち、クリア画面の3択は `upgradeChoices` が重複なしで生成する
- スロット追加は `slotChoices` がデッキ外の関数から3択を生成し、選んだ関数を `applyUpgrade(state, 'slot', key)` で追加する
- アイテム磁石は `pullItems` が最寄りの曲線点へアイテムを移動させる。リバイブは `tryRevive`、コンボガードは `guardUsed`、ボスブレイカーはボスダメージ計算で扱う
- プリズムクロスは通常敵撃破時に `fireBeam` を呼び、ビーム上の敵を直接削除する。ビーム撃破は `checkHits` を通さないので連鎖せず、`beamCooldown` で発動間隔を制限する
- 関数のジャンルは `content.js` の `genre` で定義し、`deckSwapPlan` はジャンルごとの候補が存在する枠だけを選ぶ。合成カードは入れ替え対象から除外する
- ステージクリア時は `makeDeckSwapOffer` が同じジャンルの候補を3つ提示し、`applyDeckSwap` で選んだ関数を反映する。候補が3つ未満のジャンルは、候補が3つ以上あるジャンルを優先する
- 合成カードは2つの元関数の軌道オフセットを足し合わせる。元関数がデッキ外でも、係数パラメータを `deckParams` に追加して同じ式で評価する
- デッキ変動は選んだ関数を1枠に入れ、新しい関数の係数は既定値で追加する。クリア画面に選択前の関数と選択後の関数を表示し、次ステージのスロットに反映する
- 交差角度は、プレイヤー曲線の接線と敵曲線の接線から `atan(|(m1-m2)/(1+m1*m2)|)` で求める。90 度に近いほど得点倍率が上がる
- テストでは、何もしないプレイが数秒〜十数秒で終わり、敵の高さに合わせて動くプレイが 40 秒生存できることを確認している
- チュートリアルは通常ステージと同じエンジンを使い、`hp` を大きくしてボスを止めた練習状態にする。ステップ進行はゲーム側でイベント（関数切替・`hit`・`itemPickup`）を監視し、`ui.showTutorialStep` で表示を更新する
- チュートリアル用の的はプレイヤーの高さに追従させ、関数切替後でも交差を体験できるようにしている
- ガチャは `gacha.js` に純粋ロジックを分離し、UIは保存と表示だけを担当する。抽選は `crypto.getRandomValues`、失敗時は `Math.random` にフォールバックする
- 未解放関数は `createGame({ unlocked })` で除外し、デッキ・スロット追加・クリア時の入れ替え候補に混ざらないようにしている

## 既知の制限
