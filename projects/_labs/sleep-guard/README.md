# ねむりのまもり

眠りたいキャラクターを、部屋の騒音から守るタップ防衛ゲームです。

## 遊び方

- 部屋に現れる騒音オブジェクトをタップ / クリックして静める
- 静かな時間が続くと睡眠ゲージが増える
- 騒音を放置するとゲージが減る
- ゲージがMAXならクリア、0なら「眠れ無ーーい！」でゲームオーバー
- ゲージは1/3（33%）からスタート

## 騒音

目覚まし時計、スマホの通知、テレビ、ドアの物音、掃除機、朝の鳥。種類によってゲージの減り方が変わります。時間が経つほど出現間隔が短くなります。

## 構成

| ファイル | 役割 |
| --- | --- |
| `assets/` | 背景・キャラクター・騒音2フレーム素材 |
| `audio.js` | Web Audio のBGM・効果音 |
| `engine.js` | 睡眠ゲージ、騒音生成、タップ判定、クリア/ゲームオーバー |
| `game.js` | Canvas 2D 描画、入力、HUD、`window.__GAME__` |
| `index.html` | 画面の骨格・説明・リザルト |
| `style.css` | HUD、ゲージ、画面レイアウト |
| `test-engine.js` | ゲージ・騒音・タップ・終了条件のテスト |
| `test-smoke.js` | 自動プレイでクリアまで確認 |

## テスト

universe のルートで:

```sh
./tools/run-tests.sh
```

個別:

```sh
cd projects/_labs/sleep-guard
jsc test-engine.js
jsc test-smoke.js
```

## 音と画像

- BGMはBPM72の静かなループ。開始時に再生し、終了時に停止
- 騒音出現・タップ・クリア・ゲームオーバーに効果音
- 右下の「音 ON/OFF」で切り替え、設定はlocalStorageに保存
- 背景・キャラクター・騒音アイコンは `assets/` の画像を使用
- 騒音アイコンは2フレームのスプライトシートをループ再生
- 画像が読み込めない場合はCanvasのベクター描画にフォールバック

## 設計メモ

- 睡眠ゲージは静かなときに増え、騒音の数と種類に応じて減る
- タップすると騒音が消え、ゲージが少し回復する
- 騒音は出現から2秒後に鳴り始める。最大6つまで重複し、時間経過で出現間隔が短くなる
- ゲージ開始値33%は「まだ眠りの入り口」を表す
