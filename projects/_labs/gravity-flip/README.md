# 重力フリップ

タップ / Space だけで遊べる 1 ボタンの 2D アクションです。重力を上下に反転させて床と天井を行き来し、迫ってくるトゲを避けながら距離とコインを稼ぎます。進むほど速度とトゲの頻度が上がりますが、トゲの間隔は反転にかかる時間から逆算して確保しています。依存ゼロの静的ファイルで動きます。

## 遊ぶ

universe のルートで次を実行し、http://localhost:8000/projects/_labs/gravity-flip/ を開きます。

```sh
python3 -m http.server 8000
```

## ルール

- プレイヤーは画面左寄りに固定。床か天井に張り付いて前へ進む
- タップ / `Space` / `Enter` / `↑` / `W` で重力が上下反転し、逆側の面へ移動する
- トゲに当たると即ゲームオーバー
- コインは 1 枚 +10 点。距離 10px ごとに +1 点
- 進むほど移動速度が上がり、トゲの間隔も詰まる
- 自己ベストはブラウザの `localStorage` に保存される。更新時はゲームオーバー画面に `NEW BEST!` が出る

## 難易度調整

- 速度は `距離 × 0.010` で上がり、`600px/s` で上限
- トゲの間隔は「速度 × 秒」で決め、秒数の方を緩やかに短くしている。反転の移動時間(約 0.45 秒)より十分長い時間を残す
- 連続するトゲは床→天井のように交互に置き、同じ位置に両面のトゲが重ならないようにしている
- 開始直後に導入用の「床トゲ→天井コイン→天井トゲ」を置き、最初の数秒が退屈にならないようにしている
- `test-engine.js` の自動プレイで「上手い操作なら 60 秒生存できる」「何もしないと数秒で終わる」ことを検証している

## 構成

| ファイル | 役割 |
| --- | --- |
| `engine.js` | 物理・反転・トゲ/コイン生成・衝突・スコア。描画に依存しない |
| `game.js` | Canvas 2D 描画、入力、HUD、パーティクル、`window.__GAME__` |
| `index.html` | 画面の骨格とルール説明 |
| `style.css` | レイアウトと見た目 |
| `test-engine.js` | ルール・生成間隔・バランス(自動プレイ)のテスト |
| `test-smoke.js` | 1 回プレイして終了画面まで到達するスモークテスト |

## テスト

universe のルートで実行します。

```sh
./tools/run-tests.sh
```

個別に実行する場合:

```sh
cd projects/_labs/gravity-flip
jsc test-engine.js
jsc test-smoke.js
```

`jsc` が PATH にない場合は、macOS 標準の `/System/Library/Frameworks/JavaScriptCore.framework/Versions/A/Helpers/jsc` を使うか、`JSC` 環境変数で指定してください。

## 設計メモ

- `engine.js` は固定タイムステップを前提にせず、渡された `dt` を 0〜50ms に丸めて進める。描画側は `requestAnimationFrame` の実時間差を渡す
- 乱数は引数で差し替えられる。テストでは `mulberry32` の固定シードで生成パターンを再現する
- トゲは三角形の内側だけを当たり判定にし、見た目より少し甘くしている
- コインはトゲと重ならない位置にだけ出す。取り逃しても進行には影響しない
- 3D ではないので、当たり判定・速度・間隔の調整は数値シミュレーションで完結する

## 既知の制限

- 効果音はない
- 画面サイズが極端に横長/縦長だと、移動距離の見え方が変わる
- 保存はブラウザごと。シークレットモードでは消える
