# BLOCK CRAFT（block-craft）

Three.jsのWebGLで描く、マインクラフト風の3Dボクセルサンドボックスです。夜明けの島を歩き、ブロックを掘って集め、好きな場所に積んで建築できます。決まったゴールはなく、島を自由に探索・改造できます。

## 遊ぶ

universe のルートで `python3 -m http.server 8000` を実行し、http://localhost:8000/projects/_labs/block-craft/ を開きます。

## 操作

### キーボード・マウス
- **WASD**: 移動
- **Space**: ジャンプ
- **画面ドラッグ**: 視点
- **左クリック**: ブロックを掘る
- **右クリック**: ブロックを置く
- **1〜5**: 草・土・石・木・葉を選択
- **R**: ワールドを再生成
- **? / H**: 操作ヘルプ
- **Esc**: ヘルプを閉じる

### タッチ
- **左スティック**: 移動
- **画面ドラッグ**: 視点
- **JUMP**: ジャンプ
- **掘る**: ブロックを壊す
- **置く**: 選択中のブロックを置く
- **ホットバー**: ブロック選択

## ルール

- 島のブロックは自由に掘れます
- 5種類のブロックを好きなだけ設置できます
- 地形を掘り抜いて奈落に落ちたときは、島のスポーン地点へ戻ります
- 水や敵はいません。建築と探索を楽しむクリエイティブモードです

## 見た目

- Three.js WebGLの一人称3D
- 草・土・石・木・葉・砂の色分けされたボクセル
- 草ブロックは上面・側面・底面で色が変化
- 地形の起伏、木、花、石畳の道、砂浜、周囲の海、空、雲
- ブロックを狙う白いアウトライン
- ホットバーと選択中ブロックの色表示

## ファイル構成

```text
block-craft/
├── index.html      # HUD・ホットバー・タッチ操作・タイトル
├── styles.css      # 縦画面レイアウト、タッチUI、ブロック選択
├── engine.js       # ワールド生成、一人称移動、当たり判定、レイキャスト、掘削/設置
├── game.js         # Three.js描画、一人称カメラ、入力、HUD
├── vendor/         # Three.js 0.160.0（vendored）
├── test-engine.js
└── test-smoke.js
```

## 設計の要点

- **ワールド**: 30×18×30のボクセル。シードから高さ・木・砂浜を生成
- **移動**: AABBとボクセルの軸別衝突、1ブロックのオートステップ、重力、ジャンプ
- **操作**: 視線方向のDDAレイキャストで対象ブロックを取得。掘削時は空気に、設置時は面の法線側へ配置
- **描画**: ブロック種別ごとのInstancedMesh。上面・側面・底面を頂点色で塗り分け
- **編集**: 変更イベントでインスタンスを再構築。小さなワールドなので即時反映できる
- **3D**: Three.js 0.160.0をvendoredし、外部CDNに実行時依存しない

## テスト

universe のルートで:

```sh
./tools/run-tests.sh
```

個別に:

```sh
cd projects/_labs/block-craft
jsc test-engine.js
jsc test-smoke.js
```

## 既知の制限

- クリエイティブサンドボックスで、終了条件・敵・体力・水泳はない
- ワールドは30×18×30の固定サイズ
- ブロックのテクスチャ画像は使わず、面ごとの色で表現
- セーブ機能はない。再読み込みで初期ワールドに戻る
- CPU/マルチプレイはない
