夜明けの島で、掘って、積んで、好きなものを作ろう。

  • WASD / 左スティックで移動、Spaceでジャンプ
  • 画面ドラッグで視点を回す
  • 左クリック / 掘るボタンでブロックを壊す
  • 右クリック / 置くボタンでブロックを設置
  • 1〜5で草・土・石・木・葉を選択
  • 落ちても自動でスポーンへ戻る。自由に建築しよう

Rでワールド再生成 / 右上の?で操作確認

HOW TO PLAY

あそびかた

  • 移動: WASD / 左スティック
  • 視点: 画面をドラッグ
  • 掘る: 左クリック / 掘るボタン
  • 置く: 右クリック / 置くボタン
  • ジャンプ: Space / JUMP
  • 選択: 1〜5 / ホットバー
  • 再生成: R
