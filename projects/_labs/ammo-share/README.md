# AMMO SHARE

撃った弾が1.5秒後に敵の弾になって返ってくる、60秒の共有弾倉シューターです。

## 遊び方

- `←` `→` / `A` `D` で左右に移動
- `SPACE` / `FIRE` で上方向に射撃。押し続けると連射
- **外した弾は1.5秒後に、同じxから赤い敵弾として降ってくる**
- 赤い返球は自分の弾で撃ち落とせる
- 敵が画面下に抜けると、その敵も返球になる
- `E` / `PURGE` で返球予約と画面上の赤弾をすべて消す（開始2回、金の敵で回復）
- 赤弾か敵に当たると終了。60秒生き延びれば SURVIVED

撃つほど未来が危なくなるので、当てられる時だけ撃つことが基本です。外した分だけ DEBT が増え、HUDの警告線として画面上部に予告されます。

## スコア

- 敵: DRONE 10 / WEAVER 15 / TANK 30 / GOLD 60
- 返球を撃ち落とす: 3
- PURGEで消した返球: 1ずつ
- 60秒生存: +200

ランクはスコアで決まります（CLEAR時 S/A/B/C、被弾時 B/C/D）。

## 構成

| ファイル | 役割 |
| --- | --- |
| `engine.js` | 射撃、返球予約、敵、当たり判定、PURGE、スコア |
| `game.js` | Canvas描画、入力、HUD、画面遷移 |
| `index.html` | HUD、開始/終了画面、操作ボタン |
| `style.css` | 縦長レイアウト、ネオンUI、レスポンシブ |
| `test-engine.js` | 射撃、返球、撃破、PURGE、時間切れ |
| `test-smoke.js` | 実際の `game.js` を起動して自動プレイ |

## 設計メモ

- `engine.js` はDOMに触れない。`update(state, dt)` と `setMove` / `setFiring` / `purge` で進む
- 画面外に出た弾は `pending` に予約し、`time` が `at` を超えたら `threats` に移す。予約中は上部に警告線を描く
- 返球は敵弾でありながら自分の弾で破壊できる。撃ち落とすほどスコアと命中率が上がる
- 返球予約は最大80件。超えた場合は古いものから捨てる
- 1ライフの短いランにし、当たった理由（外しすぎ／抜けられた）が結果画面で分かるようにした
- `window.__GAME__` の6キー（`id` / `title` / `start` / `autoPlayStep` / `isDone` / `getState`）を公開する

## テスト

```sh
cd projects/_labs/ammo-share

```
