# ジャンプラッシュ（jump-rush）

自動で走り続けるヒーローを、タップ / クリック / Space でジャンプさせてゴールを目指す、スマホ縦画面向けの横スクロールアクションです。敵を上から踏んで倒し、穴や横からの接触を避けながら、右端の旗ポールから城へ入るとゲームクリアです。依存ゼロの静的ファイルだけで動きます。

## 遊ぶ

universe のルートで次を実行し、http://localhost:8000/projects/_labs/jump-rush/ を開きます。

```sh
python3 -m http.server 8000
```

## 操作

- **タップ / クリック / Space**: ジャンプ
- **押しっぱなし**: 高く跳ぶ。指を離すと上昇を打ち切る
- **P / Esc / 画面右上のポーズボタン**: 一時停止と再開
- 画面外に出る、タブを隠す、ウィンドウをフォーカスから外すと自動でポーズ
- スマホでは触れた位置にスティック風のインジケーターを表示する。指を離すと必ず消える

## ルール

- ヒーローは右へ自動で進む。ライフは 3
- 敵の上に落ちると **STOMP**。100 点と跳ね返り
- 敵の横・炎・穴に触れるとライフ -1。ライフ 0 で **GAME OVER**
- 穴に落ちたときやダメージ後は、直前に安全だった地上へ戻る。再開直後は無敵
- 下から叩くと壊せるブロックと、壊せない金属ブロックがある
- 右端の旗ポールに触れるとポールを滑り降り、城へ歩いて **GAME CLEAR**
- スコアは距離、踏み、壊したブロック、クリアボーナスで決まる
- ベストスコアは `localStorage`（キー `jump-rush-best`）に保存される

## 敵

| 種類 | 動き |
| --- | --- |
| ウォーカー | 地上を左右に往復する |
| ホッパー | 地上で一定間隔ごとに跳ねる |
| ホバー | 空中を上下し、ゆっくり左右に漂う |
| シューター | 地上に固定され、プレイヤーのいる方向へまっすぐ弾を撃つ（追尾しない） |

## 見た目

- ネオンと夕暮れの街をイメージした 480×800 の Canvas
- 星、月、山、街の窓、地面のグリッドがカメラに合わせて視差移動
- 踏み・ブロック破壊・ダメージでパーティクル、ポップアップ、画面の揺れ
- クリア時は紙吹雪と城のゲート演出
- スマホの safe-area、縦画面、PC の横長画面に対応

## ファイル構成

```text
jump-rush/
├── index.html      # HUD・タイトル・リザルト・Canvas
├── styles.css      # 縦画面レイアウト、safe-area、オーバーレイ
├── script.js       # ゲームロジック、描画、入力、window.__GAME__
├── test-engine.js  # 物理・踏み・ダメージ・ブロック・クリアのテスト
└── test-smoke.js   # 自動プレイで城まで到達するスモークテスト
```

## 設計の要点

- **480×800 の論理座標**: 画面サイズが変わってもゲーム内の座標は固定。Canvas の実ピクセルだけ DPR に合わせる
- **入力は pointerId 単位**: 最初のポインタだけがジャンプを担当し、`setPointerCapture` で取りこぼしを防ぐ。複数指でも 2 本目以降はインジケーターだけ
- **可変ジャンプ**: 上昇中に押し続けると重力を弱め、離すと上昇速度をカットする
- **安全地点を記録**: 地上にいて、穴と敵から離れた位置だけをチェックポイントにする
- **描画と判定の分離**: ゲーム状態はワールド座標で更新し、描画時にカメラを引く
- **自動プレイ**: `window.__GAME__.autoPlayStep` は穴・地上敵・弾を見てジャンプし、クリア画面まで到達する

## テスト

universe のルートで実行します。

```sh
./tools/run-tests.sh
```

個別に実行する場合:

```sh
cd projects/_labs/jump-rush
jsc test-engine.js
jsc test-smoke.js
```

`test-engine.js` は 4 種類の敵、可変ジャンプ、踏み、横接触、穴、壊せる / 壊せないブロック、ポーズ、旗から城へのクリア、3 回ダメージでのゲームオーバーを検証します。`test-smoke.js` は `window.__GAME__` を自動プレイし、クリア画面、HUD、ベスト、タイム、踏み数を確認します。

## 既知の制限

- 効果音はない
- 横方向の移動操作はない（自動ラン）
- 保存はブラウザごと。シークレットモードでは消える
- ステージは 1 本の固定コース
