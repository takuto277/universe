# TUTOR

3回の手本でロボットAIを鍛え、10回の本番の成績を競う育成ゲームです。

## 遊び方

- `←` `→` / `A` `D` でロボットを左右に動かす
- 金色のコアを取るとスコア、赤いボムに当たると0.6秒スタンしてコアを1個失う
- 1回6秒の手本を3回見せる。操作は「状態 → 行動」として記録される
- 手本のあと、AIが5秒×10回の本番を3倍速でプレイする
- スコアはAIが取ったコアの合計。手本の質がそのままAIの強さになる
- コアを多く取れるほどランクが上がる（D〜S）。ベストは保存される

## AIの仕組み

- 手本は 0.05 秒ごとに、コアとボムの相対位置（dx/dy）を特徴として記録する
- 本番では、いまの特徴に近い手本を k=5 個探し、その行動を重み付きで多数決する（k近傍法）
- 学習前に左右反転した手本も加える。少ない手本でも左右の判断を補うため
- 手本にない状況では、近い状況の真似になる。だから「先回りして動く」「ボムから離れる」を手本で見せると強い

## 構成

| ファイル | 役割 |
| --- | --- |
| `engine.js` | 手本の記録、k近傍の模倣、コア/ボム、10回の本番 |
| `game.js` | Canvas描画、入力、HUD、画面遷移 |
| `index.html` | HUD、開始/終了画面、左右ボタン |
| `style.css` | 縦長レイアウト、ラボ風UI、レスポンシブ |
| `test-engine.js` | 記録、特徴量、予測、スタン、10回の本番 |
| `test-smoke.js` | 実際の `game.js` を起動して自動プレイ |

## 設計メモ

- `engine.js` はDOMに触れない。`update(state, dt)` と `setInput(state, dir)` で進む
- 本番は `EVAL_SPEED = 3` で進める。10回×5秒を約17秒で見せる
- 学習データは `{ f: 特徴, a: 行動 }` の配列。`startTraining` で左右反転を追加する
- ボム被弾は終了ではなく、スタンとコア1個の損失にした。10回の本番すべてで学ぶ機会を残すため
- `window.__GAME__` の6キー（`id` / `title` / `start` / `autoPlayStep` / `isDone` / `getState`）を公開する

## テスト

```

cd projects/_labs/tutor
jsc test-engine.js
jsc test-smoke.js
```

## 既知の制限

- 効果音は未実装
- 模倣はk近傍法で、手本にない状況の一般化は弱い。手本の coverage がそのまま上限になる
- 自動プレイの手本AIは「近いコアへ向かい、近いボムから離れる」貪欲法
