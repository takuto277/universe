# スティック・コロシアム（stick-colosseum）

5人 vs 5人で戦う、ターン制の押し出しバトルです。自分の選手を引っ張って突進させ、相手をリングの外へ押し出します。ボールやゴールはなく、先に3人をリングアウトさせた方が勝ち。各選手は1回だけ「ふんばり」を持ち、最初のリング際で踏ん張って内側に戻るため、先攻の一撃で即決着にはなりません。

## 遊ぶ

universe のルートで `python3 -m http.server 8000` を実行し、http://localhost:8000/projects/_labs/stick-colosseum/ を開きます。

## ルール

- 5人 vs 5人。自分のターンに**好きな自分の選手を引っ張って離す**と突進
- 相手にぶつけて、リングの外へ押し出す
- 各選手は**ふんばり1回**。リング際で踏ん張り、内側へ戻る
- ふんばりが切れた選手がリング外へ出ると**リングアウト**
- **先に3人リングアウトさせた方が勝利**
- リングアウト後は、**失点側が次の先攻**。連続で押し込まれにくい
- 初期配置は **2-2-1 / 3-1-1 / 1-2-2** の3種類から選択
- CPUのLVは3ステージで上昇。勝つと次のアリーナへ
- 3ステージを突破するとENDING
- 自分の選手同士もぶつかる。味方を押し出すこともできる

## 操作

- 自分の選手の近くをドラッグして離す: 突進
- **P / Esc / 右上のポーズ**: 一時停止と再開
- **M / 右上の♪**: BGMの消音 / 再生
- **Space / Enter**: タイトルで開始 / リザルトで再戦 / 次ステージへ
- 画面外に出る、タブを隠す、フォーカスを外すと自動ポーズ

## 見た目

- ネオンリングの円形アリーナ。中央のエンブレムと同心円
- 自分はミント/ゴールドの背面、CPUはピンクの正面の生成画像
- 各選手の足元にふんばりリング。ふんばりが切れると色が変わる
- 引っ張り線、逆方向の矢印、パワー%
- リング際の `EDGE SAVE!`、リングアウト時のフラッシュ、画面揺れ、紙吹雪、花火、衝撃波、`RING OUT!` バナー
- スタジアム風BGM（WebAudio生成）

## 設計の要点

- **引っ張り**: ドラッグの逆方向へ選手の速度を与える。最大速度は `MAX_PULL * PULL_POWER`
- **ふんばり**: リング外に出る判定のとき `guard > 0` なら、リング内側へ戻して `guard = 0`。2回目のリング外でリングアウト
- **リングアウト**: 残り人数ではなく、先に3リングアウトで決着。リングアウト後は生存者を開始位置へ戻し、失点側のターンにする
- **ターン**: 全選手が止まったら次のチームへ。リングアウト時は失点側を先攻にする
- **CPU**: 自分の選手と相手の組み合わせをシミュレーションし、相手を外へ押し出せるか、ガードを割れるか、自分の選手が落ちないかを評価。ステージが上がると探索人数・精度・パワーが上がる
- **フォーメーション**: 5人の相対座標プリセット。Playerは下側、CPUは上側に対称配置

## テスト

universe のルートで:

```sh
./tools/run-tests.sh
```

個別に:

```sh
cd projects/_labs/stick-colosseum
jsc test-aim.js
jsc test-audio.js
jsc test-engine.js
jsc test-smoke.js
```

## 既知の制限

- 2Dトップダウンの簡易物理。回転やキャラクターの向き変更はない
- 初期配置は3種類のプリセットのみ。自由配置はできない
- CPUはヒューリスティックな軌道シミュレーションで、学習AIではない
- BGMはWebAudio生成のため、環境によって音色が多少異なる
- オンライン対戦やランキングはない
