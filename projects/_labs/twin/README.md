# TWIN

1つの入力で2体を同時に操り、片方に0.4秒の遅延をかけて塔を登る縦スクロールアクションです。

## 遊び方

- `←` `→` / `A` `D` で2体を操作する
- 2体は常に同じ入力を共有するが、片方（ECHO）は0.4秒遅れて反応する
- `SPACE` / `SWAP` で、どちらを遅延させるかを入れ替える
- 上下に並んだ2体を、それぞれ別のゲートの開口部に通す
- ゲートにぶつかるとライフが1減る。ライフが0になると終了
- 3ステージを登り切れば CLEAR。ステージが上がるほど速く、開口部が狭くなる

遅延があるからこそ、2体のx座標をずらせます。どちらを遅らせるかで、次のゲートの並びに合う幅が変わります。

## 見どころ

- 1本の入力履歴を2つの遅延値でサンプリングする、ECHO（遅延）機構
- 前後2体のゲート差分を読む、先読みと入れ替えの判断
- ステージごとに上がる速度・狭くなる開口部・大きくなる隣接ゲートのズレ
- Canvasだけで描くネオンの塔、星、ゲート、パーティクル
- スマホ用の左右パッドとSWAPボタン

## 構成

| ファイル | 役割 |
| --- | --- |
| `engine.js` | 入力履歴、遅延サンプリング、移動、ゲート判定、ステージ進行 |
| `game.js` | Canvas描画、入力、HUD、画面遷移 |
| `index.html` | HUD、開始/終了画面、操作ボタン |
| `style.css` | 縦長レイアウト、ネオンUI、レスポンシブ |
| `test-engine.js` | 遅延、入れ替え、ゲート通過、ライフ、ステージ進行 |
| `test-smoke.js` | 実際の `game.js` を起動して自動プレイ |

## 設計メモ

- `engine.js` はDOMに触れない。`update(state, dt)` と `setInput(state, dir)` だけで進む
- 入力は `{ t, dir }` の履歴として保持し、各体は `time - lag` の位置を読む。`swap` は lag の割り当てを変えるだけ
- 隣接ゲート中心のズレは `STEER * DELAY = 80` 未満に抑え、遅延を使って到達できる範囲にしている
- ゲート通過判定は各体のyがゲートを跨いだ瞬間のxで行う
- `window.__GAME__` の6キー（`id` / `title` / `start` / `autoPlayStep` / `isDone` / `getState`）を公開する

## 既知の制限

- 効果音は未実装
- ステージ構成は3つの固定パラメータのみ。ゲート列はシード乱数で生成する
- 自動プレイは遅延を考慮した貪欲法で、SWAPは使わない
