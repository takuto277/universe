# スティックサッカー（stick-soccer）

ボールを引っ張って離し、11人ずつ計22人の棒人間が並ぶピッチでゴールを狙う、ターン制フリックサッカーです。試合前に自分の11人を4本のラインへ配置する、制限付きフォーメーション編集があります。CPUのフォーメーションは3つのステージで変化し、スタジアム風のオリジナルBGMも流れます。プレイヤーとCPUが交互にキックし、ボールは摩擦で止まるまで転がります。棒人間に当たると跳ね返り、先に3点取るか、12キック終了時の得点で勝敗が決まります。依存ゼロの静的ファイルだけで動きます。

## 遊ぶ

universe のルートで次を実行し、http://localhost:8000/projects/_labs/stick-soccer/ を開きます。

```sh
python3 -m http.server 8000
```

## ルール

- 試合前に**自分の11人を下側4本のライン（FW/MF/DF/GK）へ配置**。自由配置ではなく、スロットへスナップする
- 各ラインは**9スロット**。同じラインの左右に隣接するスロットには置けない（壁を作れない）
- CPUも11人。相手フォーメーションは**STAGE 1: 4-4-2 / STAGE 2: 3-5-2 / STAGE 3: 4-3-3**と変化する
- ステージに勝つと次のステージへ。3ステージを突破するとENDING
- 自分のターンに**ボールを引っ張って離す**とシュート。引いた方向と逆へ飛ぶ
- 引く長さでパワーが変わる。ピッチ上の棒人間に当たるとボールが跳ね返る
- CPUと交互にキック。1キックごとにボールが止まった位置から次のターン
- 先に**3点**取った方が勝利
- **12キック**で決着がつかなければ、その時点の得点で勝負。同点ならDRAW
- ゴール後はセンターから、失点側のキックで再開
- CPUもボールを引っ張ってシュートする。軌道シミュレーションでゴールを狙う

## 操作

- ボールの近くをドラッグして離す: シュート
- **P / Esc / 右上のポーズ**: 一時停止と再開
- **M / 右上の♪**: スタジアムBGMの消音 / 再生
- フォーメーション画面で選手をドラッグして4本のライン×9スロットへ移動。左右の隣接スロットは赤い×で拒否される
- **Space / Enter**: タイトル・リザルトで開始 / 再戦 / 次ステージへ
- 画面外に出る、タブを隠す、ウィンドウをフォーカスから外すと自動でポーズ
- ピンチズーム、ダブルタップズーム、長押しメニューを抑制

## 見た目

- 縦向きの深緑ピッチ、ネオンのタッチライン、ペナルティエリア、センターサークル
- 上はCPUのピンクゴール、下はプレイヤーのミントゴール
- 22人の棒人間。CPUはピンク、自分はミント/ゴールド。当たると発光してボールが跳ね返る
- フォーメーション画面では自分の4本のラインと36スロット、上側にCPUフォーメーションのゴーストを表示。左右に隣接した配置は不可
- 4小節ループのスタジアム風BGM（ドラム、ベース、ブラス、観客ノイズ、ホイッスル）をWebAudioで生成
- シュート時は引っ張り線、逆方向の矢印、パワー%、ボールの残像
- ゴール時はフラッシュ、画面の揺れ、紙吹雪、スコアバナー
- 12キックのターン制、HUDにYOU/CPUスコア、STAGE、KICK数
- safe-area、縦画面、PCの横長画面に対応

## ファイル構成

```text
stick-soccer/
├── index.html      # HUD・タイトル・リザルト・Canvas
├── styles.css      # 縦画面レイアウト、safe-area、オーバーレイ
├── engine.js       # フリック、摩擦、壁/22人の反射、ゴール、フォーメーション、CPU AI
├── audio.js        # スタジアム風BGMのWebAudio生成
├── game.js         # Canvas描画、ドラッグ、エフェクト、ステージ、window.__GAME__
├── test-audio.js   # BGMスケジューラ・消音・停止のテスト
├── test-engine.js  # ルール・反射・ゴール・ターン・勝敗のテスト
└── test-smoke.js   # 自動プレイでゲーム終了まで確認
```

## 設計の要点

- **スリングショット入力**: ドラッグベクトルの逆方向に速度を与える。長さは最大90、速度は最大990相当
- **摩擦と停止**: 速度から毎秒430を減算し、18以下が0.22秒続いたらターン終了
- **反射**: 壁は0.82、棒人間は0.88の反発係数。22人全員が円形の当たり判定
- **フォーメーション**: 4本のライン×9スロット。選手はスロット間だけを移動でき、試合中は固定。同一ラインの隣接スロットを禁止して、棒人間の壁でボールが通らなくなるのを防ぐ
- **ゴール判定**: 上下のゴールマウス内でゴールラインを越えたら得点。ポスト外は壁として反射
- **CPU**: ゴール方向の複数ターゲット×4パワーを軌道シミュレーションし、得点・前進・ゴール接近度で選択。少しだけ角度とパワーに揺らぎを入れる
- **自動プレイ**: `window.__GAME__.autoPlayStep` はプレイヤー側もAIでシュートし、CPUと交互に進める
- **陣形とステージ**: 選んだ自分のフォーメーションとステージのCPUフォーメーションは `createGame({ formation, stage })` で22人の障害物座標に変換される
- **ステージ**: 3つのCPUフォーメーションを持ち、勝利時に次のステージへ進む。BGMは外部音源を使わずWebAudioで合成する
- **ターン制**: シュートは12本まで。先に3点、または12本終了時に得点で決着

## テスト

universe のルートで実行します。

```sh
./tools/run-tests.sh
```

個別に実行する場合:

```sh
cd projects/_labs/stick-soccer
jsc test-audio.js
jsc test-engine.js
jsc test-smoke.js
```

`test-engine.js` はドラッグから速度への変換、壁と22人の棒人間の反射、9スロットのフォーメーション、左右隣接の禁止、3ステージのCPUフォーメーション、ゴール、ターン切替、3点先取、12キック終了、CPUの軌道選択を検証します。`test-audio.js` はBGMの生成・消音・停止を検証します。`test-smoke.js` は `window.__GAME__` を自動プレイし、HUDとリザルト/ステージ画面まで確認します。

## 既知の制限

- 2Dトップダウンの簡易物理。スピン・回転・芝の抵抗差はない
- フォーメーションは4本のライン×9スロットに限定。自由な2D配置や試合中の移動はできない。左右の隣接スロットは選べない
- CPUは軌道シミュレーションによるヒューリスティックで、学習AIではない
- BGMはブラウザのWebAudioで生成するため、環境によって音色が多少異なる
- ステージは3面。オンライン対戦やランキングはない
