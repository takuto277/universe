# THERMO

冷えた施設で、体の熱を物体と交換しながら出口を目指すグリッドパズルです。UIは英語のみです。

- **移動** — 矢印キー / WASD / 画面下のD-pad
- **交換** — 向いている方向、または隣接する特殊タイルへ `EXCHANGE`（Space / E）
- **体温** — 20°C〜80°Cが安全帯。外れるとその部屋は失敗

## 遊び方

1. **ENTER FACILITY** を押す。
2. 体の熱は50°Cから始まる。水や火の玉に熱を吸わせると体温が上がり、水は氷になって足場になる。
3. 氷や熱扉に熱を放出すると体温が下がり、氷は水に戻り、扉は開く。
4. 水は移動できない。氷の上は歩ける。扉は開くまで通れない。
5. 出口 `X` に到達すると部屋クリア。全5部屋を抜けると **ALL CLEAR**。
6. 体温が20°C未満で **FROZEN**、80°C超で **OVERHEATED**。その部屋をやり直す。

交換は「向いているタイル」を優先し、向きに特殊タイルがなければ隣接する特殊タイルを対象にします。対象には黄色（吸熱）または青緑（放熱）のブラケットが出ます。

## ルール

- 体温は50°Cから。吸熱で+15°C、放熱で-15°C。
- 水 `~` に吸熱 → 氷 `*` になり、+15°C。
- 火の玉 `E` に吸熱 → 灰 `.` になり、+15°C。
- 氷 `*` に放熱 → 水 `~` になり、-15°C。
- 熱扉 `D` に放熱 → 開扉 `O` になり、-15°C。
- 壁 `#`、水 `~`、火の玉 `E`、閉じた扉 `D` は移動できない。
- 部屋ごとに体温は50°Cに戻る。手持ちの熱は持ち越さない。

## 部屋

| 部屋 | 名前 | 主な課題 |
| --- | --- | --- |
| 1 | THAW | 水を凍らせ、熱扉を開ける |
| 2 | CROSSING | 2列の水を渡る |
| 3 | LOCKS | 2枚の熱扉を開ける |
| 4 | DUAL | 水と扉を交互に処理する |
| 5 | CORE | 水2枚と扉4枚。熱の使い方が問われる |

## 見た目と音

- 暗い施設のグリッド。水は波、氷は淡いシアン、火の玉は橙色、出口はシアンの菱形。
- プレイヤーの色は体温で青緑→橙に変わる。
- 対象タイルに吸熱/放熱のブラケットを表示。
- WebAudioで移動、吸熱、放熱、開扉、クリア、失敗音をプロシージャルに生成。外部音源なし。
- 画面は縦長。PCでは中央の縦パネルとして表示。共通ナビゲーションから一覧へ戻れる。

## 設計の要点

- **体温が唯一の資源**: 水/火の吸熱と氷/扉の放熱が、移動経路と体温の両方を変える。体温を安全帯に保つことがパズルの中心。
- **部屋はグリッドデータ**: `#` `~` `*` `E` `D` `O` `X` の文字列で定義。エンジンはUIに依存しない。
- **交換は対象の種類で決まる**: 水/火は吸熱、氷/扉は放熱。プレイヤーは「何に触るか」と「体温をどう使うか」を選ぶ。
- **失敗は部屋単位**: 体温が外れたらその部屋をリトライ。全体の移動数と時間はクリア済み部屋の合計。
- **自動プレイ**: 各レベルの既知解を `autoPlayStep()` で再生し、スモークテストとサムネイル生成に使う。

## テスト

```sh
cd projects/_labs/thermo
jsc test-engine.js
jsc test-smoke.js
```

`test-engine.js` は水の凍結、扉の開放、過熱失敗、リトライ、5部屋クリアを検証します。`test-smoke.js` は自動プレイで全5部屋を抜け、ALL CLEAR の結果画面が出ることを確認します。リポジトリ全体では `./tools/verify.sh` です。
