# スティックサッカー プレイヤーズ（stick-soccer-players）

選手を引っ張って突進させ、ボールにぶつけてゴールを狙うターン制フリックサッカーです。自分とCPUが11人ずつ、計22人の棒人間で戦います。ボールに当たった選手も弾かれ、選手同士がぶつかったときの吹っ飛びはボールに当たったときの約1/3。先に3点取った方が勝ちです。

## 遊ぶ

universe のルートで `python3 -m http.server 8000` を実行し、http://localhost:8000/projects/_labs/stick-soccer-players/ を開きます。

## ルール

- 自分のターンに**好きな自分の選手を引っ張って離す**と、引いた方向と逆へ突進する
- 突進した選手がボールに当たると、ボールが大きく吹っ飛ぶ。選手も反動で弾かれる
- **選手同士の衝突**でも双方が吹っ飛ぶが、その強さはボール衝突の約1/3
- ボールが上のゴールに入れば自分、下のゴールに入ればCPUの得点
- **先に3点取った方が勝利**。キック数に上限はなく、決着がつくまで続く
- ゴール後はボールと両チームの位置をリセットし、失点側のターンで再開
- 試合前に自分の11人を下側4本のラインへ配置。各ライン9スロットで、左右に隣接した配置は不可
- CPUのフォーメーションとLVは3ステージで上昇。勝つと次のステージへ
- 3ステージを突破するとENDING

## 操作

- 自分の選手の近くをドラッグして離す: 突進
- **P / Esc / 右上のポーズ**: 一時停止と再開
- **M / 右上の♪**: BGMの消音 / 再生
- フォーメーション画面で選手をドラッグして4本×9スロットへ移動。左右の隣接スロットは赤い×で拒否
- **Space / Enter**: タイトル・リザルトで開始 / 再戦 / 次ステージへ
- 画面外に出る、タブを隠す、ウィンドウをフォーカスから外すと自動でポーズ

## 見た目

- 縦向きの深緑ピッチ、ネオンのライン、上下のゴールネット
- 22人の棒人間。CPUはピンク、自分はミント/ゴールド
- 突進中の選手から伸びる引っ張り線、逆方向の矢印、パワー%
- ボールと選手の衝突時に火花とBONK表示
- ゴール時は画面フラッシュ、強い画面揺れ、紙吹雪、花火、衝撃波リング、GOALバナー
- フォーメーション画面では自分の36スロットとCPUフォーメーションのゴースト、CPU LVを表示
- スタジアム風BGM（ドラム、ベース、ブラス、観客ノイズ、ホイッスル）をWebAudioで生成

## 設計の要点

- **選手を投げる**: ドラッグの逆方向へ選手の速度を与える。最大速度は `MAX_PULL * PULL_POWER`
- **質量と反発**: ボール質量1、選手質量3、ボール反発0.95、選手同士の反発0。これによりボールは選手の約1.46倍、選手同士は約0.5倍で吹っ飛び、比率が約1/3になる
- **衝突**: ボール-選手、選手-選手の円衝突をサブステップで処理。壁とゴールも同時に判定
- **ターン**: 自分またはCPUの選手が動き、ボールと全選手が止まったら次のターン。選手の位置は次の得点まで保持
- **CPU**: 自分の選手とゴールターゲットの組み合わせを軌道シミュレーションし、得点・前進・ゴール接近度で選択。ステージが上がるほど探索人数が増え、角度・パワーの揺らぎと悪手が減り、判断が速くなる
- **フォーメーション**: 作成時の11人配置をホーム位置として保持。得点後にリセット
- **ステージ**: 3ステージ。CPUフォーメーション（4-4-2 / 3-5-2 / 4-3-3）とAIパラメータが変化

## テスト

universe のルートで:

```sh
./tools/run-tests.sh
```

個別に:

```sh
cd projects/_labs/stick-soccer-players
jsc test-aim.js
jsc test-audio.js
jsc test-engine.js
jsc test-smoke.js
```

`test-engine.js` は22人、9スロット、左右隣接禁止、ボール/選手の吹っ飛び比率（約1/3）、ゴール、3点先取、失敗フォールバック、CPUプランを検証します。`test-aim.js` は選手中心からずらしてタッチした場合も、表示と同じドラッグベクトルで発射されることを確認します。

## 既知の制限

- 2Dトップダウンの簡易物理。スピン・回転・芝の抵抗差はない
- フォーメーションは4本×9スロット。自由な2D配置や試合中の移動はできない
- CPUは軌道シミュレーションによるヒューリスティックで、学習AIではない
- BGMはWebAudio生成のため、環境によって音色が多少異なる
- オンライン対戦やランキングはない
