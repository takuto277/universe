# ORBIT WARD

中心の星を守る、60秒の360度シールドディフェンスです。外側から迫るシャードに合わせてシールドを円周上で動かし、コアに届く前に弾きます。UIは英語のみです。

- **シールド** — コアの周りをドラッグして、シャードがリングを横切る位置へ合わせる
- **PERFECT** — シールドの中心で迎撃するとスコア増加、PULSEチャージも多め
- **PULSE** — メーターが満タンになったら発動。軌道上のシャードをすべて消す
- **CORE** — 10個のコア。シャードが1つ届くたびに1つ失う
- **60秒** — 朝まで耐えれば勝利。スコアとランクを競う

## 遊び方

1. **ENTER ORBIT** を押す。
2. コアの周りをドラッグして、シアンのシールドを動かす。マウスならポインタに追従する。
3. 外側から diamond 型のシャードが近づいてくる。シールドの弧がシャードの軌道と重なる位置で迎撃する。
4. 弧の中心で迎撃すると **PERFECT**。迎撃とPERFECTでPULSEチャージがたまる。
5. PULSEが満タンになったら、右下の **PULSE** を押す（または Space）。画面上のシャードをすべて消去する。
6. 60秒耐えると **DAWN BREAKS**。コアが0になると **THE CORE BREAKS**。
7. 結果画面でスコア、S/A/B/C/Dランク、迎撃数、PERFECT数、最大チェーン、PULSE使用数を確認する。

## ルール

- シャードがリングを外れてコアに到達するとコアが1つ減り、チェーンが途切れる。
- チェーンは迎撃するたびに伸び、スコア倍率が上がる（最大2倍弱）。
- **BASIC** は標準。**SPLITTER** はリングの手前で2つのフラグメントに分裂する。**GOLD** は速く高得点。**HEAVY** は大きく硬い。
- 15秒・30秒・45秒にまとまった **SURGE** が来る。45秒以降はシャードの間隔が詰まる。
- チェーンが切れてもPULSEチャージは残る。ピンチで使うか、PERFECTを重ねて早めに使うかの判断がある。
- ベストスコアは `localStorage` に保存。

## 見た目と音

- 深宇宙の星雲、瞬く星、軌道リング、脈打つ金色の星。
- シアンのシールド弧、角度マーカー、迎撃時の粒子、PERFECTの浮遊文字。
- シャードは種類ごとの色・形・軌跡。分裂時は紫の破片が散る。
- PULSE発動時は画面全体へ金色の衝撃波。コア被弾時は赤い粒子と画面シェイク。
- WebAudioで低い環境ドローン、迎撃、PERFECT、被弾、PULSE、SURGE、勝利/敗北音を生成。外部音源なし。

## 設計の要点

- **角度だけの防御**: 位置ではなくシールドの角度を操作する。全方位から来る敵に対して、プレイヤーは「回る」「待つ」「PULSEで消す」の3つを選ぶ。
- **PERFECTの二重報酬**: スコア倍率だけでなくPULSEチャージも増えるので、正確な迎撃が次のピンチを切り抜ける資源になる。
- **分裂とSURGE**: SPLITTERはリング手前で2つに増える。SURGEは同じ方向にまとめて出すことで、シールドを合わせれば一掃できる山場にした。
- **短い周回**: 60秒固定。負けてもすぐ再挑戦でき、ベストとランクで上達を測れる。
- **Canvas 2D**: 画像・外部ライブラリなし。星、シールド、シャード、粒子をすべて手続き的に描く。

## テスト

```sh
cd projects/_labs/orbit-ward
jsc test-engine.js
jsc test-smoke.js
```

`test-engine.js` はシールド角度、迎撃、PERFECT、PULSE、ミス、60秒の自動プレイを検証します。`test-smoke.js` は仮想DOM上で自動プレイし、結果画面とランク表示を確認します。リポジトリ全体では `./tools/verify.sh` です。

## 既知の制限と次に試すこと

- 60秒固定、1ステージ。難易度選択、日替わりシード、ボスシャードは未実装。
- シールドは1本の弧のみ。反射や分裂ビーム、コアの回復などの強化はまだない。
- シャードは図形。画像や3Dモデルは使っていない。
- SURGEの方向とタイミングを予告する演出、PULSEの使いどころを教えるチュートリアルを強化する余地がある。
- 実機で、指のドラッグ角度とシールドの追従、PULSEボタンの押しやすさを確認する。
