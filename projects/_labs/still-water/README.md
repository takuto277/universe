# STILL WATER

夕暮れの湖で、8回のキャストから釣果を競う1ボタンの釣りゲームです。左右の狙い、3つのポイント、PERFECTフッキング、連続釣果のストリークがあります。UIは英語のみです。

- **キャスト** — 押してパワーをため、離して投げる
- **アタリ** — ウキが沈んだらタップで合わせる
- **リール** — 押して巻き、離してテンションを逃がす
- **8投** — スコアと自己ベストを競う

## 遊び方

1. **CAST OFF** を押す。
2. 画面を押している間、キャストパワーがたまる。離すとウキが飛ぶ。
3. アタリが出たらタップしてフッキング。早く合わせると **PERFECT HOOK**。
4. リール中は「HOLD TO REEL / RELEASE TO EASE THE LINE」。押すと巻けるがテンションが上がる。離すと下がる。
5. テンションが100%を超えるとラインが切れ、低すぎる状態が続くと魚に逃げられる。
6. 8投終了時にスコア・釣果・総延長を表示。

## ルール

- キャストは8回。アタリを逃しても1投消費。
- キャストは左右に狙える。3つのポイント（REEDS / OPEN WATER / DEEP ROCKS）で魚の傾向が変わる。
- キャストパワーが強いほど遠くへ飛び、レアな魚が出やすい。
- 早いフッキングはPERFECT HOOKで、釣果スコア+20%。連続で釣るとストリーク倍率（最大1.5倍）。ミス・ラインブレイク・スラックでストリークは切れる。
- 魚は BLUEGILL / BASS / KOI / GOLDEN CARP / OLD BOOT の5種。
- サイズ×レア度でスコアが決まる。OLD BOOTは0点。
- リールのテンションは0〜100%。18〜76%あたりが安全域。
- ベストスコアは `localStorage` に保存。

## 見た目と音

- 夕暮れの空、月、山、湖、葦、ウキ、釣り竿、魚の影。
- キャスト中は着水予定地点をリングで表示。
- アタリではウキが沈み、リール中は魚の影と泡、釣り上げると魚が跳ねる。
- WebAudioで湖の環境音、キャスト、着水、アタリ、フッキング、リール、釣果、ラインブレイクを生成。外部音源なし。

## 設計の要点

- **1ボタンの3段階**: キャストは「ためて離す」、アタリは「タップ」、リールは「押す/離す」。同じボタンで3つの判断を切り替える。
- **パワーとレア度**: 遠投ほどレア魚の確率が上がるため、毎投「安全に狙うか、深く狙うか」を選ぶ。
- **テンションの綱引き**: 押し続けると巻けるが切れ、離し続けると逃げる。安全域を維持するリズムがゲームの中心。
- **水面の情報**: ウキ、ライン、魚の影、泡で状態を伝え、HUDはキャスト数・スコア・テンションに絞る。

## テスト

```sh
cd projects/_labs/still-water
jsc test-engine.js
jsc test-smoke.js
```

`test-engine.js` はチャージ・キャスト、アタリ、フッキング、テンションを逃がしながらの釣り上げ、アタリを逃したときの消費を検証します。`test-smoke.js` は8投の自動プレイで結果画面が出ることを確認します。リポジトリ全体では `./tools/verify.sh` です。

## 既知の制限と次に試すこと

- 8投固定。釣り場の追加、時間制、餌やルアーの選択、魚図鑑は未実装。3ポイントは左右の狙いで選ぶが、ポイントごとの地形変化はまだない。
- 魚は図形シルエット。画像や3Dモデルは使っていない。
- リールの安全域は固定。魚ごとの引きのパターンやラインの種類を増やす余地がある。
- 実機での片手操作と、タップで合わせるタイミングの心地よさを確認する。
