# STILL WATER

夕暮れの湖で、8回のキャストから釣果を競う1ボタンの釣りゲームです。3種類のルアー、3つのポイント、毎投変わるHOTスポット、PERFECTキャスト/フッキング、魚ごとの引きに合わせるリール、連続釣果のストリークがあります。UIは英語のみです。

- **キャスト** — 押してパワーをため、離して投げる
- **アタリ** — ウキが沈んだらタップで合わせる
- **リール** — 押して巻き、離してテンションを逃がす
- **8投** — スコアとランク、自己ベストを競う

## 遊び方

1. ルアーを選び、**CAST OFF** を押す。
2. 画面を押している間、キャストパワーがたまる。左右にドラッグして狙いを変える。
3. 金色に光る **HOT** スポットの中心に投げると **PERFECT CAST**。アタリが早くなり、レア魚とスコアにボーナス。
4. アタリが出たらタップしてフッキング。早く合わせると **PERFECT HOOK**。
5. リール中は「HOLD TO REEL / RELEASE TO EASE THE LINE」。押すと巻けるがテンションが上がる。離すと下がる。
6. テンションが100%を超えるとラインが切れ、低すぎる状態が続くと魚に逃げられる。
7. 8投終了時にスコア・ランク・釣果・総延長を表示。

## ルール

- キャストは8回。アタリを逃しても1投消費。
- キャストは左右に狙える。3つのポイント（REEDS / OPEN WATER / DEEP ROCKS）で魚の傾向が変わる。
- 毎投どれか1つがHOTスポットになる。中心±0.14に投げるとPERFECT CASTで、アタリが早く、釣果+15%、レア寄りになる。
- キャストパワーが強いほど遠くへ飛び、レアな魚が出やすい。
- 早いフッキングはPERFECT HOOKで、釣果スコア+20%。連続で釣るとストリーク倍率（最大1.5倍）。ミス・ラインブレイク・スラック・OLD BOOTでストリークは切れる。
- 魚は BLUEGILL / BASS / KOI / GOLDEN CARP / OLD BOOT の5種。
- サイズ×レア度でスコアが決まる。OLD BOOTは0点でストリークを切る。
- リールのテンションは0〜100%。18〜76%あたりが安全域。魚ごとの引き（STEADY / DARTER / DIVER / THRASH / DEAD）で押すリズムが変わる。
- 最終投はレア寄り。スコアに応じてS/A/B/C/Dランク。
- ベストスコアは `localStorage` に保存。

## ルアー

| ルアー | 特徴 | アタリ | 引き |
| --- | --- | --- | --- |
| WORM | 安全。小魚中心でレアが出にくい | 遅い | 弱い |
| SPOON | バランス型 | 普通 | 普通 |
| FLY | リスキー。レア寄りだがミスも増える | 速い | 強い |

## 魚

| 魚 | レア度 | サイズ | スコア倍率 |
| --- | --- | --- | --- |
| BLUEGILL | COMMON | 10〜24cm | ×1 |
| BASS | UNCOMMON | 28〜52cm | ×2 |
| KOI | RARE | 36〜68cm | ×3 |
| GOLDEN CARP | LEGENDARY | 52〜86cm | ×5 |
| OLD BOOT | JUNK | 24〜30cm | ×0（ストリーク終了） |

## 見た目と音

- 夕暮れの空、月、山、湖、葦、ウキ、釣り竿、魚の影。
- キャスト中は着水予定地点をリングで表示。HOTスポットは金色の波紋と魚影で強調。
- アタリではウキが沈み、リール中は魚の影と泡、釣り上げると魚が跳ねる。
- PERFECT CAST / PERFECT HOOK、JUNK CATCH、ランクを画面に表示。
- WebAudioで湖の環境音、キャスト、着水、アタリ、フッキング、リール、釣果、ラインブレイクを生成。外部音源なし。

## 設計の要点

- **1ボタンの3段階**: キャストは「ためて離す」、アタリは「タップ」、リールは「押す/離す」。同じボタンで3つの判断を切り替える。
- **2軸のキャスト**: 押す長さでパワー、離す位置でポイントを選ぶ。さらに毎投変わるHOTスポットが、狙いを合わせる理由になる。
- **ルアーの賭け**: WORMは安全、FLYはレア寄りだがアタリが速く引きが強い。同じ湖でも選ぶたびに緊張感が変わる。
- **魚ごとのリズム**: STEADY / DARTER / DIVER / THRASH / DEADで引きの波形が変わり、押す/離すタイミングを読む。
- **テンションの綱引き**: 押し続けると巻けるが切れ、離し続けると逃げる。安全域を維持するリズムがゲームの中心。
- **水面の情報**: HOTの金色、ウキ、ライン、魚の影、泡で状態を伝え、HUDはキャスト数・スコア・テンションに絞る。

## テスト

```sh
cd projects/_labs/still-water
jsc test-engine.js
jsc test-smoke.js
```

`test-engine.js` はチャージ・キャスト、HOTスポットへのPERFECT CAST、ルアー、魚のファイト型、アタリ、フッキング、テンションを逃がしながらの釣り上げ、アタリを逃したときの消費を検証します。`test-smoke.js` は8投の自動プレイで結果画面が出ることを確認します。リポジトリ全体では `./tools/verify.sh` です。

## 既知の制限と次に試すこと

- 8投固定。釣り場の追加、時間制、魚図鑑、ルアー強化は未実装。3ポイントは左右の狙いで選ぶが、ポイントごとの地形変化はまだない。
- 魚は図形シルエット。画像や3Dモデルは使っていない。
- リールの安全域は固定。魚ごとの引きパターンは入ったが、ラインの種類や障害物はまだない。
- 実機での片手操作、HOTスポットの見つけやすさ、FLYの難易度を確認する。
