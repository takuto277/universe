# SHIFT ROOM（見ていない部屋）

暗い部屋を抜け出すトップダウンの脱出ゲームです。鍵と扉は、**光の円錐（視線）の中に置かれている間だけ**位置が安定します。視線を外して約0.8秒経つと、鍵や扉は別の場所へ「シフト」します。3つの部屋・各3つの鍵・制限時間3分。

## 遊び方

1. 各室にある3つの鍵を集める。鍵に触れれば回収できる。
2. 3つ集めると扉が開く。
3. 開いた扉に触れると次の部屋へ。3部屋目を抜ければ脱出成功。
4. 制限時間3分が0になると失敗。

### 視線とシフトのルール

- 視線はプレイヤーから伸びる**約55度**の円錐。マウス（または右スティック）で向きを変える。
- 鍵と扉は、円錐の中にある間は位置が固定される。円錐の外に出ると `unseen` タイマーが進む。
- 円錐の外で**0.8秒**経つと、そのオブジェクトはランダムな有効スロットへワープする。ワープ先は「現在視線に入っていない場所」から選ばれる。
- プレイヤーは**後ろ歩き**ができる。移動方向と視線方向は独立している。
- 壁は**移動だけ**を遮る。視線は壁を貫通する（ルールを単純にして、位置取りの駆け引きに集中するため）。

## 部屋

1. **COLD STORAGE（冷たい保管室）** — 水色の保管庫。棚と中央の仕切りで視線の通り道が変わる。
2. **SIGNAL HALL（信号の広間）** — 赤い信号室。中央の柱と上下のバーで回り込むルートが増える。
3. **VOID ENGINE（虚無の機関室）** — 紫の機関室。左右に長い壁があり、端まで見渡しにくい。

各部屋には鍵スロットが10個、扉スロットが3個あり、開始時に3つの鍵と扉がランダムに配置されます。

## スコアとランク

- 鍵を1つ回収: **+100**
- 部屋を1つクリア: **+300**
- 脱出成功: **+500** と残り時間1秒あたり **+15**
- 時間切れ: その時点のスコアで終了、ランクは **D**

| ランク | 条件 |
| --- | --- |
| S | 脱出成功かつスコア 3800 以上 |
| A | 脱出成功かつスコア 3000 以上 |
| B | 脱出成功かつスコア 2200 以上 |
| C | 脱出成功（上記未満） |

ベストスコアは `localStorage` の `shiftroom-best` に保存します（保存できない環境では表示のみ）。

## 設計メモ

- `engine.js` は DOM と Canvas に依存しない。乱数は `mulberry32` のシード付きで、`createGame({ seed })` により同じ展開を再現できる。
- シフトはオブジェクトごとの `unseen` タイマーで管理する。視線内なら毎フレーム0に戻り、視線外なら `dt` を加算する。0.8秒に達したときだけ、視線外の空きスロットからワープ先を抽選する。
- 扉は鍵が3つ揃うまでロック。開いた後も視線を外すとシフトするため、「最後の鍵 → 扉」の間も見続ける必要がある。
- 描画はワールド座標（900×900）を canvas に合わせて等倍スケールし、レターボックスで中央寄せする。`devicePixelRatio` を考慮。
- 自動プレイAIは「最も近い未回収の鍵」を注視し、グリッドBFSで壁を避けて移動する。鍵がなくなったら扉へ向かう。`autoStep` は入力（移動・視線）だけを設定し、`update` は呼ばない。
- 観戦用の「watcher」は実装していない。理不尽な被弾より、視線と位置取りの駆け引きだけで緊張を作る方がフェアだと判断した（時間ペナルティもなし）。

## テスト

```sh
cd projects/_labs/shift-room
/System/Library/Frameworks/JavaScriptCore.framework/Versions/A/Helpers/jsc test-engine.js
/System/Library/Frameworks/JavaScriptCore.framework/Versions/A/Helpers/jsc test-smoke.js
```

リポジトリ全体では `./tools/run-tests.sh`。

`test-engine.js` は次を検証する。

- 3部屋・3鍵・180秒・55度・0.8秒のセットアップ
- 円錐の内外判定と、壁が視線を遮らないこと
- 見続けている鍵はシフトせず、見ていない鍵だけが0.8秒でシフトすること
- 鍵の回収、扉のロック解除、部屋遷移、壁の移動遮断
- 時間切れ、同一シードでの決定論、3部屋の自動プレイ完走

`test-smoke.js` はハーネス上で実際の `game.js` を起動し、終了状態・HUD・エンドオーバーレイ・`console.error` の有無を確認する。

## 既知の制限

- 視線は壁を貫通する仕様のため、壁の裏の鍵も見た目上は光る。位置関係の把握はプレイヤーの推測に委ねられる。
- バーチャルスティックはマルチタッチ対応だが、端末やブラウザによってはタッチイベントの挙動が異なる。
- 盤面は正方形固定で、極端に細長い画面ではレターボックスが大きくなる。
- `localStorage` が使えない環境ではベストスコアは保存されない。
- サウンドはWebAudioのシンセのみ。AudioContextが使えない環境では無音で動作する。
