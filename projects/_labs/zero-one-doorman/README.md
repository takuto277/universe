# 0.1秒ドアマン

奥から走ってくる人を、0.1秒で開閉するエレベーターのドアで仕分ける30秒ゲームです。

## 遊び方

- 本日のドレスコードは「ドレス OK / スーツ NG」
- ドレスの人は「開ける」、スーツの人は「閉じる」
- ドアは0.1秒で開閉する。ボタンを連打すると開閉状態をキープできる
- 正しく仕分けると加点、失敗するとコンボが切れる
- 30秒終了時のスコアと仕分け数でランク判定

## 見どころ

- 左右の金属ドアが中央で「バシッ」と閉まる
- 奥から走ってくる人が手前に来るほど大きくなる遠近感
- ドレスとスーツのキャラクター、OK / NG バッジ
- ドアの自動反転と連打による開閉キープ
- 仕分け成功でコンボ、0.1秒以内の操作でボーナス

## 構成

| ファイル | 役割 |
| --- | --- |
| `engine.js` | ドア開閉、乗客生成、仕分け判定、スコア、30秒終了 |
| `game.js` | Canvas 2D 描画、入力、HUD、画面遷移 |
| `index.html` | 画面の骨格、ルール、リザルト |
| `style.css` | エレベーター風UI、連打ボタン、レスポンシブ |
| `test-engine.js` | ドア、仕分け、コンボ、終了条件のテスト |
| `test-smoke.js` | 自動プレイで30秒完走 |

## テスト

universe のルートで:

```sh
./tools/run-tests.sh
```

個別:

```sh
cd projects/_labs/zero-one-doorman
jsc test-engine.js
jsc test-smoke.js
```

## 設計メモ

- ドアは閉まった状態から開始。0.45秒操作しないと自動で反転するため、連打で状態を維持する
- 開閉アニメーションは約0.1秒
- 仕分け判定はドアが開いているか（`doorOpen > 0.5`）と乗客タグだけで行う
- キャラクター画像は未導入。現在はCanvasのベクター描画
- 画像差し替え時は `game.js` の `drawDress` / `drawSuit` を画像描画に置き換える
