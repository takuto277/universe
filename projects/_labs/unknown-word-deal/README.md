# 未知語de交渉

品物は最初から見えています。読むのは、商人の文に潜む **文法語と意図**。差し出す / 受け取る / 断るを選ぶ、スマホ向けの言語交渉ゲームです。1回3〜5分。

## 遊び方

1. **文を読む** — 商人の短い文には、知らない文法語が1つだけ。品物の名前や「欲しい」などは最初から意味が表示されます。
2. **しぐさと前後の語から推理する** — 商人が品を押し返す、押し出す、自分を指さす。しぐさが意図のヒントになります。
3. **行動を選ぶ** — 3つのボタンから選びます。
   - **差し出す**: 品を商人に渡す
   - **受け取る**: 商人から品をもらう
   - **断る**: 取引しない
4. **外しても学べる** — 当たりは+10硬貨、外れは+3硬貨。行動のあとで未知語の意味が確定し、次の商人では読める語が増えます。
5. **迷ったら確認** — 「意味を確認」で2硬貨を払うと、その場で未知語の意味を開示できます。確認せずに賭けるか、払って確実にするか。
6. **契約書** — 3人のあと、契約1条の主語を読み、署名するか断るかを選びます。
   - 「あなた」が主語なら、あなたが品を受け取る（+5硬貨）
   - 「私」が主語なら、あなたが品を渡す（-5硬貨）
   - 断る: 増減なし

## 3人の流れ

1. **ムウ**: 「? パン 欲しい」＋自分を指さす → `?` は「私」。パンを **差し出す**。
2. **リサ**: 「私 魚 欲しい ?」＋魚を押し返す → `?` は「否定」。魚は欲しくないので **断る**。
3. **ゼン**: 「私 宝石 欲しい 否定」＋宝石を押し出す → 言葉では「欲しくない」が、しぐさは「持っていけ」。**受け取る**。

文法語の「私」「否定」は商人とのやりとりで学び、既知語だけの場面ではしぐさを読みます。

## ルール

- 語彙はシードから生成される7語（品物3 + 私 / あなた / 欲しい / 否定）。
- 品物、あなた、欲しいは最初から既知。私と否定は商人とのやりとりで学びます。
- 未知語は文の中で `?` として強調され、確認するか行動すると意味が確定します。
- 「私」「否定」は商人とのやりとりで学び、既知語だけの場面ではしぐさから意図を読みます。
- 契約は「あなた」か「私」かの主語で損得が変わります。

## 評価

最終的な硬貨がスコアです。

- S: 30硬貨以上
- A: 23硬貨以上
- B: 15硬貨以上
- C: それ未満

3人全員に正しい行動を取ると30硬貨。契約で+5を取れば35硬貨が最高です。確認に使った2硬貨はスコアに響きます。自己ベストはブラウザに保存されます（`localStorage`）。

同じシードなら同じ言語です。終了画面から「同じことばで再挑戦」できます。`?seed=12345` のように URL にシードを付けることもできます。

## 設計の要点

- **品物は見えている**: 品物当ての運をなくし、未知語を文法（私 / 否定 / 誰が欲しいか）に置き換えた。
- **1画面1判断**: 文・しぐさ・品物を見せ、選ぶのは「差し出す / 受け取る / 断る」の3つだけ。
- **確認のコスト**: 2硬貨で未知語を開示できる。確認するか賭けるかの判断を入れた。
- **学びが次の判断に効く**: 「私」「否定」を学び、既知語としぐさの食い違いを読む。
- **契約は主語の読み**: 最後に「あなた」か「私」かを読み、署名/拒否を選ぶ。
- **スマホ優先**: 幅460pxの縦画面。PCでは中央の細いパネルとして表示する。

## テスト

```sh
cd projects/_labs/unknown-word-deal
jsc test-engine.js
jsc test-smoke.js
```

リポジトリ全体では `./tools/verify.sh` です。`test-engine.js` は文法語の学習、3つの行動、確認コスト、契約の署名/拒否、シード再挑戦を検証します。`test-smoke.js` は `window.__GAME__` を自動プレイし、S評価・全問正解・契約最適・エンド画面まで確認します。

## 既知の制限と次に試すこと

- 1ランは3人固定（場面の順番はシードで変化）。商人の追加、日替わりシード、スコア共有は次版。
- 文法語は「私 / あなた / 欲しい / 否定」のみ。あげる/もらう、過去、丁寧さなどは今後の拡張。
- しぐさのヒントが強い場面がある。誤解を誘うしぐさや、商人ごとの信用度を入れる余地がある。
- 音のON/OFF、文字サイズ変更など、アクセシビリティはまだ十分ではない。
- スマホの実機で、片手操作と画面の収まりをさらに調整したい。
