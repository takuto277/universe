# SHADE（影渡り）

光源を切り替えて壁の影を伸ばし、見張りの視界を避けて出口を目指す、ターン制のステルスパズルです。光は見つかる原因であり、同時に隠れるための道具でもあります。

## 遊び方

- `WASD` / 矢印キー / パッド / 隣接マスのタップで1マス移動
- `L` / `LAMP` で光源を次のソケットへ切り替える（1ターン消費）
- 見張りの赤い視界は「光が当たっている範囲」。そこへ入ると見つかる
- 光源を変えると影が伸び縮みし、安全なマスと出口の露出が変わる
- 出口 `EXIT` へ10ターン以内に到達すればステージクリア
- 見つかる・ターン切れで残影を1つ失い、そのステージをやり直す
- 残影3つで5ステージを抜ければ ESCAPED。`Z` で一手戻せる

## 見どころ

- 光を動かすことが、そのまま「安全な道を作る」操作になっている
- 出口は開始ソケットでは必ず見張りに露出し、壁の影になるソケットへ切り替えると安全になるよう生成する
- 見張りは「光が当たっているマス」しか見ない。明るさと視界が同じ光源に結びついている
- 壁の影・赤い視界・残りターンを読む、短いが噛み応えのある10ターン
- 5部屋をシードから生成し、BFSソルバで解けることを保証する
- UNDOで手詰まりを組み直せる

## 構成

| ファイル | 役割 |
| --- | --- |
| `engine.js` | グリッド、光と視線、見張り、ステージ生成、BFSソルバ、ターン進行 |
| `game.js` | Canvas描画、入力、HUD、画面遷移 |
| `index.html` | HUD、開始/終了画面、方向パッド、LAMP/UNDOボタン |
| `style.css` | 光と影のUI、レスポンシブ、オーバーレイ |
| `test-engine.js` | 生成、決定性、ソルバ、移動、被発見、UNDO、タイムアウト、自動クリア |
| `test-smoke.js` | 実際の `game.js` を起動して自動プレイ |

## 設計メモ

- `engine.js` はDOMに触れない。`act(state, action)` と `undo(state)` だけで状態が進む
- 光源のマスから各マス中心へレイを飛ばし、壁を横切るマスは影にする。見張りは「光っているマス」かつ90度コーン・射程内・視線が通るマスだけを見る
- ステージ生成は「出口が見張りに露出するソケット」と「壁の影になるソケット」を必ず用意し、BFSソルバで10ターン以内に解けるまで再生成する
- 解はソルバが計算して `stage.solution` に保持し、自動プレイとテストに使う
- `window.__GAME__` の6キー（`id` / `title` / `start` / `autoPlayStep` / `isDone` / `getState`）を公開する

## テスト

universe のルートで:

```sh
./tools/run-tests.sh
```

個別:

```sh
cd projects/_labs/shade
jsc test-engine.js
jsc test-smoke.js
```

## 既知の制限

- 効果音は未実装
- 見張りは静的で、巡回はしない（光源切替と壁の影だけでパズルを作る）
- ステージはシード生成のみ。手作りの固定面やデイリーシードは未実装
- 自動プレイはソルバの解を実行するだけで、プレイヤー向けのヒント表示はない
