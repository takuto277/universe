# 月夜のミニゴルフ（night-mini-golf）

静かな夜のミニゴルフコースを、ボールのドラッグショットで攻略する1人用パットゲームです。壁やバンパーで跳ね返り、砂で減速し、水に入るとペナルティ。カップに近づいて速度が落ちると沈みます。3ホール×3コースの全9ホールで、少ない打数を目指します。

## 遊ぶ

universe のルートで `python3 -m http.server 8000` を実行し、http://localhost:8000/projects/_labs/night-mini-golf/ を開きます。

## ルール

- ボールの近くをドラッグして離すとショット。引いた方向と逆へ転がる
- 壁・バンパーで跳ね返る
- **砂**は摩擦が強く減速。**水**は1打ペナルティでティーへ戻る
- カップに近づき、速度が落ちるとカップイン
- 各ホールのPARと、コース合計のスコア（打数−PAR）を表示
- 3ホールクリアで次のコースへ。全3コース、9ホール

## 操作

- ボールの近くをドラッグして離す: ショット
- **P / Esc / 右上のポーズ**: 一時停止
- **M / 右上の♪**: BGMの消音 / 再生
- **Space / Enter**: タイトル開始 / 次コースへ / タイトルへ

## 見た目

- 月と星の夜、ネオンの縁取りをしたミニゴルフ場
- カップの旗、ボールの光、ショットの狙い線とパワー%
- バンパー、砂、水、壁のコースギミック
- カップイン時の紙吹雪、フラッシュ、花火
- スタジアム風BGM（WebAudio生成）

## ファイル構成

```text
night-mini-golf/
├── index.html      # HUD・タイトル・コースクリア・Canvas
├── styles.css      # 縦画面レイアウト、safe-area
├── engine.js       # ボール物理、壁/バンパー、砂/水、カップ、9ホール
├── audio.js        # BGMのWebAudio生成
├── game.js         # コース描画、ドラッグ、演出、コース進行
├── test-audio.js   # BGMスケジューラ・消音・停止
├── test-engine.js  # ショット、壁、水、カップ、自動プレイ
└── test-smoke.js   # 自動プレイでコースクリアまで確認
```

## 設計の要点

- **ショット**: ドラッグの逆方向に速度を与える。最大ドラッグ150、パワー6.2
- **摩擦**: 通常145/s²、砂420/s²。速度9以下で停止
- **カップ**: カップ半径内かつ速度300未満で沈む
- **コース**: 3コース×3ホール。壁、バンパー、砂、水を配置
- **自動プレイ**: テスト用にカップ方向へ直接ショットする `autoShot` を持つ

## テスト

universe のルートで:

```sh
./tools/run-tests.sh
```

個別に:

```sh
cd projects/_labs/night-mini-golf
jsc test-audio.js
jsc test-engine.js
jsc test-smoke.js
```

## 既知の制限

- 2Dトップダウンの簡易物理。傾斜や芝の向きはない
- 9ホールの固定コース。コースエディットやオンライン対戦はない
- 水は即ティー戻り。ロストボールのドロップ位置選択はない
- BGMはWebAudio生成のため、環境によって音色が多少異なる
