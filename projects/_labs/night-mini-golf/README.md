# 月夜のミニゴルフ MATCH（night-mini-golf）

CPUと交互に打つ、3Dミニゴルフ対決です。Three.jsのWebGLでコースを立体表示し、ボールの後ろからカメラを回して打つ方向を決めます。HITを長押ししてパワーを溜め、離すとショット。先にカップインした方がホールを獲得し、3ホールで先に2勝した方がコース勝利です。

## 遊ぶ

universe のルートで `python3 -m http.server 8000` を実行し、http://localhost:8000/projects/_labs/night-mini-golf/ を開きます。

## ルール

- 自分とCPUが交互にショット
- **ドラッグでカメラを回して方向を決める**
- **HITを押し続けてパワーを溜め、離すとショット**
- 壁・バンパーで跳ね返り、砂は減速、水は1打ペナルティ
- 回転バーと左右/上下に動くスライドブロックがショットを妨害
- 障害物は3Dプリミティブのプレースホルダー。画像テクスチャへ差し替え可能
- 先にカップインした方がホール獲得
- 3ホールで先に2勝した方がコース勝利
- 3コース制。コースを落とすとそのコースをやり直し
- 負けた側が次のホールの先攻

## 操作

- 画面を左右にドラッグ: カメラを回して狙う
- **HITを長押し→離す**: パワーを溜めてショット
- **A / D / ← / →**: キーボードでもカメラ回転
- **Space**: ショット開始/リリース、リザルトで次へ
- **P / Esc / 右上のポーズ**: 一時停止
- **M / 右上の♪**: BGM・効果音の消音 / 再生

## 見た目

- Three.js WebGLによる3Dコース。後方チェイスカメラでボールを見る
- カメラを回すと床・壁・バンパー・カップの位置関係が変わる
- 自分はミント、CPUはピンクのボール
- 壁・バンパー・砂・水・回転バー・スライドブロック・カップ・旗
- 障害物は今は図形のプレースホルダー（画像は後日差し替え）
- ショット、バンパー、水、カップインの効果音
- 月夜のBGM（WebAudio生成）

## 設計の要点

- **2ボール**: 自分とCPUの2球を保持し、ターンごとにアクティブ球を動かす
- **3Dカメラ**: 2Dのコース座標をXZ平面へ写し、ボール後方のカメラで追従。ヨー回転で狙いを変える
- **ショット**: カメラ前方へ、パワーに応じた速度を与える
- **CPU**: カップ方向へ軌道を計算してショット。次ホールは前ホールの敗者が先攻
- **マッチ**: 先にカップインでホール獲得。3ホール先取2でコース勝利
- **障害物**: 回転バーとスライドブロックをエンジンで動かし、3D側で同期。画像はプレースホルダー
- **3D**: Three.js 0.160.0をvendoredし、外部CDNに実行時依存しない

## 既知の制限

- コースは3コース×3ホール。コースエディット・自由視点・オンライン対戦はない
- 障害物は回転バーとスライドブロックの2種類。画像テクスチャは未使用（後で差し替え予定）
- 3Dは固定の後方チェイスカメラで、自由に歩き回る視点ではない
- CPUは直接狙うヒューリスティックAI
- ベストスコア保存はない
