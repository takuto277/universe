# ネオンスタック（neon-stack）

左右に往復するブロックを、クリック / タップ / Space の 1 ボタンで落として塔を積み上げるネオン風アーケードです。下のブロックと重なった幅だけが残り、完全に外れると終了します。中心付近で落とすと **PERFECT** になり、幅を保ったままコンボとボーナスが入ります。依存ゼロの静的ファイルだけで動きます。

## 遊ぶ

universe のルートで次を実行し、http://localhost:8000/projects/_labs/neon-stack/ を開きます。

```sh
python3 -m http.server 8000
```

## ルール

- 土台の上で次のブロックが左右に往復する。**クリック / タップ / Space** で落とす
- 落としたブロックと下のブロックが重なった幅だけが残る。ずれた分は削れて落ちる
- 重なりがほぼ 0 になったらゲームオーバー。落としたブロックもそのまま落下する
- 中心との差が「幅の 3.5%（最低 3px）」以内なら **PERFECT**
  - 幅が減らず、コンボが 1 増える
  - 得点は `10 + 10 + コンボ × 5`。連続 PERFECT ほど伸びる
- 通常の設置は 10 点。PERFECT でないとコンボは 0 に戻る
- 高さが増すほど移動速度が上がる（`205 + 高さ × 9`、最大 `520`）
- カメラは塔の頂上を追い、高く積むほど縦にスクロールする
- スコア、高さ、最大コンボ、PERFECT 数、ベストを HUD に表示
- ベストスコアは `localStorage`（キー `neon-stack-best`）に保存される

## 見た目

- ダークな背景にシアン / 紫 / マゼンタのネオングラデーション
- ブロックは積んだ高さに応じて色相が変わる
- 落下時はパーティクル、PERFECT 時は金色のパーティクルとフラッシュ、画面の揺れ
- 塔の中心にはうっすらガイド線が出て、狙いを合わせやすい
- Canvas は画面幅に追従。スマホの縦画面でも HUD とリザルトが崩れない

## ファイル構成

```text
neon-stack/
├── index.html      # 画面の骨格・遊び方・リザルト
├── style.css       # HUD・開始/終了画面・レスポンシブ
├── engine.js       # 積み上げ、重なり、PERFECT、速度、カメラ（UI非依存）
├── audio.js        # Web Audio のBGM・設置音・PERFECT音・ミス音
├── game.js         # Canvas 2D 描画、入力、エフェクト、window.__GAME__
├── test-engine.js  # ルール・重なり・PERFECT・速度・カメラのテスト
└── test-smoke.js   # 自動プレイでゲームオーバーとリザルトまで確認
```

## 設計の要点

- **判定はワールド座標**: 塔の中心を x=0、地面を y=0 とし、x は左右、y は上向き。描画側だけが `cameraY` を使って画面座標へ変換する。エンジンは Canvas に依存しない
- **重なり幅がそのまま次の幅**: 左右の重なり区間を計算し、その中央と幅を次のブロックに引き継ぐ。PERFECT のときだけ元の中心と幅を維持する
- **移動は往復**: ブロックの中心を `±FIELD_HALF` の間で反転させる。幅が縮んでも移動範囲は一定なので、終盤ほどシビアになる
- **速度は高さだけの関数**: `BASE_SPEED + 高さ × 9`。乱数を使わないのでテストが決定的
- **カメラは追従**: 頂上付近のワールド y から目標カメラ位置を出し、1 フレームごとに線形補間する。高さが増えても塔が画面外に出ない
- **音**: BPM132のAm-F-C-Gループを先読みスケジューラで鳴らし、塔の高さで音数とテンポを上げる。設置・PERFECT・ミスは個別の効果音
- **自動プレイ**: `autoPlayStep` は前半 14 回を中心付近で落として PERFECT とカメラ移動を確認し、その後わざと外して終了まで到達する

## テスト

universe のルートで実行します。

```sh
./tools/run-tests.sh
```

個別に実行する場合:

```sh
cd projects/_labs/neon-stack
jsc test-engine.js
jsc test-smoke.js
```

`jsc` が PATH にない場合は、macOS 標準の `/System/Library/Frameworks/JavaScriptCore.framework/Versions/A/Helpers/jsc` を使うか、`JSC` 環境変数で指定してください。

`test-engine.js` は初期状態、往復と範囲、PERFECT の幅維持とコンボ、ずれたときの幅・中心・コンボ、完全に外れたときの終了、許容誤差、速度上限、カメラ追従、リサイズ、リセットを検証します。`test-smoke.js` は `window.__GAME__` を自動プレイし、HUD とリザルト画面、ベスト更新まで確認します。

## 既知の制限

- BGM・効果音はWeb Audioで生成し、端末の音量設定に依存する
- ブロックの幅は 1 次元の重なりだけで判定する。回転や物理演算はない
- 保存はブラウザごと。シークレットモードでは消える
- 画面が極端に横長だと、塔の左右の余白が広く見える
