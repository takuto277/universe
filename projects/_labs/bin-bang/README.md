# BIN BANG

ゴミ箱型キャノンで、降ってくるゴミの嵐を撃ち抜く60秒のネオンシューターです。UIは英語のみです。

- **移動** — 画面ドラッグ / 矢印キー / A・D
- **射撃** — ゴミ箱のフタが自動で連射
- **BANG** — Space / 画面右下のボタンで扇状のゴミブラスト
- **60秒** — スコア、撃破数、最大コンボを競う。ベストスコアはローカル保存

## 遊び方

1. **OPEN FIRE** を押す。
2. ゴミ箱を左右に動かして、落ちてくるゴミに弾を当てる。
3. ゴミが下に抜けるか、ゴミ箱にぶつかるとライフが1減る。ライフは3。
4. BANGはクールダウン付きの広範囲ブラスト。囲まれたときに使う。
5. 連続撃破でコンボが伸び、12ヒット相当でゲージが満タンになると **OVERDRIVE**。連射速度と弾の威力が上がる。
6. 36秒で巨大なボスが出現。60秒生き残れば結果画面。

## ルール

- 60秒、ライフ3。ライフ0または時間切れで終了。
- 通常弾は自動連射。BANGは9発の扇状ショットで、クールダウン2.2秒。
- ゴミの種類: 袋、瓶、缶（HP3）、爆弾、金のゴミ、ボス。
- コンボは最後の撃破から2.6秒で切れる。5コンボごとにスコア倍率が上がる。
- OVERDRIVE中はスコア2倍、連射間隔が約半分、弾の威力が2になる。
- 撃破時にパーティクル、衝撃波リング、スコアポップ、画面シェイク、フラッシュが発生。
- ベストスコアは `localStorage` に保存。

## 見た目と音

- 暗い路地にネオンサイン、遠景のビル、ゴミ箱の列。プレイフィールドは縦長。
- プレイヤーのゴミ箱はフタが開いたキャノン。体温ならぬオーバードライブで発光。
- 敵は袋・瓶・缶・爆弾・金のゴミ・巨大ボスで、それぞれ色と形が違う。
- 弾は白熱したトレイル、撃破は粒子とリング、コンボはHUDで発光。
- WebAudioで射撃、ヒット、爆発、BANG、被弾、OVERDRIVE、ボス、終了音と簡易ビートを生成。外部音源なし。

## ファイル構成

```text
bin-bang/
├── index.html        # HUD・開始/結果画面・BANGボタン
├── style.css         # ネオンHUD・オーバーレイ・縦パネル
├── engine.js         # 射撃、敵、衝突、コンボ、OVERDRIVE、ボス、60秒
├── audio.js          # WebAudioの効果音とビート
├── renderer.js       # Canvasの路地・ゴミ箱・敵・弾・粒子・リング
├── game.js           # 入力、描画ループ、HUD、ベスト保存、window.__GAME__
├── test-engine.js    # 射撃・BANG・被弾・時間切れ・自動プレイ
└── test-smoke.js     # 60秒自動プレイと結果画面
```

## 設計の要点

- **移動と射撃の分離**: 移動はドラッグ/キー、射撃は自動。BANGだけ能動的な緊急手段にして、スマホで片手でも遊べるようにした。
- **コンボとOVERDRIVE**: 撃破を続けるほどスコア倍率が上がり、ゲージ満タンで連射と威力が強化される。撃たれ続けるだけでなく、当て続ける動機を作る。
- **派手さを状態から作る**: 画面シェイク、フラッシュ、パーティクル、リング、ポップアップをエンジン状態に持たせ、rendererはそれを描くだけにした。
- **決定的な自動プレイ**: 乱数はLCGで固定。`autoPlayStep()` は最も下の敵に照準を合わせ、必要ならBANGを撃つ。スモークテストとサムネイル生成に使う。

## テスト

```sh
cd projects/_labs/bin-bang
jsc test-engine.js
jsc test-smoke.js
```

`test-engine.js` は自動射撃、BANGの扇状弾とクールダウン、移動、被弾、時間切れ、自動プレイのスコアを検証します。`test-smoke.js` は60秒の自動プレイで結果画面とスコア表示が出ることを確認します。リポジトリ全体では `./tools/verify.sh` です。

## 既知の制限と次に試すこと

- 実機でのドラッグ操作と、BANGボタンの押しやすさを確認する。
