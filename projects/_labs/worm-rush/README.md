# WORM RUSH

AIミミズと餌を奪い合う、オフラインio風のミミズゲームです。

## 遊び方

- ドラッグ、または WASD / 矢印キーで移動
- 光る餌を食べると体が伸びてスコアが増える
- DASH / Shift / Spaceで加速。ただし体が短くなる
- 敵の体に頭をぶつけるとゲームオーバー
- 相手の頭に自分の体をぶつけると撃破
- 倒したAIは数秒後に復活し、常に敵がいる状態になる

## 見どころ

- 広い円形アリーナとカメラ追従
- 最大10匹のAIミミズ。餌探し・回避・プレイヤー追跡
- AI死亡から約2〜3秒で復活
- ミニマップ、リーダーボード、キルフィード
- スマホのドラッグ操作とDASHボタン
- ネオン描画、パーティクル、被弾・撃破の演出

## 構成

| ファイル | 役割 |
| --- | --- |
| `engine.js` | 移動、体、餌、AI、当たり判定、復活、スコア |
| `game.js` | Canvas描画、カメラ、入力、HUD、ミニマップ |
| `index.html` | HUD、開始/終了画面、DASHボタン |
| `style.css` | ネオンUI、レスポンシブ、開始/終了画面 |
| `test-engine.js` | 移動、成長、ブースト、AI復活、死亡 |
| `test-smoke.js` | 自動操作でしばらくプレイ |

## テスト

universe のルートで:

```sh
./tools/run-tests.sh
```

個別:

```sh
cd projects/_labs/worm-rush
jsc test-engine.js
jsc test-smoke.js
```
