# PRISM

ミラーを回して光をシグナルへ届ける、1画面の光パズルです。キャラクター画像を使わず、光線・ミラー・発光をすべて Canvas のコードで描いています。

## 遊び方

- START で開始
- 盤面のミラーをタップすると 45 度ずつ向きが変わる
- 光はエミッターから出て、ミラーで反射し、壁で遮られる
- すべてのシグナルに光が当たるとレベルクリア。全5レベル

## 構成

| ファイル | 役割 |
| --- | --- |
| `engine.js` | グリッド、光線追跡、ミラー回転、レベル定義、ソルバー |
| `renderer.js` | Canvas描画（光線・ミラー・シグナル・発光・パーティクル） |
| `game.js` | 入力、HUD、画面遷移、`window.__GAME__` |
| `index.html` | 画面の骨格 |
| `style.css` | 見た目 |
| `test-engine.js` | ロジックと全レベルの可解性テスト |
| `test-smoke.js` | 自動プレイのスモークテスト |

## 設計メモ

- 盤面は 9×13 のグリッド。光はセル単位で進み、ミラーで反射する。`/` は `(dx,dy) -> (-dy,-dx)`、`\` は `(dx,dy) -> (dy,dx)`
- レベルは `engine.js` の `LEVELS` にデータとして持つ。ミラーの初期向きは未解状態にしてある
- `solve()` は回転可能なミラーの向きを全探索して解を返す。テストと自動プレイで使う。状態は変更しない
- 描画は発光を `globalCompositeOperation = 'lighter'` の重ね塗りで表現し、光線は線幅違いの3回描画＋破線アニメで流れを出す
- 画面は論理座標 390×844 をレターボックスし、入力を `screenToWorld` で逆変換する

## テスト

```sh
./tools/run-tests.sh
```

個別:

```sh
cd projects/_labs/prism/
jsc test-engine.js
jsc test-smoke.js
```

## 既知の制限

- レベルは5つの固定データ。追加・調整は `engine.js` の `LEVELS` を編集する
- 斜めビームとミラーの角での衝突は考慮していない（セル単位の追跡）
- 効果音は未実装
