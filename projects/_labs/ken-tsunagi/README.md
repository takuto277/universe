# けんつなぎ（ken-tsunagi）

47都道府県の形をしたピースを箱に落とし、隣り合う県同士をくっつけて日本列島を完成させる、スマホ縦画面向けの落ちものパズルです。県は重力で落ちて積もり、県境が触れると地図どおりの位置にぴたっと合体します。47県を落としたあと60秒以内に完成させるとクリアです。依存ゼロの静的ファイルだけで動きます。

## 遊ぶ

universe のルートで次を実行し、http://localhost:8000/projects/_labs/ken-tsunagi/ を開きます。

```sh
python3 -m http.server 8000
```

## ルール

- 画面の箱を左右にドラッグして、指を離すと県が落ちる。箱をタップしても落とせる
- 県は重力で落下し、床・壁・他の県とぶつかって積もる
- **隣り合う県**の県境が触れると合体し、地図どおりの位置に固定される
- 隣り合わない県同士は合体せず、そのまま積もる
- 47都道府県を落としきると **60秒タイマー** がスタート
- 47県がすべて1つにつながると **日本列島 完成**
- 箱から県があふれる、または60秒が過ぎると **ゲームオーバー**
- 海をこえる接続（北海道〜青森、岡山〜香川、広島〜愛媛、山口〜福岡、兵庫〜徳島、鹿児島〜沖縄）は「橋」としてつながる
- ヒントは3回。現在の県を落とすべきX位置を光らせる
- ゆらすは3回。箱の中の県を軽く揺らして崩せる
- 合体、地方完成、クリアでスコア加算。ベストスコアと最速タイムを `localStorage`（キー `ken-tsunagi-best`）に保存

## 操作

- 箱をドラッグ → 離してドロップ
- 箱をタップ → その位置へドロップ
- **← / →**: 現在の県を左右に移動
- **Space / Enter**: ドロップ（タイトル・リザルトでは開始）
- **H**: ヒント
- **X**: ゆらす
- **P / Esc / 右上のポーズ**: 一時停止と再開
- 画面外に出る、タブを隠す、ウィンドウをフォーカスから外すと自動でポーズ
- ピンチズーム、ダブルタップズーム、長押しメニューを抑制

## 見た目

- 深い藍色の箱に、海のグリッドとコンパス円
- 県は実際の形・地方カラーで描画され、合体すると日本地図が組み上がっていく
- 合体時のパーティクル、地方完成バナー、クリア時の紙吹雪
- 上部HUDにスコア、60秒タイマー、現在の最大連結数を表示
- 下部に次の県、ヒント、ゆらす、残り県数を表示
- safe-area、縦画面、PCの横長画面に対応

## ファイル構成

```text
ken-tsunagi/
├── index.html      # HUD・タイトル・リザルト・Canvas
├── styles.css      # 縦画面レイアウト、safe-area、オーバーレイ
├── data.js         # 47都道府県の形・地方・隣接・当たり判定用の円
├── engine.js       # 落下・衝突・隣接合体・スコア・タイマー・ヒント
├── game.js         # Canvas描画、ドラッグ、HUD、window.__GAME__
├── test-engine.js  # ルール・物理・合体・タイマー・クリアのテスト
└── test-smoke.js   # 自動プレイで47県クリアまで確認
```

## 設計の要点

- **実際の県形状**: 描画は Natural Earth の行政区分形状。当たり判定は県ごとに生成した複数の円で近似する
- **位置合わせ**: 合体時は基準県の地図座標を保ち、相手県を地図上の正しい相対位置へスナップする。向きは常に地図と同じ上向き
- **合体判定**: 隣接リスト（陸続き＋橋）と衝突円の近接で判定。隣接していない県は物理的にぶつかるだけ
- **連結クラスタ**: 合体後の県は1つの剛体として落下・衝突する。質量は構成県の面積と数で増える
- **箱あふれ**: どのクラスタの上端も箱の上端を超えた状態が0.5秒続くと終了
- **60秒ルール**: 47県を落とし終えるまでタイマーは動かず、最後の県を落とした時点から60秒
- **自動プレイ**: `window.__GAME__.autoPlayStep` は現在の県を正しいX位置へ移動して落とし、47県クリアまで進む

## テスト

universe のルートで実行します。

```sh
./tools/run-tests.sh
```

個別に実行する場合:

```sh
cd projects/_labs/ken-tsunagi
jsc test-engine.js
jsc test-smoke.js
```

`test-engine.js` は47県・8地方、隣接/非隣接の合体、地方完成、ヒント、ゆらす、60秒タイマー、箱あふれ、47県クリア、ポーズを検証します。`test-smoke.js` は `window.__GAME__` を自動プレイし、HUD・クリア画面・ベストスコア・クリアタイムを確認します。

## 地図データ

都道府県の形状は [Natural Earth](https://www.naturalearthdata.com/) の 1:10m Admin 1 States/Provinces（パブリックドメイン）を基に、ゲーム用に簡略化・正規化したものです。国境・県境の正確な行政データではありません。海をこえる接続はゲーム進行のためのブリッジとして扱っています。

## 既知の制限

- 県ピースは回転しない（常に地図と同じ上向き）
- 衝突判定は県形状を複数の円で近似しているため、見た目と当たり判定が完全には一致しない
- 効果音・BGMはない
- ステージは1種類。地方別ステージや鬼畜モードはない
- 保存はブラウザごと。シークレットモードでは消える
