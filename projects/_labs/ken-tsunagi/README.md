# けんつなぎ（ken-tsunagi）

実際の形の47都道府県ピースを地図の正しい場所へ置き、日本地図を完成させるスマホ縦画面向けパズルです。地方タブから県を選び、ドラッグまたはタップで配置します。隣り合う県がつながるほどコンボとボーナスが伸び、地方完成で+500。180秒のタイムアタックです。依存ゼロの静的ファイルだけで動きます。

## 遊ぶ

universe のルートで次を実行し、http://localhost:8000/projects/_labs/ken-tsunagi/ を開きます。

```sh
python3 -m http.server 8000
```

## ルール

- 制限時間は **180秒**。47都道府県すべてを地図に置くと **GAME CLEAR**
- 地方タブ（北海道 / 東北 / 関東 / 中部 / 近畿 / 中国 / 四国 / 九州・沖縄）でピースを絞り込む
- ピースを地図の正しい位置へ **ドラッグ**。ピースをタップして選び、地図をタップしても置ける
- 正しい位置ならピースが固定される。周囲の配置済み県と隣接していれば「つながった」ボーナス
- 間違った位置に落とすと **-2秒**、コンボはリセット。ピースは消えない
- 地方の全都道府県を置くと **+500**、コンボも継続
- ヒントは1ラン3回。選択中の県（未選択なら現在の地方の先頭）の正しい場所を光らせる
- 残り時間が0になると **TIME UP**
- スコア、ベストスコア、最速クリアタイムを `localStorage`（キー `ken-tsunagi-best`）に保存

## 操作

- タップ / クリック: ピース選択、地方タブ切り替え、ヒント
- ドラッグ: ピースを地図へ移動
- **P / Esc / 右上のポーズ**: 一時停止と再開
- **H**: ヒント
- 画面外に出る、タブを隠す、ウィンドウをフォーカスから外すと自動でポーズ
- スマホのピンチズーム、ダブルタップズーム、長押しメニューを抑制

## 見た目

- 深い藍色の地図台に、淡い海のグリッドとコンパス円
- 未配置の県は地方カラーで薄く表示。選択中の地方だけ輪郭を強める
- 配置済みの県は実色で塗られ、日本地図が少しずつ完成していく
- 地方完成時はバナー、正解時はパーティクルとポップアップ
- クリア時は紙吹雪と、完成した日本地図の上にリザルトを表示
- safe-area、縦画面、PCの横長画面に対応

## ファイル構成

```text
ken-tsunagi/
├── index.html      # HUD・タイトル・リザルト・Canvas
├── styles.css      # 縦画面レイアウト、safe-area、オーバーレイ
├── data.js         # 47都道府県の形状・地方・隣接・配置座標
├── engine.js       # 配置判定、スコア、タイマー、ヒント、地方完成
├── game.js         # Canvas描画、ドラッグ、HUD、window.__GAME__
├── test-engine.js  # ルール・スコア・タイマー・クリアのテスト
└── test-smoke.js   # 自動プレイで47県クリアまで確認
```

## 設計の要点

- **実形状の当たり判定**: 都道府県ごとの代表点（重心）とスナップ許容距離で配置を判定。ドラッグ中は実際の形を地図スケールで表示する
- **地方フィルタ**: 一度に47ピースを探さず、8地方に絞って選べる。地方が埋まると次の未完成地方へ自動で進む
- **隣接ボーナス**: 地図形状から生成した隣接リストを使い、配置済みの隣県1つにつき+40
- **得点**: `100 + コンボボーナス + 隣接ボーナス + 地方完成500`。クリア時に残り秒数×20
- **失敗**: 位置が違えば時間を2秒失うが、ピースは失わない。コンボだけリセット
- **自動プレイ**: `window.__GAME__.autoPlayStep` は現在の地方のピースを正しい位置へ置き、47県クリアまで進む
- **形状データ**: Natural Earth 1:10m Admin 1 States/Provinces（パブリックドメイン）を間引き・正規化して同梱。実行時に外部通信しない

## テスト

universe のルートで実行します。

```sh
./tools/run-tests.sh
```

個別に実行する場合:

```sh
cd projects/_labs/ken-tsunagi
jsc test-engine.js
jsc test-smoke.js
```

`test-engine.js` は47県・8地方、正解/不正解、隣接・コンボ・地方完成ボーナス、ヒント3回、地方フィルタ、タイマー切れ、47県クリア、ポーズを検証します。`test-smoke.js` は `window.__GAME__` を自動プレイし、クリア画面、HUD、ベストスコア、クリアタイムを確認します。

## 地図データ

都道府県の形状は [Natural Earth](https://www.naturalearthdata.com/) の 1:10m Admin 1 States/Provinces（パブリックドメイン）を基に、ゲーム用に簡略化・正規化したものです。国境・県境の正確な行政データではありません。

## 既知の制限

- 効果音・BGMはない
- ステージは1種類。地方ごとの難易度変更や鬼畜モードはない
- 地図の拡大・縮小、回転はできない
- 保存はブラウザごと。シークレットモードでは消える
- 沖縄や離島は、画面に収めるため一部の小島を省略している
