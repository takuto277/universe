# 音の家（oto-no-ie）

目が見えない住人に、鈴の音で帰り道を教える、スマホ縦画面向けの音響パズルです。部屋に最大3つの鈴を置き、住人が聞こえた鈴へ順番に歩いていくように音の道を作ります。壁と閉じた扉は音を遮り、ガラスは音だけを通します。最後の鈴のあと、出口の鐘が届けばクリアです。依存ゼロの静的ファイルだけで動きます。

## 遊ぶ

universe のルートで次を実行し、http://localhost:8000/projects/_labs/oto-no-ie/ を開きます。

```sh
python3 -m http.server 8000
```

## ルール

- 住人は **音が聞こえた方向へ歩く**。プレイヤーは直接動かせない
- 部屋に置ける鈴は最大3つ。置いた順番に鳴る
- 鈴の音は **3マス**まで届く（壁・閉じた扉は遮る。開いた扉は通す）
- **ガラス**は音を通すが、住人は通れない
- 住人は、聞こえた鈴まで歩く。次の鈴が届かないと立ち止まる
- 最後の鈴のあと、**出口の鐘**が聞こえれば、住人は出口へ歩いてクリア
- 全5室。失敗したら鈴を置き直してやり直せる
- WebAudioによる鈴・失敗・クリア音つき。`M` で消音

## 操作

- 下の **鈴スロット1〜3** をタップして選択
- 光っている部屋のマスをタップして鈴を置く
- 置いた鈴をタップすると外せる
- **音を鳴らす**: 住人が音をたどって歩く
- **鈴をけす**: すべての鈴を外す
- **Space / Enter**: 音を鳴らす / 次の部屋へ / やりなおす
- **1 / 2 / 3**: 鈴スロットを選択
- **R**: 音を鳴らす
- **P / Esc / 右上のポーズ**: 一時停止と再開
- 画面外に出る、タブを隠す、ウィンドウをフォーカスから外すと自動でポーズ
- ピンチズーム、ダブルタップズーム、長押しメニューを抑制

## 見た目

- 暗い家の設計図に、海のような青い床グリッド
- 壁は厚いブロック、閉じた扉は赤いX、開いた扉は金色のアーチ、ガラスは斜線入りの透明パネル
- 鈴を選ぶと、音が届くマスが淡く光る
- 住人は白杖と目隠しをつけ、音を聞くときは波紋が広がる
- 実行中は鈴の波紋、歩いた軌跡、出口の灯りを表示
- safe-area、縦画面、PCの横長画面に対応

## ファイル構成

```text
oto-no-ie/
├── index.html      # HUD・タイトル・部屋クリア・失敗・エンディング
├── styles.css      # 縦画面レイアウト、safe-area、オーバーレイ
├── data.js         # 5つの部屋のグリッドと解答
├── engine.js       # 音のBFS、移動経路、鈴の順番、クリア判定
├── game.js         # Canvas描画、タップ操作、音、window.__GAME__
├── test-engine.js  # 音・移動・扉・ガラス・レベル進行のテスト
└── test-smoke.js   # 自動プレイで全5室クリアまで確認
```

## 設計の要点

- **音と移動を別々にBFS**: 音は `ガラス` を通れるが、移動は通れない。壁と閉じた扉は両方を遮る
- **鈴の順番**: 置いたスロット順に、住人が現在地から聞こえるか・歩けるかを判定する
- **出口の鐘**: 最後の鈴の位置から出口の音が3マス以内で聞こえ、移動経路があればクリア
- **失敗理由**: 音が届かない / 歩けない / 出口の鐘が届かない を分けて表示
- **自動プレイ**: `window.__GAME__.autoPlayStep` は各部屋の解答を置いて実行し、全5室を進む
- **音**: WebAudioの短いサイン波のみ。外部音源なし

## テスト

universe のルートで実行します。

```sh
./tools/run-tests.sh
```

個別に実行する場合:

```sh
cd projects/_labs/oto-no-ie
jsc test-engine.js
jsc test-smoke.js
```

`test-engine.js` は5部屋のデータ、音の届く範囲、ガラス越しの聴取、閉じた扉、鈴の順番、出口判定、失敗、再試行、全室クリアを検証します。`test-smoke.js` は `window.__GAME__` を自動プレイし、HUDとエンディング到達を確認します。

## 既知の制限

- 音はグリッドBFSの距離で扱う。反射・回折・残響はない
- 扉の開閉は固定。プレイヤーが動かせるのは鈴だけ
- ステージは5室。レベルセレクトや保存はない
- 効果音はWebAudioのみ。環境によっては鳴らない
