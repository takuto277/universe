# DEBT

**5日間で借金を返す経済ゲームです。** 強化を借りて買い、日利10〜20%に耐えます。最終日に現金が借金を上回れば勝ち。残金がスコアです。

「資源は増やすもの」という前提を壊し、**前借りして育てる**ことを遊びにしています。借りるほど金利が上がるので、増やす額と返す額のバランスが勝負です。

## 遊び方

1. **オファーを買う** — 1日4件。現金が足りなければ、その場で借金になります。買った資産は毎日売上を生みます。
2. **利息に注意** — 日を終えるたびに借金へ利息。借金が枠に対して多いほど金利が10%から20%へ上がります。
3. **返済する** — `-50` / `-200` / `ALL` で現金から返済。返済すると利息と借金が減ります。
4. **日を終える** — 売上を受け取り、利息を借金に足して翌日へ。DAY 5 の終了で決済です。
5. **決済** — 現金が借金以上なら、借金を返して残金がスコア。足りなければデフォルト（E）。

キーボード: `1`〜`4` で購入、`E` / `Enter` で日を終える、`R` で全額返済。

## 市場とイベント

- 初日は平常運転。2日目以降は毎日イベントが変わります。
- 例: グルメブーム（FOOD 1.6倍）、長雨（STREET 0.6倍）、テック相場（TECH 1.8倍）、景気後退（全体 0.8倍）。
- オファーは価格と売上にばらつきがあり、ROIは約25〜65%の範囲で変動します。
- 画面には「回収日数」を表示します。残り日数より長いオファーは、買うと損をしやすいです。

## 金利とスコア

- 金利 = 10% + 10% ×（借金 / 借入枠）。借入枠は700。
- 利息は終了時に `ceil(借金 × 金利)` で加算されます。
- クリア時のスコア = 決済後の残金。ランクは S（1000以上）/ A（750）/ B（550）/ C（300）/ D。デフォルトは E。
- 自己ベストは `localStorage` に保存されます。

## 設計の要点

- **借りるほど金利が上がる**: 金利を借金/枠の線形関数にしたことで、全力で借りるほど利ざやが薄くなります。増やすか返すかの判斷に意味が出ます。
- **必要ROIでオファーを評価**: 残り日数と金利から「借金を償却するのに必要なROI」を計算できます。終盤のオファーが割高になる理由を数字で示せます。
- **回収日数**: 額面のROIに加えて「何日で元が取れるか」を表示し、残り日数と比較できるようにしました。これが終盤の罠を見抜く手がかりです。
- **シード固定**: オファーとイベントはシードから再現できるため、テストで同じ展開を検証できます。
- **自動プレイ**: `autoStep` は必要ROIと借入枠を見て序盤に買い、終盤は返済に寄せて決済します。破綻せず完走する基準として使っています。


リポジトリ全体では `./tools/verify.sh` です。

## 既知の制限

- 資産の売却はできません。終盤のオファーは「買わない」判斷が基本になります。
- イベントは日単位の倍率のみで、資産ごとの固有イベントはありません。
- 難易度は固定。借入枠・金利・日数は `engine.js` の定数で調整できます。
- ランキングはローカルの自己ベストのみです。
