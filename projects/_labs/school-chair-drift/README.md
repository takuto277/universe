# 放課後チェア・グランプリ（school-chair-drift）

放課後の日本の校舎を舞台にした、オフィスチェアの3D風レースです。1F昇降口の下駄箱、教室の扉、廊下の窓、階段表示、2F特別教室、3F渡り廊下を描き、自分＋CPU3台の4人で各フロア3周を走ります。後方チェイスカメラで廊下を駆け抜け、ドリフトでミニターボを溜め、アイテムボックスから出るミルク・消しゴム・給食トレイで順位を狙います。各コース1位で次へ進み、3コース制覇でENDINGです。

## 遊ぶ

universe のルートで `python3 -m http.server 8000` を実行し、http://localhost:8000/projects/_labs/school-chair-drift/ を開きます。

## ルール

- 椅子は自動で前進。**画面を左右にドラッグ**すると曲がる。離すと直進
- 曲がりながら自動ドリフト。ドリフトゲージMAXでミニターボ
- CPU3台と4人レース。各コース**3周**
- アイテムボックスからアイテムを取得
  - **ミルク**: 一定時間加速
  - **消しゴム**: 後方に落として相手をスピンさせる
  - **給食トレイ**: 一度だけ消しゴムを防ぐシールド
- **1位でゴール**すると次のコースへ。3コース制覇でENDING
- 1位以外、またはタイムアップ時はリトライ

## 操作

- 画面を左右にドラッグ: ステアリング
- **I / アイテムボタン**: アイテム使用
- **A / D / ← / →**: キーボードでもステアリング
- **P / Esc / 右上のポーズ**: 一時停止
- **M / 右上の♪**: BGMの消音 / 再生
- **Space / Enter**: タイトル開始 / リザルトで再戦 / 次コースへ

## 見た目

- Canvasによる**疑似3Dの後方チェイスカメラ**。奥行きに合わせて廊下・壁・障害物・対戦相手を投影
- 1F昇降口の下駄箱、教室の扉、廊下の窓、階段表示、2F特別教室、3F渡り廊下
- 学校の廊下、ロッカー、机、給食ワゴン、消しゴム、アイテムボックス
- オフィスチェアのキャスター、座面、背もたれ、乗っている生徒
- ドリフトゲージ、順位、ラップ、アイテムボタン
- ミニターボ、クラッシュ、アイテム使用、ゴールの紙吹雪・花火
- スタジアム風BGM（WebAudio生成）

## ファイル構成

```text
school-chair-drift/
├── index.html      # HUD・タイトル・リザルト・Canvas
├── styles.css      # 縦画面レイアウト、safe-area、アイテムボタン
├── engine.js       # 4人レース、3周、アイテム、CPU AI、疑似3D用のコースデータ
├── audio.js        # BGMのWebAudio生成
├── game.js         # 後方チェイス描画、入力、演出、コース遷移
├── test-audio.js   # BGMスケジューラ・消音・停止
├── test-engine.js  # ステアリング、アイテム、ラップ、順位、ゴール
└── test-smoke.js   # 自動走行でレース終了まで確認
```

## 設計の要点

- **疑似3D**: ワールド座標（コース上の距離s・横位置x）を透視投影し、床・壁・障害物・他レーサーを奥行き順に描画。WebGLや外部3Dライブラリは使わない
- **コースループ**: コース長でラップを管理。3周でフィニッシュ
- **レースAI**: CPU3台がコース中心＋車線オフセットを追従。プレイヤーとの差に応じた軽いラバーバンド、アイテム自動使用
- **アイテム**: アイテムボックスは共有クールダウン。ミルク=ブースト、消しゴム=後方トラップ、トレイ=シールド
- **ドリフト**: 横速度と操舵量から自動判定。ゲージMAXで短時間ブースト

## テスト

universe のルートで:

```sh
./tools/run-tests.sh
```

個別に:

```sh
cd projects/_labs/school-chair-drift
jsc test-audio.js
jsc test-engine.js
jsc test-smoke.js
```

## 既知の制限

- 3DはCanvasの疑似3D。自由視点・本格的な3D物理・モデリングはない
- 校舎は3フロアのレースコースとしての再現で、教室内部への自由侵入や校舎全体の散策はできない
- コースは3本。分岐やショートカットはない
- CPUはヒューリスティックAI。オンライン対戦・ゴースト・ランキングはない
- 1位以外は次コースへ進めない
- BGMはWebAudio生成のため、環境によって音色が多少異なる
