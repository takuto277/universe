# 放課後チェア・ドリフト（school-chair-drift）

放課後の校舎を、オフィスチェアで滑り抜けるタイムアタックです。椅子は自動で前進し、画面を左右にドラッグすると曲がります。曲がりながら自然にドリフトし、ゲージがMAXになると自動ブースト。机やロッカー、バケツ、給食ワゴンを避けながら、制限時間内に校門を目指します。

## 遊ぶ

universe のルートで `python3 -m http.server 8000` を実行し、http://localhost:8000/projects/_labs/school-chair-drift/ を開きます。

## ルール

- 椅子は自動で前進する
- **画面を左右にドラッグ**すると曲がる。指を離すと直進
- 曲がりながら自動でドリフト。ドリフトゲージMAXで自動ブースト
- 机・ロッカー・バケツ・給食ワゴンに当たると減速
- 給食のミルクを取ると**残り時間+1.4秒**
- 3つのフロアを制限時間内にゴールする
- 時間切れはやり直し。全フロアクリアでENDING

## 操作

- 画面を左右にドラッグ: ステアリング
- 指を離す: 直進
- **A / D / ← / →**: キーボードでもステアリング
- **P / Esc / 右上のポーズ**: 一時停止
- **M / 右上の♪**: BGMの消音 / 再生
- **Space / Enter**: タイトル開始 / リザルトで再戦 / 次フロアへ

## 見た目

- 奥に続く校舎の廊下、ロッカー、教室のドア、給食ワゴン
- ネオンの廊下ラインと、ドリフト時のスキッドマーク
- オフィスチェアの5輪キャスター、座面、背もたれ、乗っている生徒
- スピード、残り時間、ステージ進捗、ドリフトゲージ
- ミルク取得、クラッシュ、ドリフトブースト、ゴールの紙吹雪・花火
- スタジアム風BGM（WebAudio生成）

## ファイル構成

```text
school-chair-drift/
├── index.html      # HUD・タイトル・リザルト・Canvas
├── styles.css      # 縦画面レイアウト、safe-area、オーバーレイ
├── engine.js       # 椅子物理、コース、障害物、ミルク、タイマー
├── audio.js        # BGMのWebAudio生成
├── game.js         # 廊下描画、ドラッグ操作、演出、ステージ遷移
├── test-audio.js   # BGMスケジューラ・消音・停止
├── test-engine.js  # ステアリング、壁、ミルク、ゴール、タイムアップ
└── test-smoke.js   # 自動走行でステージクリアまで確認
```

## 設計の要点

- **自動前進**: 前方向の速度はステージごとに加速し、最大速度へ近づく
- **ドラッグステア**: ドラッグ開始点からの横移動を操舵量に変換。離すと舵0
- **ドリフト**: 横速度と操舵量が一定以上でドリフト状態。横摩擦を下げ、ゲージを溜める
- **ブースト**: ドリフトゲージMAXで自動発動。一定時間最大速度が上がる
- **コース**: ワールドYに対してサインカーブする廊下。左右の壁、机/ロッカー/バケツ/ワゴン、ミルクを配置
- **タイム**: 各ステージの制限時間から減算。ミルクで加算。ゴールで残り時間を確定

## テスト

universe のルートで:

```sh
./tools/run-tests.sh
```

個別に:

```sh
cd projects/_labs/school-chair-drift
jsc test-audio.js
jsc test-engine.js
jsc test-smoke.js
```

## 既知の制限

- 2Dトップダウンの簡易物理。椅子の回転慣性やサスペンションはない
- コースは縦方向の一本道。分岐や周回レースはない
- CPU対戦・ゴースト・ランキングはない
- BGMはWebAudio生成のため、環境によって音色が多少異なる
