# TRASH TOSS

固定カメラのリビングで、動き回るゴミ箱へゴミを投げ入れる30秒の3D風トスゲームです。UIは英語のみです。

- **スワイプ** — 上方向へドラッグして投げる
- **長さ** — 長いスワイプほど奥へ飛ぶ
- **左右** — スワイプの横方向で左右を狙う
- **30秒** — 投げ放題。入った数とPERFECT数を競う

## 遊び方

1. **START TOSSING** を押す。
2. 画面を上方向へスワイプする。スワイプ中はゴミの軌道と着地点が表示される。
3. スワイプの長さで前後、横方向で左右が決まる。
4. ゴミ箱の開口部に入れば **IN**。中央なら **PERFECT**。
5. 15秒を過ぎるとゴミ箱が前後にも動き始める。
6. 30秒で終了。IN数、投げ数、命中率、PERFECT数、最大ストリークを表示。

## ルール

- 制限時間30秒。投げ数は無制限。連投は0.22秒の間隔。
- ゴミ箱は左右にランダム移動。15秒以降は前後にもランダム移動。
- 入った判定は、着地点とゴミ箱の中心の距離。開口部半径の82%以内でIN、24%以内でPERFECT。
- 入るたびにストリークが伸び、外すと0に戻る。
- ベストIN数は `localStorage` に保存。
- カメラは投げ手の後ろに固定。

## 見た目と音

- リビングのソファ、テレビ、観葉植物、ランプ、ラグ、木の床をCanvasの疑似3Dで描画。
- 投げ手の手元とゴミ袋を画面下に表示。ゴミ箱は奥行きに応じて大小が変わる。
- スワイプ中は点線の放物線と着地点リングを表示。
- ゴミ箱は開口部の金色の縁、目、影で位置を読みやすくする。
- WebAudioで投げる音、IN、PERFECT、ミス、前後移動開始、終了音を生成。

## 設計の要点

- **3D座標でゲーム、描画は疑似3D**: x（左右）、y（高さ）、z（奥行き）で投擲と箱を管理し、固定カメラの透視投影でCanvasに描く。Three.jsなどの依存はない。
- **スワイプをそのまま3Dに変換**: `dx` を左右、スワイプ長を奥行きにマップ。着地点までの放物線はエンジンが計算し、プレビューと実際の投擲で同じ軌道を使う。
- **箱のランダム移動**: 左右は最初から、前後は15秒から。箱が動く間に着地点を選ぶため、単なる座標合わせではなく先読みが要る。
- **投げ放題＋クールダウン**: 30秒という短い制限の中で、連投のテンポと正確さのバランスを取る。
- **結果を数で見せる**: IN数、投げ数、命中率、PERFECT、最大ストリークを同時に出す。

## テスト

```sh
cd projects/_labs/trash-toss
jsc test-engine.js
jsc test-smoke.js
```

`test-engine.js` はスワイプの左右・長さ、軌道プレビュー、IN/PERFECT、ミス、15秒の前後移動、30秒終了、自動プレイを検証します。`test-smoke.js` は30秒の自動プレイで結果画面が出ることを確認します。リポジトリ全体では `./tools/verify.sh` です。

## 既知の制限と次に試すこと

- リビングは図形の雰囲気のみ。画像・テクスチャ・BGMは未実装。
- 箱の動きは等速の追従で、イージングやフェイントはまだない。
- リムに当たって跳ねる物理、風、複数箱、難易度選択は未実装。
- 本物のWebGLにはしていない。固定カメラなので疑似3Dで十分だが、家具の3Dモデルや照明を入れるならWebGL化の価値がある。
- 実機でスワイプの長さと奥行きの対応が分かりやすいか確認する。
