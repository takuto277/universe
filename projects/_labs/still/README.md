# STILL

見下ろしの小部屋を抜ける、時間停止シューティングです。**時間はプレイヤーが動いた量に比例して進み、止まれば弾も敵も止まります。** 1発被弾で終了。60秒で3つの部屋を抜けます。

## 遊び方

1. **動く** — WASD / 矢印キー、または画面左側のドラッグで移動します。移動している間だけ世界の時間が進みます。
2. **止まる** — 入力を止めると時間も止まります。敵の弾が止まって見えるので、次の動きを考えられます。ただし制限時間は止まりません。
3. **狙う・撃つ** — マウスで照準、クリック / Spaceで射撃（押しっぱなしで連射）。スマホは画面右側のドラッグで照準と射撃です。
4. **敵を全滅させる** — 部屋の敵をすべて倒すとEXITが開きます。EXITに触れると次の部屋へ。
5. **60秒で3部屋** — 被弾すると即終了。時間切れでも終了です。

## 時間のルール

- 移動入力の大きさに応じて `flow` が 0〜1 の間で変化します。
- 弾・敵の射撃・敵の回転は `flow` に比例した速度で進みます。
- プレイヤーの移動と射撃クールダウンは実時間で進みます。止まっている間も弾は発射できますが、弾はその場に留まります。
- **止まって弾を置き、動いて弾を飛ばす**のが基本の駆け引きです。

## 敵

| 種類 | 動き |
| --- | --- |
| TURRET | プレイヤーを狙って単発弾を撃つ |
| SPINNER | 回転しながら3方向に弾をばらまく |

壁は弾もプレイヤーも通しません。敵は壁を貫通して撃ってくるため、遮蔽ではなく位置取りで避けます。

## スコアと評価

- 敵撃破: +120
- EXIT開放: +250
- 部屋クリア: +500
- 勝利時の残り時間: 1秒あたり +20

勝利時は S / A / B / C、敗北時は B / C / D で評価します。自己ベストは `localStorage` に保存されます。

## 設計の要点

- **時間と移動の結合**: `flow` を移動量から作り、ワールドの `dt` に掛ける。止まると弾が凍り、動くと一斉に動き出す。
- **弾を置く**: 射撃は実時間クールダウンなので、停止中に弾を撒いてから動いて発射できる。これが攻撃のリズムになる。
- **1発被弾**: ライフ制にせず、被弾で即終了。時間を止める判断に重みを持たせた。
- **自動プレイ**: `autoStep` は最寄りの敵を狙い、距離を保ちながら弾を避ける。`update` は描画ループ側だけが呼ぶ。
- **決定的なテスト**: 敵の初期角度・射撃タイマーはシード固定。`test-engine.js` で時間停止と部屋遷移を検証する。

## テスト


## 既知の制限

- 部屋は3つ固定。敵の種類は2種類。
- スマホの右スティックは「照準 + 射撃」を同時に行う。細かい狙いより回避優先の操作感。
- 音のON/OFFは右上のSOUNDのみ。音量調整は未実装。
- タイムアタックのランキングはローカルの自己ベストのみ。
