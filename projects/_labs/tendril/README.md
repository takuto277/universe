# TENDRIL

光る餌を触手で捕食する、45秒の海中アクションです。キャラクター・アニメーション・エフェクトを画像素材なしのコードだけで描く試作でもあります。

## 遊び方

- START で開始
- 画面をドラッグすると頭がその方向へ泳ぐ
- 押したままにすると触手が伸び、先端が餌に触れると掴んで引き寄せる
- 餌を食べるほど体が伸び、コンボが伸びる
- トゲに触れると弾かれてコンボが切れる（スコアは減らない）
- 45秒終了時のスコアが記録される（ベストは localStorage）

## 構成

| ファイル | 役割 |
| --- | --- |
| `engine.js` | 状態、体のチェーン、触手、餌・トゲ、終了判定 |
| `renderer.js` | Canvas描画（発光・パーティクル・揺れ・ビネット） |
| `game.js` | 入力、HUD、画面遷移、`window.__GAME__` |
| `index.html` | 画面の骨格 |
| `style.css` | 見た目 |
| `test-engine.js` | ロジックのテスト |
| `test-smoke.js` | 自動プレイのスモークテスト |

## 設計メモ

- キャラクターは画像を使わず、`body` の関節チェーンを毎フレーム距離制約で解いて描く。しなりは sin 波を足して生成する
- 触手は頭から照準方向へ伸びる線分。先端と餌の距離でグラブを判定し、掴んだ餌は頭へ補間で引き寄せる
- 描画は `globalCompositeOperation = 'lighter'` の重ね塗りで発光を表現し、`ctx.shadowBlur` は使わない（モバイル負荷対策）
- 画面は論理座標 390×844 を `min(width/390, height/844)` でレターボックスし、入力は `screenToWorld` で逆変換する
- ロジックは `engine.js` に閉じ、乱数は `createGame({ rng })` で差し替え可能にしてテストを再現できるようにする

## テスト

```sh
./tools/run-tests.sh
```

個別:

```sh
cd projects/_labs/tendril/
jsc test-engine.js
jsc test-smoke.js
```

## 既知の制限

- トゲは自動プレイでは避けないため、実際の操作感は手で確かめる必要がある
- 体のノードは最大26。それ以上は伸びない
- 効果音は未実装
