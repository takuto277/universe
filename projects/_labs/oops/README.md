# OOPS

**時計は止まっている。間違えたときだけ、時が進む。** 90秒の「誤答予算」で18問に挑む4択クイズです。正解しても時間は減りません。誤答だけが残り時間を10秒ずつ削ります。

## 遊び方

1. **4択に答える** — 選択肢をクリック、またはキーボードの `1`〜`4`。正解でスコアとコンボが増えます。
2. **誤答に注意** — 誤答すると残り時間が10秒進みます。コンボも消えます。9回誤答すると時間切れで終了です。
3. **スキップを選ぶ** — `S` / `Space` または SKIPボタン。時間は減りませんが、得点もコンボもありません。7秒で自動スキップになります。
4. **速く答える** — 回答が速いほどスピードボーナス（FLASH / FAST / OK）が付きます。連続正解でコンボ倍率も上がります。
5. **18問を読み切る** — 全問終えるとクリア。残り時間に応じたタイムボーナスが入ります。

## 時間のルール

- 開始時の残り時間は90秒。**時計は通常止まっています。**
- 誤答のたびに `-10秒`。これがこのゲームの「時が進む」正体です。
- 正解・スキップでは時間は変わりません。焦って答える理由は、時間ではなくスコアです。
- 残り時間が0になった時点でゲームオーバー。全問回答できればクリアです。

## スコアと評価

- 正解: 基本100点 + スピードボーナス（FLASH +100 / FAST +60 / OK +30）
- コンボ倍率: 連続正解1回ごとに +10%（最大1.4倍）
- クリア時: 残り時間1秒あたり +15点
- ランク: クリア時はスコアで S / A / B / C、時間切れは正解数で C / D / E

自己ベストは `localStorage` に保存されます。

## 設計の要点

- **時計を誤答にだけ結びつける**: 通常のクイズは時間が常に減りますが、このゲームは正解では止まり、誤答だけが時間を進めます。時間＝ミスの予算という読み替えが独自性です。
- **スキップの価値**: 誤答は時間を削り、スキップは時間を守るが点にならない。迷ったときの判斷がそのままスコア差になります。
- **スピードは別軸**: 時間を削らずに「速さ」を評価するため、問題ごとの経過時間からスコアボーナスを出します。時計の比喩を壊さずにテンポを作っています。
- **決定的な出題**: シード付きシャッフルで、テストでは同じ出題順を再現できます。
- **自動プレイ**: `autoStep` は常に正解を選び、クリアまで到達します。誤答や時間切れの経路は `test-engine.js` で検証します。

## 既知の制限

- 問題は固定プール25問から18問をランダム出題。追加・差し替えは `engine.js` の `QUESTIONS` を編集します。
- 誤答時の時間ペナルティは常に10秒。難易度調整は未実装です。
- ランキングはローカルの自己ベストのみで、サーバー共有はありません。
- 7秒の制限時間は回答のテンポ用で、時間を削る要素ではありません。
