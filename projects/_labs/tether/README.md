# TETHER

張り出したアンカーにロープを引っかけて登る、1ボタンの縦画面クライミングです。UIは英語のみです。

- **押す** — ロープを巻き取り、アンカーへ引き寄せられる
- **離す** — ロープを外し、次のアンカー方向へ飛ぶ
- **60秒** — 時間切れ時点の高さがスコア。ベスト高さはローカル保存

## 遊び方

1. **START CLIMB** を押す。
2. 画面のどこかを押している間、ロープが縮んで体が上へ寄る。
3. 離すとロープが外れ、次の未使用アンカーへ向かう推力が加わる。
4. アンカーに近づくと自動で掴み、また巻き取れる。回転バーに当たると弾かれる。
5. 60秒で終了。到達した高さと使用アンカー数が結果に出る。

押し続けるとアンカーを通り過ぎてしまうため、近づいたら離す。どのアンカーを次に使うか、どのタイミングで切り替えるかが判断になります。アンカーは1回だけ使えます。

## ルール

- プレイヤーは1点のボール。重力は常に下向き。
- ロープは掴んでいるアンカーとの距離を一定に保つ振り子。巻き取ると距離が縮む。
- 離した瞬間に、次の未使用アンカー方向へ780の推力。ロープは消える。
- アンカーから120px以内に入ると自動で掴む。掴んだアンカーは再利用不可。
- 高さは開始地点から上方向の距離。落下しても減らない。
- 障害物は3つの回転バー。当たると速度を落とし、横へ弾かれる。
- 60秒で強制終了。結果画面から同じ塔に再挑戦する。

## 見た目と音

- 暗い藍色の塔、金のアンカー、ティールのロープとボール。登るほど背景の星とリングが増える。
- ロープの張力、巻き取りの速さ、残り時間で画面のグローが変わる。
- WebAudioで、アタッチ音、スナップ音、ヒット音、終了音をプロシージャルに生成。外部音源なし。
- 画面は縦長。PCでは中央の縦パネルとして表示。共通ナビゲーションから一覧へ戻れる。

## ファイル構成

```text
tether/
├── index.html        # 縦画面の骨格・HUD・開始/結果画面
├── style.css         # HUD・オーバーレイ・PCの縦パネル
├── engine.js         # テザー物理、アンカー、障害物、60秒、自動プレイ
├── audio.js          # WebAudioの効果音
├── renderer.js       # Canvasの塔・星・ロープ・アンカー・障害物
├── game.js           # 入力、描画ループ、HUD、ベスト保存、window.__GAME__
├── test-engine.js    # 巻き取り・リリース・60秒終了
└── test-smoke.js     # 60秒の自動プレイと結果画面
```

## 設計の要点

- **テザーは距離拘束**: ボールとアンカーの距離を一定にし、速度を接線方向へ射影する。巻き取り中だけ距離を縮める。振り子の運動と巻き取りを同じ更新で扱う。
- **離す方向は次のアンカー**: 未使用のうち最も近いアンカーへ780の推力を与える。プレイヤーは方向を選ばず、タイミングだけを選ぶ1ボタン設計。
- **高さは最高地点**: 落下してもスコアは減らない。60秒のどこで高い地点にいるかが結果になる。
- **自動プレイを同じエンジンで**: `autoStep()` が「掴む→巻く→離す」を繰り返す。スモークテストはUIではなく `window.__GAME__` 経由で同じエンジンを動かす。
- **状態と描画を分離**: `getState()` にプレイヤー、アンカー、テザー、障害物、結果をまとめ、rendererは状態だけを描く。

## テスト

```sh
cd projects/_labs/tether
jsc test-engine.js
jsc test-smoke.js
```

`test-engine.js` は巻き取りでロープが縮むこと、離すとテザーが外れて上向きの速度が出ること、60秒で終了することを検証します。`test-smoke.js` は60秒の自動プレイ後に結果画面と高さ表示が出ることを確認します。リポジトリ全体では `./tools/verify.sh` です。

## 既知の制限と次に試すこと

- アンカーは15個で、60秒の自動プレイでは3個しか使わない。上位を狙うには巻き取り時間と離す高さの調整が必要。
- 障害物は回転バーのみ。動くアンカー、切れるロープ、風、下から迫る床は未実装。
- ベストは端末の `localStorage` のみで、ランキングやリプレイ共有はない。
- 効果音のミュート状態はページを閉じるとリセットされる。
- 実機での片手操作と、60秒という長さが集中を保てるかは今後確認する。
