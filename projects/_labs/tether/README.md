# TETHER

張り出したアンカーにロープを引っかけて登る、1ボタンの縦画面クライミングです。UIは英語のみです。

- **押す** — ロープを巻き取り、アンカーへ引き寄せられる（最短80pxで停止）
- **離す** — ロープを外し、次のアンカー方向へ飛ぶ。ロープが長いほど速く遠くへ飛ぶ
- **60秒** — 5ステージを1本のランで突破。目標高さに届くと次のステージへ。ベスト高さはローカル保存

## ステージ

| ステージ | 目標高さ | ギミック速度 | 風の強さ |
| --- | --- | --- | --- |
| 1 | 80m | 1.00x | 1.00x |
| 2 | 160m | 1.15x | 1.12x |
| 3 | 250m | 1.30x | 1.24x |
| 4 | 350m | 1.45x | 1.36x |
| 5 | 450m | 1.60x | 1.50x |

目標高さに届くと画面にステージクリアのバナーが出て、そのまま次の目標へ進みます。60秒以内に450mへ届けば **ALL CLEAR**。届かなければ、到達したステージと高さが結果になります。

## 遊び方

1. **START CLIMB** を押す。
2. 画面のどこかを押している間、ロープが縮んで体が上へ寄る。
3. 離すとロープが外れ、次に上のアンカーへ向かう推力が加わる。
4. ホールド中にアンカーから120px以内へ入ると掴む。使用済みのアンカーにも再リンクできる。ロープは最短80pxまでしか巻き取れない。
5. 離した瞬間の速度はロープの長さに比例する。長いロープほど高く遠くへ飛ぶ。
6. 回転バー、バンパー、風ゾーンが進路を変える。ステージが上がるほどバーが速く、風が強くなる。
7. 目標高さに届くとステージクリア。HUDのSTAGEとGOALが次の目標に切り替わる。
8. 一番下まで落ちると床で止まり、ボトムのアンカー（anchor 0）に自動で再リンクする。時間は進むが、そこから巻き取って再開できる。
9. 60秒で終了。ALL CLEARまたは到達ステージと高さが結果に出る。

押し続けるとアンカーを通り過ぎてしまうため、近づいたら離す。アンカーは何度でも掴み直せます。どのアンカーへ向かい、どのタイミングで切り替えるかが判断になります。

## ルール

- プレイヤーは1点のボール。重力は常に下向き。
- ロープは掴んでいるアンカーとの距離を一定に保つ振り子。巻き取ると距離が縮む。
- 離した瞬間に、次に上のアンカー方向へ推力。ロープは消える。推力は `780 × (0.75 + 0.75 × ロープ長 / 120)`。長いロープほど強い。
- ホールド中にアンカーから120px以内へ入ると掴む。使用済みアンカーにも再リンクできる。
- 巻き取りの最短は80px。アンカーの中心まで吸い寄せられない。
- 高さは開始地点から上方向の距離。落下しても減らない。
- 一番下には床があり、画面外へは落ちない。テザーなしで床に触れると、自動で anchor 0 に再リンクして停止する。
- ギミックは回転バー3、バンパー4、風ゾーン2。バンパーは弾き、風ゾーンは横方向へ加速する。ステージが上がるとバーの回転と風が強くなる。
- 高速移動でも貫通しないよう、速度に応じて物理更新を最大16分割する。
- ステージ目標は80 / 160 / 250 / 350 / 450m。450m到達でALL CLEAR、時間切れで結果。
- 60秒で強制終了。結果画面から同じ塔に再挑戦する。

## 見た目と音

- 暗い藍色の塔、金のアンカー、ティールのロープとボール。登るほど背景の星とリングが増える。
- ロープの張力、巻き取りの速さ、残り時間で画面のグローが変わる。
- WebAudioで、アタッチ音、スナップ音、ヒット音、終了音をプロシージャルに生成。外部音源なし。
- 画面は縦長。PCでは中央の縦パネルとして表示。共通ナビゲーションから一覧へ戻れる。

## ファイル構成

```text
tether/
├── index.html        # 縦画面の骨格・HUD・開始/結果画面
├── style.css         # HUD・オーバーレイ・PCの縦パネル
├── engine.js         # テザー物理、アンカー、障害物、60秒、自動プレイ
├── audio.js          # WebAudioの効果音
├── renderer.js       # Canvasの塔・星・ロープ・アンカー・障害物
├── game.js           # 入力、描画ループ、HUD、ベスト保存、window.__GAME__
├── test-engine.js    # 巻き取り・リリース・60秒終了
└── test-smoke.js     # 60秒の自動プレイと結果画面
```

## 設計の要点

- **テザーは距離拘束**: ボールとアンカーの距離を一定にし、速度を接線方向へ射影する。巻き取り中だけ距離を縮めるが、最短80pxで止める。振り子の運動と巻き取りを同じ更新で扱う。
- **離す方向は次のアンカー**: 次に上のアンカーへ、ロープ長に応じた推力を与える。プレイヤーは方向を選ばず、巻き取り量とタイミングを選ぶ1ボタン設計。
- **高さは最高地点**: 落下してもスコアは減らない。60秒のどこで高い地点にいるかが結果になる。
- **ステージは高さの節目**: 80mごとではなく、80 / 160 / 250 / 350 / 450mと間隔を広げる。ステージが上がるほどバーと風を強くし、同じ操作でも判断を忙しくする。
- **自動プレイを同じエンジンで**: `autoStep()` が「ホールドして近くのアンカーを掴む→巻く→離す」を繰り返す。スモークテストはUIではなく `window.__GAME__` 経由で同じエンジンを動かす。
- **状態と描画を分離**: `getState()` にプレイヤー、アンカー、テザー、障害物、結果をまとめ、rendererは状態だけを描く。

## テスト

```sh
cd projects/_labs/tether
jsc test-engine.js
jsc test-smoke.js
```

`test-engine.js` は巻き取りでロープが縮むこと、最短80pxで止まること、ホールド中だけ近くのアンカーへ掛かること、使用済みアンカーへ再リンクできること、長いロープほど離した速度が大きいこと、高速時の回転バー貫通、バンパー、床救助、5ステージのクリアとALL CLEAR、60秒終了を検証します。`test-smoke.js` は60秒の自動プレイ後に結果画面と高さ表示が出ることを確認します。リポジトリ全体では `./tools/verify.sh` です。

## 既知の制限と次に試すこと

- アンカーは15個で、60秒の自動プレイでは356m・ステージ5まで到達する。使用済みアンカーにも再リンクできるため、巻き取り時間と離す高さの調整で450mのALL CLEARを狙える。
- ギミックは回転バー・バンパー・風ゾーンのみ。動くアンカー、切れるロープ、下から迫る床は未実装。
- 床は anchor 0 に戻るだけで、全アンカーを使い切った後の特別な再スタートはない。
- ベストは端末の `localStorage` のみで、ランキングやリプレイ共有はない。
- 効果音のミュート状態はページを閉じるとリセットされる。
- 実機での片手操作と、60秒という長さが集中を保てるかは今後確認する。
