# REBEL BREAKOUT（逃げるブロック）

ブロック崩しのブロック側になって、AIのボールを60秒かわすネオン回避ゲームです。壊す側ではなく、壊される側の逆転がテーマです。

## 遊び方

- `WASD` / 矢印キー / ドラッグで自機ブロックを動かす
- ボールは壁とシールドで跳ね、少しずつ自分を狙って加速する
- ボールに当たるとライフが1減る。ライフ0で終了
- `SPACE` / `SWAP` で、一番安全なシールドへ瞬間移動する。移動先のシールドは消費される
- 60秒生き残れば CLEAR。生存時間・GRAZE・残ライフでスコアとランクが決まる

## 見どころ

- ブロック崩しの視点反転。消えるのは敵ではなく、自分の隠れ場所
- シールドが「隠れ場所」と「SWAPの逃げ道」を兼ねる資源になっている
- 速度上昇・SURGE・22秒/42秒の追加ボールで、60秒の間に波を作る
- 被弾で全ボールが上へ戻るので、立て直しの猶予がある
- ぎりぎりをかわす GRAZE で上を狙える

## 構成

| ファイル | 役割 |
| --- | --- |
| `engine.js` | プレイヤー移動、ボール物理、シールド破壊、SWAP、時間とスコア |
| `game.js` | Canvas描画、入力、HUD、画面遷移 |
| `index.html` | HUD、開始/終了画面、方向パッド、SWAPボタン |
| `style.css` | ネオンUI、レスポンシブ、オーバーレイ |
| `test-engine.js` | 移動、反射、破壊、被弾、SWAP、クリア、自動プレイ |
| `test-smoke.js` | 実際の `game.js` を起動して自動プレイ |

## 設計メモ

- `engine.js` はDOMに触れない。`update(state, dt)` と `setInput(state, x, y)` だけで進む
- ボールは最大6pxずつサブステップ移動し、高速時のシールド貫通を防ぐ
- ホーミングは「すでに自分へ向いているとき」だけ最大0.1rad/秒補正する。追尾しすぎない
- `SWAP` は全ボールからの最短距離が最大のシールドを選ぶ。使い切ると逃げ道が消える
- `window.__GAME__` の6キー（`id` / `title` / `start` / `autoPlayStep` / `isDone` / `getState`）を公開する

## 既知の制限

- 効果音は未実装
- ステージは1種類。シールド配置の穴だけシード乱数で変わる
- 自動プレイは最寄りボールから離れる貪欲法で、GRAZEは狙わない
- 序盤はシールドが多く、ボールが上で跳ねる時間が長い
