# AFTERIMAGE

ジャンプの頂点が **残像の足場** になって固まる、縦登りアクションです。過去の自分の軌跡を踏み台にしながら、60秒で高度500mを目指します。

## 遊び方

1. **移動** — A / D または ← →。スマホは画面下の ◀ ▶。
2. **ジャンプ** — Space / ↑ / W。スマホは JUMP。ジャンプキーを離すと高さを調整できます。
3. **残像を作る** — ジャンプの頂点に、約0.2秒後に半透明の足場が固まります。約3.4秒で消えます。
4. **残像を踏む** — 頂点で左右を戻すと、自分の残像に着地しやすい。残像から跳ぶと通常より少し高くなります。
5. **500mを目指す** — 1000pxごとにチェックポイント。落ちるとライフが1減り、最後のチェックポイントから再開します。ライフ3、制限時間60秒。

## ルール

- 足場は上から踏む一方通行。下からはすり抜けます。
- 残像の足場は時間で消えるため、連続で置きながら登ります。
- 落ちて画面下に出るとライフ-1。ライフが0になると終了。
- 高度500mのSUMMITに触れると勝利。時間切れでも終了します。
- スコア = 高度(m) × 10 + チェックポイント × 100 + 勝利時の残り時間 × 20。
- 評価は勝利時 S / A / B、時間切れ時 A / B / C / D。自己ベスト高度は `localStorage` に保存。

## 設計の要点

- **頂点に足場**: ジャンプ中に `vy` が正から負へ変わる瞬間を頂点として検出し、0.2秒後に小さな足場を生成する。同じジャンプ中には使えないため「過去の自分」を踏む感覚になる。
- **残像からのジャンプ**: 残像の上で跳ぶと `JUMP_V` が1.07倍になる。連続で残像を置くほど高く登れる。
- **カメラは上方向のみ**: 一度上がったカメラは戻らない。落下すると画面外に出てライフを失う。
- **塔の生成**: シード固定。通常の間隔と、残像を使わないと届かない広い間隔を混ぜる。チェックポイントは1000pxごとに配置。
- **自動プレイ**: 最寄りの足場と残像を探し、頂点では残像の中心へ戻るように移動する。`update` は描画ループ側だけが呼ぶ。

## テスト

```sh
cd projects/_labs/afterimage
jsc test-engine.js
jsc test-smoke.js
```

リポジトリ全体では `./tools/verify.sh` です。

## 既知の制限

- 塔は1本の縦坑で、分岐や横ルートはない。
- 残像の足場は1ジャンプにつき1枚。連続ジャンプのタイミングが主な技量。
- チェックポイントは4つ＋頂上。ライフは3で固定。
- 音のON/OFFは右上のSOUNDのみ。音量調整は未実装。
