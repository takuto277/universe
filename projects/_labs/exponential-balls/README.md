# BLOOM（exponential-balls）

音楽に合わせて遊ぶ縦画面のオーディオビジュアル体験です。120 BPM / 4/4。UIは英語のみです。

- **AUTO** — 1小節ごとにボールが倍々に増える
- **FRAME** — 上部ラインに触れたボールが2個に増えて色が濃くなる
- **RACE** — 20色のボールがギミックを抜け、最後の1球を決めるノータップ・サバイバル
- **RACE 3D** — 20球が積み木コースを転がり、最初のゴールを予想するモード

## モード

ホーム画面で4つのモードを選べます。

1. **AUTO** — 1小節ごとに自動で分裂。1 → 2,048 を12小節で駆け抜ける、拍に完全に同期したモード。
2. **FRAME** — 上部のラインにボールが触れると、そのボールが2個に増えてラインと逆の下向き180度のどこかへ飛ぶ。ラインで増えた子ボールだけ、倍になるたびに色が濃くなる。
3. **RACE** — 20色のボールが上から落ち、ペグ・バンパー・スピナー・ポータル・コンベア・ウェル・ブースター・奈落を抜ける。最後の1球になったら終了。タップ介入はなし。
4. **RACE 3D** — 20球が斜め下の積み木コースを転がり、最初にゴールした球が勝ち。約20秒。レース前に勝つ球を予想し、SPD/BNC/GRP/SIZEの能力差を見て選ぶ。横ドラッグでカメラが周回し、右の縦スライダーでコースに沿って移動する。

## 遊び方

1. ホームで **AUTO / FRAME / RACE / RACE 3D** のカードを選び、**START** を押す。
2. AUTO/FRAMEでは音が鳴り、1個のボールから始まる。
3. AUTOは小節ごと、FRAMEは上部ラインに触れるたびにボールが倍々に増える。
4. RACEは20球が自動で落ち、最後の1球が勝者。RACE 3Dは20球が積み木コースを転がり、最初のゴールが勝者。RACE 3Dはレース前に予想し、結果で連勝を更新。横ドラッグでカメラ周回、右スライダーでコース移動。
5. AUTO/FRAMEは2,048個でサイクルが切り替わる。**HOME** でホームに戻り、**SOUND** でミュート。

AUTO/FRAMEでは画面タップで近くのボールを押し返せます。RACEは観るモードで、タップしても球には影響しません。RACE 3Dは予想とカメラ操作のみで、球には介入しません。

## 音楽と同期

外部の音源ファイルは使わず、WebAudioでプロシージャルに鳴らしています。

- 120 BPM、16分ステップを先読みしてスケジュール
- キック、ハット、ベース、アルペジオ、パッド、ライザー、インパクト
- 小節が進むほど層が増え、12小節でサイクル
- サイクルごとにキーが変わる（C / E♭ / F / G minor）
- FRAMEのライン通過音は次の16分に量子化し、現在のキーの2度/3度上で鳴らす
- RACEの脱落音は16分に量子化し、勝者が出た瞬間はインパクトで鳴らす

**音ハメの考え方:** AUTOは小節頭の分裂とキックが一致するため、最も強く拍にハマります。FRAMEはライン、RACEはギミックと奈落が入力になるため、増加や脱落そのものは拍に固定できません。通過音を16分に量子化し、拍のパルスで音楽との接点を作っています。

AI生成の音源を使う場合は、音源ファイルとBPM・拍の開始位置を用意すれば差し替えできます。

## 映像

- AUTO: 1小節ごとに各ボールが2個に分裂
- FRAME: 上部ラインに触れたボールを2個に分け、下向き180度へ放出
- RACE: 20色の球、ペグ、バンパー、回転バー、ポータル、コンベア、ウェル、ブースター、奈落、勝者のリング
- RACE 3D: 斜め下の積み木コース、20色の球、SPD/BNC/GRP/SIZEの能力差、予想画面と連勝、横ドラッグで周回するカメラ、右スライダーでコース移動
- RACE 3Dの積み木は球の色と重ならない銀色。ワールド座標の固定ブロックで、カメラを回しても向きは変わらない
- RACE 3Dはパーティクル/軌跡を出さず、球と積み木だけを描く
- RACEは高速化した球、長い軌跡、ヒット時のパーティクル、フラッシュで派手に動く

- ボールの半径は数が増えるほど小さくなり、画面全体が群れになる
- FRAMEでラインを通過して生まれたボールは、倍になるたびに色が濃くなる
- 加算合成の軌跡、波紋、拍のパルス、サイクル切替のフラッシュ
- キャンバスは縦画面。PCでは中央の縦パネルとして表示

## 設計の要点

- **AUTOは時間と小節だけ**: ボール数は `2^bar`。1サイクル12小節、24秒。描画と音は状態から決まる。
- **FRAMEはラインと速度**: 上部ラインを通過した瞬間に2個へ増え、ラインと逆の下向き180度のどこかへ飛ぶ。0.35秒の免疫で連鎖通過を防ぎ、子ボールは親より色が濃くなる。
- **RACEは20球の物理**: 重力・壁・球同士の衝突・ペグ・バンパー・回転バー・ポータル・コンベア・ウェル・ブースター・奈落で構成。下の奈落に落ちた球から脱落し、生存が1球になった瞬間に勝者。38秒後は奈落が上がり、決着を促す。ヒット時はパーティクルとフラッシュで派手に返す。
- **RACE 3Dは積み木レース**: 斜め下のボードを20球が転がり、最初にゴールした球が勝者。球ごとに速度・反発・グリップ・サイズが異なり、予想画面で選ぶ。カメラは横ドラッグで周回、右スライダーでコースに沿って移動。自動追尾はせず、パーティクル/軌跡も出さない。積み木は銀色の固定ブロック。
- **映像の時計を基準に音を組む**: ゲームの時刻は `performance.now`。AudioContextが止まっても映像は進み、復帰後は現在の小節から音を再開する。
- **2,048でリセット**: AUTO/FRAMEの上限。FRAMEではライン通過イベントとしてフラッシュと波紋を出す。RACEは最後の1球で結果画面に移る。
- **入力**: AUTO/FRAMEはタップで押し返し、RACEはノータップ。RACE 3Dはレース前の予想とカメラ操作。勝敗は能力とコースに委ねる。

## テスト

```sh
cd projects/_labs/exponential-balls
jsc test-engine.js
jsc test-audio.js
jsc test-ui.js
jsc test-renderer.js
jsc test-smoke.js
jsc test-frame-smoke.js
jsc test-race-smoke.js
```

リポジトリ全体では `./tools/verify.sh` です。`test-engine.js` はAUTO/FRAMEの倍々、RACEの20球、RACE 3Dの予想・能力・最初のゴールを検証します。`test-audio.js` はスケジューラの安全を確認します。`test-ui.js` は4モード選択・RACE 3D予想・連勝・HOMEを確認します。`test-renderer.js` はFRAME/RACE描画を確認します。`test-smoke.js` はAUTO、`test-frame-smoke.js` はFRAME、`test-race-smoke.js` はRACE、`test-race3d-smoke.js` はRACE 3Dの積み木レースを自動再生します。

## 既知の制限と次に試すこと

- RACE/RACE 3DのMVP。RACE 3Dは約20秒で、予想と連勝はローカル保存。簡易3D投影で、物理は3Dだが描画はCanvas 2D。カメラズーム、コース分岐、能力の追加はまだない。
- RACEの結果はランダム性が強い。シード固定やリプレイ共有は次に試す。
- FRAMEの増加は拍に固定されない。ライン通過音の16分量子化とラインの拍パルスで補っているが、AUTOほどの音ハメはない。
- 一時停止ボタンはない。止める場合はHOMEでホームに戻るか、タブを閉じる。
- 2,048個の描画は端末によって負荷がある。必要なら最大数を下げる、軌跡を軽くする、描画を間引く。
- AI生成の音源への差し替え、BPM変更、サイクルごとのテンポ変化は未実装。
