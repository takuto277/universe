# ONE CARD DUNGEON

1ターンに手札3枚から**1枚だけ**選んで戦う、6階層のデッキ構築ローグライトです。

## 遊び方

- 手札3枚から1枚を選んで、敵と戦う
- 敵の「次の行動」を見て、攻撃・防御・回復・状態異常を使い分ける
- 敵を倒すたびにカードを1枚デッキへ追加
- 6階層の魔王を倒せばクリア
- キーボードは 1 / 2 / 3 でもカードを選べる

## カード

- ストライク: 8ダメージ
- ガード: 9ブロック
- ヘビー: 15ダメージ / 自分3
- ヒール: 9回復
- フリーズ: 敵の次の行動を止める
- ポイズン: 3毒を3ターン
- フォーカス: 次の攻撃+8
- ドレイン: 6ダメージ + 6回復
- シールドバッシュ: ブロック分ダメージ

## 見どころ

- 1枚しか選べない制約から生まれる、攻めるか守るかの判断
- 敵の次行動が見えるので、先読みしてカードを選ぶ
- 階層クリアごとのカード選択でデッキが育つ
- 60HP、HP+8回復、6階層の魔王
- ベスト到達階層を保存

## 構成

| ファイル | 役割 |

| `test-smoke.js` | 自動プレイで決着まで確認 |
