自作アプリ・ゲームのハブ

  • GAME

    9球種を読め!

    3回勝負の野球ゲーム。9球種と見逃しの駆け引き、カウント制、タイミングバーで長打を狙え。配球メモと得意/苦手バッジでCPUのクセを読んで打ち崩し、守備はゾーン率を見極めて四球に注意!
  • GAME

    手を読め!

    心理戦じゃんけんゲーム。連勝ボーナスと先読み必殺の読み合い、見切りゲージを満タンにしてCPUの手を見てから選べ。手の履歴と「CPUの読み」メーターを見ながら、出しグセを読まれないように駆け引きを制せ!
  • GAME

    重力フリップ

    タップで上下の重力を反転してトゲを避ける1ボタン2Dアクション。だんだん速くなるステージでコインを集め、自己ベストの距離を目指せ!
  • GAME

    グラフクロス

    xが自動で進むグラフの上で関数を切り替え、自分の曲線を敵の曲線に交差させて大爆発を起こす2Dアクション。上昇/下降/その他のジャンルから3つ選ぶデッキ、累乗(x^p)と波(sin/cos/三角/角丸/減衰)の関数ビルダー、リアルタイム軌道プレビュー、角度・弱点・連続MULTI、アイテムで追加される非対称グラフ、ボスとステージクリア、同ジャンル内の関数入れ替えと3択強化、ライフ無限のストレス解消モードを搭載。BGMと効果音、スマホのタップ操作にも対応!
ローカルで動かすには python3 -m http.server をこのフォルダで実行して開く（各ゲームは依存ゼロの静的ファイル）。
