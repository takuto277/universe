# 観測者

5×5の盤面を動く敵の **隠れた規則** を観測し、次の一手を予測するスマホ向け推理ゲームです。1回約5分。外すとライフが減り、敵の規則が1つ書き換わります。

## 遊び方

1. **観測する** — 敵が1マス動きます。軌跡・向き・灯との位置関係を見て、規則のクセを読みます。
2. **次の一手を予測** — 光っている隣のタイルをタップします。
   - 当たり: +10、正解数+1
   - 外れ: ライフ-1、敵は実際に動き、**ルールが変わる**
3. **灯を動かす** — 残り2回まで、灯（ビーコン）を別のタイルへ移せます。「灯へ/灯から」の規則かを試す実験になります。灯のマスには敵は入れません。
4. **ルール候補** — 6つの候補をメモで消去できます。現在のルールは教えてもらえないので、動きと候補を照らし合わせて絞ります。
5. **12ターン** — 観測・予測・灯の移動でターンを使います。ライフが0になるか12ターンを過ぎると終了です。

## ルール候補

- **まっすぐ**: 同じ方向へ進む。壁なら右へ曲がる。
- **右回り**: 毎回右に曲がって進む。
- **左回り**: 毎回左に曲がって進む。
- **ジグザグ**: 右と左を交互に曲がる。
- **灯へ**: 灯に近づく方向へ進む。
- **灯から**: 灯から遠ざかる方向へ進む。

同じ距離の候補が複数あるときは、今の向きを優先し、時計回りに選びます。灯のマスは壁として扱います。

## 評価

スコアは `正解 × 10 + 残りライフ × 3` です。

- S: 正解7回以上
- A: 正解5回以上
- B: 正解3回以上
- C: それ未満

12ターン中、最初に2回観測してから10回当てると、正解10・スコア109が最高です。観測を増やすと当てられる回数は減ります。自己ベストはブラウザに保存されます（`localStorage`）。

同じシードなら同じ盤面・同じ初期ルールです。終了画面から「同じ盤面で再挑戦」できます。`?seed=12345` のように URL にシードを付けることもできます。


## 設計の要点

- **1画面1判断**: 盤面を見て、光る隣のタイルをタップするか、観測するか。予測・観測・灯の3つだけ。
- **観測にコスト**: 観測は安全だがターンを使う。予測は点数になるが外すとライフとルールが変わる。どこで賭けるかの判断を入れた。
- **ルール変更**: 外すと敵の規則が変わり、候補メモもリセットされる。「負けるほど情報が増える」が、そのままでは勝てない。
- **灯の実験**: 灯を動かすと「灯へ/灯から」を切り分けられる。動きの観察だけでは曖昧な候補を試せる。
- **論理的な候補**: 6つの候補をメモで消去する。当てずっぽうではなく、軌跡・向き・灯の位置から候補を絞る。
- **決定的なテスト**: 盤面・初期ルール・ルール変更はシード固定。`test-engine.js` で6ルールの移動と境界を検証する。

## テスト

```sh
cd observer-game
jsc test-engine.js
jsc test-smoke.js
```

リポジトリ全体では `./tools/verify.sh` です。`test-engine.js` は5×5の盤外・灯の壁・6ルールの移動・予測成功/失敗・ルール変更・灯の回数・評価境界を検証します。`test-smoke.js` は `window.__GAME__` を自動プレイし、正解10・スコア109・S評価・エンド画面まで確認します。

## 既知の制限と次に試すこと

- 盤面は5×5、ルールは6種類、12ターン固定。盤面サイズ・ルール・ターン数のバリエーションは次版。
- 候補メモはUIだけのメモで、ゲーム側は正解を判定しない。上級者向けにメモなしモードも考えられる。
- しぐさ/軌跡のヒントが強いルールと弱いルールがある。誤解を誘う盤面や、観測を制限するモードは今後。
- 音のON/OFF、文字サイズ変更など、アクセシビリティはまだ十分ではない。
- スマホ実機で片手操作と盤面サイズをさらに調整したい。
