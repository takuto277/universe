# 関数評価シート / レアリティ設計メモ

ガチャの排出率やレアリティを決める前に、関数の「使いやすさ」「役割」「習熟度」を整理するためのメモです。

## 評価の考え方

レアリティは **強さ** ではなく、次の組み合わせで決めます。

- **操作性**: 軌道が予測しやすいか、暴走しにくいか
- **カバー範囲**: 上下どれだけ動けるか
- **習熟曲線**: 初心者でも扱えるか、使い込むと化けるか
- **構築依存度**: 単体で強いか、他の関数や合成前提か
- **独自性**: 他の関数で代用できるか

レア=上位互換にすると、ガチャ運で難易度が変わるため避けます。

## 軌道シミュレーション

`jsc evaluate-functions.js` で、各関数を中央から2秒動かしたときの軌道を測れます。

- 5 seed の平均
- 敵・アイテムなし
- 画面中央から開始
- カバー率 = 2秒間で動いた高さ / プレイフィールド高さ
- 端到達 = 上端または下端に初めて届くまでの時間
- 方向転換 = 上下方向が反転した回数
- 軌道長 = 動いた距離の合計

| 関数 | ジャンル | カバー率 | 最大速度(px/s) | 端到達(s) | 方向転換 | 軌道長(px) |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| y = 0 | その他 | 0% | 0 | - | 0.0 | 0 |
| y = x/2 | 上昇 | 48% | 170 | 1.45 | 0.0 | 246 |
| y = -x/2 | 下降 | 48% | 170 | 1.45 | 0.0 | 247 |
| y = 2x | 上昇 | 48% | 320 | 0.78 | 0.0 | 246 |
| y = -2x | 下降 | 48% | 320 | 0.78 | 0.0 | 247 |
| y = x² | 上昇 | 48% | 513 | 0.93 | 0.0 | 247 |
| y = -x² | 下降 | 48% | 513 | 0.93 | 0.0 | 247 |
| y = sin(x) | その他 | 26% | 285 | - | 3.0 | 350 |
| y = e^x - 1 | 上昇 | 48% | 539 | 0.90 | 0.0 | 247 |
| y = ln(x+1) | 上昇 | 48% | 424 | 1.50 | 0.0 | 247 |

## 暫定レアリティ

| レアリティ | 関数 | 理由 |
| --- | --- | --- |
| Common | y = 0 / y = x/2 / y = -x/2 | 予測しやすく、初心者向け |
| Uncommon | y = 2x / y = -2x / y = x² / y = -x² | 速度・加速があり、慣れが必要 |
| Rare | y = sin(x) / y = e^x - 1 / y = ln(x+1) / y = -1 + e^{-x} | 軌道が独特で、状況を選ぶ |
| Epic | y = sigmoid(x) / y = e^{-x²} | 形が特殊で使いこなしが必要 |
| Legendary | fusion | 合成でのみ作れる特別枠 |

`sin` は方向転換が多く、使いこなせると強い可能性があります。レアリティは「強さ」ではなく「独特さ」の暫定です。

## レアリティを決める追加材料

軌道メトリクスだけでは不十分なので、次を人間テストで取ります。

- 理解しやすさ（1〜5）
- また使いたいか（1〜5）
- 強さの印象（1〜5）
- どの関数と組み合わせたいか
- 使っていて気持ちいいか

「勝率は高いのに選ばれない」なら不人気、「勝率も使用率も高い」なら要調整です。

## 実装済みローカルガチャ

- 最初から `y=0 / x/2 / -x/2 / x²` のスターターを配る
- チュートリアルは固定デッキ
- レア関数は「強い」ではなく「別解」にする
- 全解放までは未所持の関数だけを排出（重複なし）
- レア+天井10回、EPIC天井20回
- ステージクリアの3択は **解放済み関数の中から出す**
  - ガチャと3択で二重にランダムにしない
- ポイント・所持・天井・直近の結果は `localStorage`
  - 端末間共有・課金・ランキングが必要になったらサーバー/DBへ

## ローカル保存の例

```js
localStorage.setItem('graph-cross-gacha', JSON.stringify({
  version: 1,
  unlocked: ['hold', 'up', 'down'],
  points: 300,
  pityRare: 0,
  pityEpic: 0,
  rolls: 0,
  lastResult: null
}));
```

`localStorage` は Swift の `UserDefaults` に近いが、文字列のみ・約5MB・端末間同期なし・改ざん可能という違いがあります。小さいコレクションなら十分です。
