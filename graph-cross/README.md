# グラフクロス

x が自動で進むグラフの上で、関数を切り替えながら自分の曲線を描き、右から流れてくる敵の曲線と交差させて大爆発を起こす 2D アクションです。8 種類の関数から 3 つを選んでデッキを組み、`x²` / `x² + bx` / `sin(bx + c)` は数値入力で自分好みに調整できます。交差角度が急なほど高得点で、敵と同じ系統(直線/2次/波)で交差すると弱点ボーナス。一定数交差するとボスが出現し、倒すとステージクリアです。コンボが伸びると BGM の音が重なって速くなります。曲線は「攻撃範囲」でもあり、自分が描いたグネグネした形がそのまま罠になります。依存ゼロの静的ファイルで動きます。

## 遊ぶ

universe のルートで次を実行し、http://localhost:8000/graph-cross/ を開きます。

```sh
python3 -m http.server 8000
```

## ルール

- x が自動で増え、プレイヤーの曲線が左から右へ伸びていく
- 開始前に 8 種類の関数から **3 つを選んでデッキ**を組む
- 開始画面の「関数をつくる」で `y = a x² + b x` / `y = -a x² + b x` / `y = a sin(bx + c)` の係数を数値入力できる。入力に合わせて軌道プレビューと説明がリアルタイムに変わる
- 通常の敵を一定数交差すると **ボス** が出現。ボスを倒すと **ステージクリア** で、次のステージへ進む
  - `y = 0`: その場をキープ
  - `y = x/2` / `y = -x/2`: 一定の速さで上下へ
  - `y = 2x` / `y = -2x`: 速い上下移動
  - `y = x²` / `y = -x²`: 上下に加速するカーブ
  - `y = sin x`: 上下に揺れるウェーブ
- `1`〜`3`(または下のボタン / 画面タップ)でデッキの関数を切り替え、これから描く曲線の形を変える
- 右から流れてくる敵の曲線と自分の曲線が交差すると、大爆発・得点・コンボ
- **交差角度が急なほどボーナス倍率アップ**(最大 1.8 倍)。真横から斬り込むと大きなエフェクトになる
- 敵の曲線には系統がある: 直線(青) / 2次(金) / 波(ピンク)。**プレイヤーの曲線の色と敵の色が同じ**ときに交差すると弱点ボーナス **1.5 倍**
- 曲線は描いた時点の関数の色で残る。ウェーブを置いてから別の関数に切り替えても、その区間は波として弱点を突ける
- 通常の敵を交差させずに画面左へ逃がすとライフ -1。ライフ 0 でゲームオーバー
- ボスは一定時間ごとに弱点の系統を変える。ボスを逃がすとライフ -1 で、少し後に再出現する
- ステージクリアでスコアボーナスとライフ回復。次のステージは敵の目標数とボスHPが増える
- 5 コンボごとにライフが 1 回復(最大 3)
- コンボは 2.6 秒以内に次の交差を決めると継続。得点は `(100 + (コンボ-1) × 50) × 角度ボーナス × 弱点ボーナス`
- コンボが伸びると BGM にハモリ・高音・カウンターが重なり、テンポも少し上がる。ミスでコンボが切れると元に戻る
- 音は画面下の「音 ON / OFF」でミュートできる。設定は保存される

## ステージとボス

- 通常フェーズの目標は `6 + ステージ × 2` 体。目標を満たすと通常敵の生成を止めてボスを出す
- ボスHPは `7 + ステージ × 3`。交差の角度と弱点で1回のダメージが1〜3変わる
- ボスの弱点は直線→2次→波の順に、2回ダメージを与えるたびに切り替わる
- ステージクリアで `1000 × ステージ` のボーナス。デッキと係数は持ち越す

## 難易度調整

- スクロール速度は開始 220px/s から、時間経過で最大 380px/s まで上がる
- 敵の生成間隔は約 1.5 秒から約 0.8 秒へ短くなる
- 敵の曲線は `sin` / `x²` / 直線`x/2` の 3 種類で、振幅と長さをランダムに変える。系統ごとに色と弱点が決まっている
- 開始直後に 3 本の敵曲線を画面内へ置き、最初の数秒から交差チャンスがあるようにしている
- ライフの回復条件を「5コンボ」にすることで、逃げ切るより攻める方が得になる
- ボスは通常敵より遅い速度で流れ、画面外に出るとライフを失って再出現する。時間切れではなく「倒すまで続く」区切りにしている

## テスト

universe のルートで実行します。

```sh
./tools/run-tests.sh
```

個別に実行する場合:

```sh
cd graph-cross
jsc test-engine.js
jsc test-smoke.js
```

`jsc` が PATH にない場合は、macOS 標準の `/System/Library/Frameworks/JavaScriptCore.framework/Versions/A/Helpers/jsc` を使うか、`JSC` 環境変数で指定してください。

## 設計メモ

- プレイヤーの曲線は「画面座標の点列」として持つ。毎フレーム点を左へスクロールさせ、ヘッド位置に新しい点を足すので、描いた形がそのまま残って敵を迎え撃つ
- 交差判定は「曲線の点列」と「敵の曲線のサンプル点」を同じ x で比べる。どちらも y = f(x) の形なので、線分交差より単純で安定する
- 敵が画面左へ抜けたときだけミスにする。ヘッドより後ろの曲線にも当たり判定があるため、後ろに罠を張る戦略が成立する
- 関数は速度・加速度として曲線に反映する。`x²` は加速度、`sin x` は上下する速度、`x/2` は一定速度
- デッキは 3 枠に制限し、`setMode` をデッキ内の関数だけに制限する。8 種類から 3 つを選ぶことで、上下の移動力・カーブ・ウェーブのどれを取るかがプレイスタイルになる
- 係数は `PARAM_SPECS` で範囲と刻みを定義し、`normalizeParams` でクランプ・スナップする。UI とエンジンで同じ仕様を使う
- 弱点は曲線の点ごとに保存した「描いた時のモード」から判定する。現在のモードではなく、その区間を描いた関数で判定するのがポイント
- BGM は AudioContext の時計で先読みスケジュールする。コンボ強度は音のレイヤーと1ステップの長さに反映する
- 係数プレビューは実際のゲームと同じ加速度・波の式で1.6秒分をシミュレーションし、画面端に届くかも判定する
- ステージクリアはエンジン側で `stageCleared` を立てて更新を止め、ゲーム側が900ms後にクリア画面を出す。次のステージは `nextStage` でスコアとライフを保持したままステージ固有の状態だけをリセットする
- 交差角度は、プレイヤー曲線の接線と敵曲線の接線から `atan(|(m1-m2)/(1+m1*m2)|)` で求める。90 度に近いほど得点倍率が上がる
- テストでは、何もしないプレイが数秒〜十数秒で終わり、敵の高さに合わせて動くプレイが 40 秒生存できることを確認している

## 既知の制限

- 画面サイズを途中で変えると、曲線や敵の画面位置が少しずれることがある
- BGM と効果音は Web Audio の合成音。初回の開始操作で AudioContext を再開する
- 効果音の ON/OFF とデッキはブラウザの `localStorage` に保存。シークレットモードでは消える
