# グラフクロス

x が自動で進むグラフの上で、関数を切り替えながら自分の曲線を描き、右から流れてくる敵の曲線と交差させて大爆発を起こす 2D アクションです。8 種類の関数から 3 つを選んでデッキを組み、交差角度が急なほど高いボーナスが入ります。曲線は「攻撃範囲」でもあり、自分が描いたグネグネした形がそのまま罠になります。依存ゼロの静的ファイルで動きます。

## 遊ぶ

universe のルートで次を実行し、http://localhost:8000/graph-cross/ を開きます。

```sh
python3 -m http.server 8000
```

## ルール

- x が自動で増え、プレイヤーの曲線が左から右へ伸びていく
- 開始前に 8 種類の関数から **3 つを選んでデッキ**を組む
  - `y = 0`: その場をキープ
  - `y = x/2` / `y = -x/2`: 一定の速さで上下へ
  - `y = 2x` / `y = -2x`: 速い上下移動
  - `y = x²` / `y = -x²`: 上下に加速するカーブ
  - `y = sin x`: 上下に揺れるウェーブ
- `1`〜`3`(または下のボタン)でデッキの関数を切り替え、これから描く曲線の形を変える
- 右から流れてくる敵の曲線と自分の曲線が交差すると、大爆発・得点・コンボ
- **交差角度が急なほどボーナス倍率アップ**(最大 1.8 倍)。真横から斬り込むと大きなエフェクトになる
- 敵の曲線を交差させずに画面左へ逃がすとライフ -1。ライフ 0 でゲームオーバー
- 5 コンボごとにライフが 1 回復(最大 3)
- コンボは 2.6 秒以内に次の交差を決めると継続。得点は `(100 + (コンボ-1) × 50) × 角度ボーナス`

## 難易度調整

- スクロール速度は開始 220px/s から、時間経過で最大 380px/s まで上がる
- 敵の生成間隔は約 1.5 秒から約 0.8 秒へ短くなる
- 敵の曲線は `sin` / `x²` / 直線`x/2` の 3 種類で、振幅と長さをランダムに変える
- 開始直後に 3 本の敵曲線を画面内へ置き、最初の数秒から交差チャンスがあるようにしている
- ライフの回復条件を「5コンボ」にすることで、逃げ切るより攻める方が得になる

## テスト

universe のルートで実行します。

```sh
./tools/run-tests.sh
```

個別に実行する場合:

```sh
cd graph-cross
jsc test-engine.js
jsc test-smoke.js
```

`jsc` が PATH にない場合は、macOS 標準の `/System/Library/Frameworks/JavaScriptCore.framework/Versions/A/Helpers/jsc` を使うか、`JSC` 環境変数で指定してください。

## 設計メモ

- プレイヤーの曲線は「画面座標の点列」として持つ。毎フレーム点を左へスクロールさせ、ヘッド位置に新しい点を足すので、描いた形がそのまま残って敵を迎え撃つ
- 交差判定は「曲線の点列」と「敵の曲線のサンプル点」を同じ x で比べる。どちらも y = f(x) の形なので、線分交差より単純で安定する
- 敵が画面左へ抜けたときだけミスにする。ヘッドより後ろの曲線にも当たり判定があるため、後ろに罠を張る戦略が成立する
- 関数は速度・加速度として曲線に反映する。`x²` は加速度、`sin x` は上下する速度、`x/2` は一定速度
- デッキは 3 枠に制限し、`setMode` をデッキ内の関数だけに制限する。8 種類から 3 つを選ぶことで、上下の移動力・カーブ・ウェーブのどれを取るかがプレイスタイルになる
- 交差角度は、プレイヤー曲線の接線と敵曲線の接線から `atan(|(m1-m2)/(1+m1*m2)|)` で求める。90 度に近いほど得点倍率が上がる
- テストでは、何もしないプレイが数秒〜十数秒で終わり、敵の高さに合わせて動くプレイが 40 秒生存できることを確認している

## 既知の制限

- 効果音はない
- 画面サイズを途中で変えると、曲線や敵の画面位置が少しずれることがある
- 自己ベストはブラウザの `localStorage` 保存。シークレットモードでは消える
