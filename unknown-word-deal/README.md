# 未知語de交渉

商人の短いことばを読み、**3つの品から欲しいものを推理する**スマホ向けの言語交渉ゲームです。1回3〜5分。3人の商人と交渉し、最後に契約書を読んで署名するか断るかを選びます。

## 遊び方

1. **ことばを読む** — 商人の文には、知らない語が1つだけ。まわりの語には意味が付いています。しぐさもヒントです。
2. **3つの品から選ぶ** — パン・魚・宝石のカードを1つタップします。
   - 当たり: +10硬貨
   - 外れ: +3硬貨（商人は代わりの品を受け取ります）
3. **覚えた語が残る** — 選んだ結果で、その語の意味が確定します。確定した語は品物カードに表示され、次の商人では消去法の材料になります。
4. **3人目はウソつき** — 「いらない」と言いながら、しぐさは宝石を見ているかもしれません。
5. **契約書** — 最後に短い条文を読み、署名するか断ります。
   - 署名: 条文の主語が「私」なら品を渡して-5硬貨、「あなた」なら品を受け取って+5硬貨。
   - 断る: 増減なし。読みに自信がなければ断るのも手です。

スタート画面の「はじめての人へ」から、3枚の絵で流れを確認できます。

## ルール

- 語彙はシードから生成される7語。品物3語と、既知の文法語（私・あなた・欲しい・否定）です。
- 既知の文法語は最初から意味が表示されます。品物の語だけが未知語で、3択の品物カードで推理します。
- 1人目はパン、2人目は魚、3人目は宝石が正解です。外れても進行し、正解の語は必ず学べます。
- 3人目の文には否定が入りますが、しぐさと消去法を信じるかどうかが勝負です。
- 最後の契約は、主語が「私」か「あなた」かで損得が変わります。

## 評価

最終的な硬貨がスコアです。

- S: 30硬貨以上
- A: 23硬貨以上
- B: 15硬貨以上
- C: それ未満

3人全員に当てると30硬貨。契約で+5を取れば35硬貨が最高です。自己ベストはブラウザに保存されます（`localStorage`）。

同じシードなら同じ言語です。終了画面から「同じことばで再挑戦」できるので、読み方と契約の判断を詰められます。`?seed=12345` のように URL にシードを付けることもできます。

## 設計の要点

- **1画面1判断**: 商人の文と品物カードだけを見せ、選択肢は3つの品物に絞る。自由文の組み立て、単語ノート、複数リソースは使わない。
- **既知語はインライン表示**: 文の中の文法語には意味を付け、未知語だけを残す。情報量を減らし、推理の対象を品物の語に集中させる。
- **覚えた語がカードに残る**: 1人目でパン、2人目で魚を学ぶと、3人目は残った候補を消去法で絞れる。
- **失敗しても学べる**: 外れても+3硬貨で進行し、正解の語は必ず表示される。進行不能にしない。
- **契約は2択**: 条文の主語を読んで、署名か拒否かを選ぶ。署名したときだけ±5硬貨が反映される。
- **スマホ優先**: 幅460pxの縦画面。PCでは中央に細いパネルとして表示する。タップ領域は大きめにしている。

## テスト

```sh
cd unknown-word-deal
jsc test-engine.js
jsc test-smoke.js
```

リポジトリ全体では `./tools/verify.sh` です。`test-engine.js` は3人の推理、外れ時の+3、語の学習、契約の署名/拒否、シード再挑戦を検証します。`test-smoke.js` は `window.__GAME__` を自動プレイし、S評価・全問正解・契約最適・エンド画面まで確認します。

## 既知の制限と次に試すこと

- 1ランは3人固定。商人の追加、日替わりシード、スコア共有は次版。
- 未知語は品物の名詞のみ。動詞・形容詞・語順の推理は今後の拡張。
- 音のON/OFF、文字サイズ変更、色以外の手がかりなど、アクセシビリティはまだ十分ではない。
- スマホの実機で、片手操作と画面の収まりをさらに調整したい。
