# ゲーム案の種

「スルメゲー」= 短時間で遊べて、噛むほど味が出るゲームの案を寝かせる場所です。
採用が決まったら、[アプリの追加手順](adding-an-app.md)に沿ってトップレベルへ昇格させます。

## 採用中

### 観測者

- 状態: v1 実装済み（[`observer-game/`](../projects/_labs/observer-game/)）
- 一言: 5×5の盤面で、敵の隠れた移動規則を観測して次の一手を予測する
- スルメ要素: 6つのルール候補を軌跡・灯の実験・消去法で絞る。外すとライフが減り、規則が変わる。観測にターンを使うため、どこで賭けるかの判断が要る
- 実装メモ: 6ルール、5×5、12ターン、ライフ3、灯2。盤面と初期ルールはシード固定。ルール変更もシードで再現する
- v1の範囲: 観測・予測・灯の移動、候補メモ、12ターン、S〜C評価、同じ盤面の再挑戦。約5分

### BLOOM（exponential-balls）

- 状態: v2.6 実装済み（[`exponential-balls/`](../projects/_labs/exponential-balls/)）
- 一言: ボールが倍々に増えるAUTO/FRAME、20球の最後の1球RACE、能力差と予想を楽しむ積み木レースRACE 3D
- スルメ要素: AUTOの拍に固定された分裂、FRAMEの偶発的なライン通過、RACEの20球がギミックで削られていく様子と勝者当て、12小節ごとのキー変更、モードで変わる音ハメ
- 実装メモ: AUTOは2^bar、FRAMEは上部ラインへの接触で2個に増え、下向き180度へ飛ぶ。RACEは20色の球が重力・壁・球同士・ペグ・バンパー・回転バー・ポータル・コンベア・ウェル・ブースター・奈落を抜けるノータップ・サバイバル。RACE 3Dは斜め下の積み木コースを20球が転がり、最初のゴールが勝者。球ごとに速度・反発・グリップ・サイズが異なり、レース前に勝者を予想して連勝を狙う。約20秒。横ドラッグでカメラ周回、右スライダーでコース移動。パーティクル/軌跡は出さず、積み木は銀色の固定ブロック。UIは英語のみ。WebAudioの16分スケジューラ、Canvasの分裂/ライン/2D/3Dアリーナ/軌跡/波紋、AUTO/FRAME/RACE/RACE 3Dのスモークテスト。外部音源なし

### TETHER

- 状態: v1.3 実装済み（[`tether/`](../projects/_labs/tether/)）
- 一言: アンカーにロープを引っかけて登る、押して巻き取り・離して飛ぶ1ボタンクライミング
- スルメ要素: 巻き取り続けるとアンカーを通り過ぎるため、近づいたら離す判断が要る。次のアンカーへの推力は自動なので、方向ではなくタイミングと高さを詰める。60秒でどこまで登れるか、ベスト更新を狙う
- 実装メモ: 15アンカー、回転バー3、バンパー4、風ゾーン2、重力980、巻き取り250、スナップ780。テザーは距離拘束の振り子で、最短80pxまで巻き取り、離すとロープ長に比例した推力で次に上のアンカーへ飛ぶ。ホールド中に120px以内のアンカーへ再リンクでき、使用済みも再利用可能。高さは最高地点、60秒で終了。最下部には床があり、テザーなしで落ちると anchor 0 に再リンクして再開できる。高速時の貫通を防ぐため物理更新を最大16分割。WebAudioの効果音、Canvasの塔・星・ロープ・床・バンパー・風、ベスト保存、自動プレイのスモークテスト

## 保留

### 未知語de交渉

- 状態: v4で区切り（[`unknown-word-deal/`](../projects/_labs/unknown-word-deal/)）。公開は継続
- 理由: 「品物当ての延長は運に見える」という指摘。未知語を文法語に変えても、1問1答の連続では「仮説→検証→発見」の快感が弱かった
- 再挑戦するなら: 1つの会話に複数の未知語を置き、指さし・差し出し・聞き返しで仮説を試す。答えを即開示せず、結末を分岐させる手作りパズルにする

## 種

### 効用関数を読め

- 一言: NPCとの交渉カードゲーム。相手が何を欲しがるかを履歴から推定する
- スルメ要素: 読む対象が心理ではなく合理性。同じ手札でも相手の効用関数で最適解が変わる
- 注意: 「手を読め!」と近いので、カードと数値の駆け引きを主役にする

### 毎日シードの一筆書き

- 一言: 日付シードで全員同じ盤面、最短手数を競う
- スルメ要素: スコアアタックと翌日への引き。実装は軽く、説明も短い
- 実装メモ: シード生成とソルバを純粋関数に分ける。共有用の短いコードを出す

### 配合と醸造

- 一言: 素材の組み合わせで効果が変わる発見型クラフト。レシピは教えられない
- スルメ要素: 組み合わせ爆発と「あの素材同士は効くはず」という仮説。図鑑が育つ
- 実装メモ: 効果は素材の属性合成で決め、隠しレシピを少数だけ用意する

### 一つのボタン、一つの嘘

- 一言: 1ボタンで跳ぶ/溜める/離す。見た目は反射ゲー、実は相手のフェイントを読むゲーム
- スルメ要素: 同じ操作のまま、相手の癖と自分の癖の読み合いが深くなる
- 注意: 「重力フリップ」と操作感が近い。フェイントの読み合いを主役にできるかで判断する
