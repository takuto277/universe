# ゲーム案の種

「スルメゲー」= 短時間で遊べて、噛むほど味が出るゲームの案を寝かせる場所です。
採用が決まったら、[アプリの追加手順](adding-an-app.md)に沿ってトップレベルへ昇格させます。

> 複数セッションで実装する場合は、先に `./tools/seed.sh next`（または `claim <id>`）で種を確保してください。手順は [seed の確保](seed-claims.md)。

### REBEL BREAKOUT（逃げるブロック）

- 実装メモ: 60秒、ライフ3、シールド32〜40枚、ボールは壁反射＋弱いホーミング、速度235→470、14/29/44秒に4秒のSURGE、22/42秒に追加ボール（最大3）、被弾で全ボールを上へ戻して1.3秒無敵、SWAPは2.6秒クールダウンで安全なシールドと入れ替わり消費、GRAZE +25点、S〜D評価、ベスト保存、Canvasのネオン描画とパーティクル、既知AIの自動プレイ

### DEBT（借金で強くなる）

- 状態: v1 実装済み（[`debt/`](../projects/_labs/debt/)）
- 一言: 5日間で借金を返す経済ゲーム。オファーを借りて買い、日利10〜20%と戦いながら最終日に決済する
- スルメ要素: 借りるほど金利が上がるので、増やす額と返す額のバランスが毎日変わる。ROIと回収日数、残り日数を見て、終盤の割高オファーを避ける判斷が要る。イベントとオファーの乱数で毎回違う最適解になる
- 実装メモ: 5日、借入枠700、金利10%＋借金比率×10%（最大20%）、1日4オファー（ROI約25〜65%、価格/売上にばらつき）、市場イベント7種、必要ROI（年金式）と回収日数の表示、返済は50/200/ALL、最終日に現金≥借金で残金がスコア、S〜E評価、ベスト保存、DOM UI、WebAudio、自動プレイのスモークテスト

### OOPS（間違えると時が進む）

- 状態: v1 実装済み（[`oops/`](../projects/_labs/oops/)）
- 一言: 時計は止まったまま。誤答したときだけ残り時間が10秒進む、90秒の誤答予算で18問に挑む4択クイズ
- スルメ要素: 正解では時間が減らないため、焦りの理由はスコアだけ。スキップは安全だが点にならず、勘で賭ければ時間を失う。連続正解のコンボと速答ボーナスが上を狙う動機になる
- 実装メモ: 90秒、-10秒/誤答、18問（25問プールからシード付きシャッフル）、7秒で自動スキップ、基本100点＋速答ボーナス（FLASH/FAST/OK）、コンボ最大1.4倍、クリア時は残り1秒15点、S〜E評価、ベスト保存、WebAudio、DOM UI、自動プレイのスモークテスト

### TWIN（一人二役）

- 状態: v1 実装済み（[`twin/`](../projects/_labs/twin/)）
- 一言: 1つの入力で2体を操り、片方に0.4秒の遅延をかけて上下のゲートを抜ける縦スクロール
- スルメ要素: 遅延があるから2体のx座標をずらせる。どちらを遅らせるかをSWAPで切り替え、隣り合うゲートの中心差を読む。速度と開口部が上がる3ステージ
- 実装メモ: 3ステージ、ライフ3、遅延0.4秒、ゲート間隔145、隣接中心差は最大40/44/48、開口幅88/76/66。入力は時刻付き履歴で保持し、各体が `time - lag` を読む。`swap` はlagの割り当てだけを変える。ゲート通過はyが跨いだ瞬間のxで判定。Canvasの塔・星・ゲート・パーティクル、自動プレイ（SWAPなしの貪欲法）のスモークテスト

## 保留

### 未知語de交渉

- 状態: v4で区切り（[`unknown-word-deal/`](../projects/_labs/unknown-word-deal/)）。公開は継続
- 理由: 「品物当ての延長は運に見える」という指摘。未知語を文法語に変えても、1問1答の連続では「仮説→検証→発見」の快感が弱かった
- 再挑戦するなら: 1つの会話に複数の未知語を置き、指さし・差し出し・聞き返しで仮説を試す。答えを即開示せず、結末を分岐させる手作りパズルにする

## 種

### 効用関数を読め

- 一言: NPCとの交渉カードゲーム。相手が何を欲しがるかを履歴から推定する
- スルメ要素: 読む対象が心理ではなく合理性。同じ手札でも相手の効用関数で最適解が変わる
- 注意: 「手を読め!」と近いので、カードと数値の駆け引きを主役にする

### 毎日シードの一筆書き

- 一言: 日付シードで全員同じ盤面、最短手数を競う
- スルメ要素: スコアアタックと翌日への引き。実装は軽く、説明も短い
- 実装メモ: シード生成とソルバを純粋関数に分ける。共有用の短いコードを出す

### 配合と醸造

- 一言: 素材の組み合わせで効果が変わる発見型クラフト。レシピは教えられない
- スルメ要素: 組み合わせ爆発と「あの素材同士は効くはず」という仮説。図鑑が育つ
- 実装メモ: 効果は素材の属性合成で決め、隠しレシピを少数だけ用意する

### 一つのボタン、一つの嘘

- 一言: 1ボタンで跳ぶ/溜める/離す。見た目は反射ゲー、実は相手のフェイントを読むゲーム
- スルメ要素: 同じ操作のまま、相手の癖と自分の癖の読み合いが深くなる
- 注意: 「重力フリップ」と操作感が近い。フェイントの読み合いを主役にできるかで判断する

### 上位10の遊び

1. **間違えると時が進む / OOPS** — 90秒。4択に正解すると残り時間が止まり、誤答すると10秒減る。分からない問題を飛ばすか、勘で賭けるかの判断が全て。
2. **弾は敵のもの / AMMO SHARE** — 60秒。自分が撃った弾が次のウェーブで敵の弾になる。今を凌ぐほど未来が濃くなる。被弾1で終了。
3. **借金で強くなる / DEBT** — 5ラウンド。強化を借金で買い、日利10〜20%で返す。期限に間に合わなければ即終了。残金がスコア。
4. **一人二役 / TWIN** — 3面。1つのスティックで2体を動かし、片方の行動が0.4秒遅れて他方に効く。主従を切り替えながら両方を生かす。
5. **教えてロボ / TUTOR** — 3回のデモで動きを教え、10回の本番をAIが走る。何を見せ、どこを一般化させるかが設計になる。
6. **地図は自分で描く / MAPLESS** — 3フロア。円形の視界だけを頼りに、通った道を有限インクで描き足す。描くほど地図が濁る。
7. **重心トラック / CARGO** — 3コース。箱を積み、傾斜と段差で崩れない重心を探す。速さより荷降ろし順。
8. **一行直すと世界が変わる / EDIT** — 5問。短い文の一語を置換すると地形・敵・天候が変わる。最小手数の別解を探す。
9. **ルールの穴 / BUG HUNTER** — 5面。各面のルールには必ず1つバグがあり、見つけて使うと突破できる。次面では修正済み。
10. **音を選んで聴く / MUTE** — 10問。足音・機械・雨・声・時計の5chをミュート/ソロして、必要な音だけで状況を当てる。字幕なし。

### 既存との差分メモ

- OOPS は「選択肢クイズ / OVERLOAD」と逆で、時間は失敗でしか減らない
- AMMO SHARE は BIN BANG の「撃ち得」を反転し、弾を敵への預金にする
- DEBT は既存にない経済単体。資源を増やすのではなく前借りする
- TWIN は自己プログラミング案と違い、コードではなく遅延した2体の同時操作
- TUTOR は直接操作ではなく教育。上手さが「何を教えるか」に出る
- MAPLESS は記憶系（MEMORY CLIMB / SHIFT ROOM）と違い、記憶を画面に外注できる
- CARGO はネオンスタック等の「積む」ではなく、積んだ後の運搬と重心が主役
- EDIT はしりとり・交渉・クイズと違い、編集そのものが操作
- BUG HUNTER はルールを守るのではなく、ルールの欠陥を突く
- MUTE は音を届ける「音の家」と逆で、音を選別して聴く
