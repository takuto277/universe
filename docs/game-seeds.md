# ゲーム案の種

「スルメゲー」= 短時間で遊べて、噛むほど味が出るゲームの案を寝かせる場所です。
採用が決まったら、[アプリの追加手順](adding-an-app.md)に沿ってトップレベルへ昇格させます。

## 採用中

### 未知語de交渉

- 状態: v3（スマホ版）実装済み（[`unknown-word-deal/`](../unknown-word-deal/)）
- 一言: 商人の短い文を読み、3つの品から未知語の意味を推理して損得を賭ける
- スルメ要素: 品物の語をしぐさ・既知語・消去法で絞る。最後に契約の主語を読む。同じシードでスコアを詰める
- 実装メモ: 言語生成と3択・硬貨・契約を純粋な状態機械にし、`test-engine.js` で検証する。チュートリアルはUIの3枚画像
- v3の範囲: 3商談 + 契約1条、語彙7語（品物3 + 文法4）、1画面1判断の3択、+10/+3硬貨、覚えた語のカード表示、3人目の否定のウソ、契約の署名/拒否、3〜5分。モード選択・自由文・11語ノート・信頼/質問券は削除

## 種

### 効用関数を読め

- 一言: NPCとの交渉カードゲーム。相手が何を欲しがるかを履歴から推定する
- スルメ要素: 読む対象が心理ではなく合理性。同じ手札でも相手の効用関数で最適解が変わる
- 注意: 「手を読め!」と近いので、カードと数値の駆け引きを主役にする

### 観測者

- 一言: 敵の行動規則を観察して次の手を予測するオートマトン当て
- スルメ要素: 外れるほど情報が増える。予測的中でゲージが伸び、外すとルールが1つ書き換わる
- 実装メモ: 規則の集合を小さく持ち、観測ログから推定させる。UIは表とタイムラインだけでも成立する

### 毎日シードの一筆書き

- 一言: 日付シードで全員同じ盤面、最短手数を競う
- スルメ要素: スコアアタックと翌日への引き。実装は軽く、説明も短い
- 実装メモ: シード生成とソルバを純粋関数に分ける。共有用の短いコードを出す

### 配合と醸造

- 一言: 素材の組み合わせで効果が変わる発見型クラフト。レシピは教えられない
- スルメ要素: 組み合わせ爆発と「あの素材同士は効くはず」という仮説。図鑑が育つ
- 実装メモ: 効果は素材の属性合成で決め、隠しレシピを少数だけ用意する

### 一つのボタン、一つの嘘

- 一言: 1ボタンで跳ぶ/溜める/離す。見た目は反射ゲー、実は相手のフェイントを読むゲーム
- スルメ要素: 同じ操作のまま、相手の癖と自分の癖の読み合いが深くなる
- 注意: 「重力フリップ」と操作感が近い。フェイントの読み合いを主役にできるかで判断する
