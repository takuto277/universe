# ゲーム案の種

「スルメゲー」= 短時間で遊べて、噛むほど味が出るゲームの案を寝かせる場所です。
採用が決まったら、[アプリの追加手順](adding-an-app.md)に沿ってトップレベルへ昇格させます。

## 採用中

### 観測者

- 状態: v1 実装済み（[`observer-game/`](../projects/_labs/observer-game/)）
- 一言: 5×5の盤面で、敵の隠れた移動規則を観測して次の一手を予測する
- スルメ要素: 6つのルール候補を軌跡・灯の実験・消去法で絞る。外すとライフが減り、規則が変わる。観測にターンを使うため、どこで賭けるかの判断が要る
- 実装メモ: 6ルール、5×5、12ターン、ライフ3、灯2。盤面と初期ルールはシード固定。ルール変更もシードで再現する
- v1の範囲: 観測・予測・灯の移動、候補メモ、12ターン、S〜C評価、同じ盤面の再挑戦。約5分

### BLOOM（exponential-balls）

- 状態: v2 実装済み（[`exponential-balls/`](../exponential-balls/)）
- 一言: ボールが1→2,048と倍々に増える縦画面のオーディオビジュアル体験。AUTOとFRAMEの2モード
- スルメ要素: AUTOの拍に固定された分裂、FRAMEの偶発的なライン通過、12小節ごとのキー変更、モードで変わる音ハメ、タップで押し返す干渉
- 実装メモ: AUTOは2^bar、FRAMEは上部ラインへの接触で2個に増え、ラインと逆の下向き180度へ飛ぶ。子ボールは倍になるたびに色が濃くなる。ボールは常に360度のどれかへ移動。ライン通過音は16分に量子化。UIは英語のみ。タップで押し返せる。WebAudioの16分スケジューラ、Canvasの分裂/ライン/軌跡/波紋、AUTOとFRAMEのスモークテスト。外部音源なし

## 保留

### 未知語de交渉

- 状態: v4で区切り（[`unknown-word-deal/`](../projects/_labs/unknown-word-deal/)）。公開は継続
- 理由: 「品物当ての延長は運に見える」という指摘。未知語を文法語に変えても、1問1答の連続では「仮説→検証→発見」の快感が弱かった
- 再挑戦するなら: 1つの会話に複数の未知語を置き、指さし・差し出し・聞き返しで仮説を試す。答えを即開示せず、結末を分岐させる手作りパズルにする

## 種

### 効用関数を読め

- 一言: NPCとの交渉カードゲーム。相手が何を欲しがるかを履歴から推定する
- スルメ要素: 読む対象が心理ではなく合理性。同じ手札でも相手の効用関数で最適解が変わる
- 注意: 「手を読め!」と近いので、カードと数値の駆け引きを主役にする

### 毎日シードの一筆書き

- 一言: 日付シードで全員同じ盤面、最短手数を競う
- スルメ要素: スコアアタックと翌日への引き。実装は軽く、説明も短い
- 実装メモ: シード生成とソルバを純粋関数に分ける。共有用の短いコードを出す

### 配合と醸造

- 一言: 素材の組み合わせで効果が変わる発見型クラフト。レシピは教えられない
- スルメ要素: 組み合わせ爆発と「あの素材同士は効くはず」という仮説。図鑑が育つ
- 実装メモ: 効果は素材の属性合成で決め、隠しレシピを少数だけ用意する

### 一つのボタン、一つの嘘

- 一言: 1ボタンで跳ぶ/溜める/離す。見た目は反射ゲー、実は相手のフェイントを読むゲーム
- スルメ要素: 同じ操作のまま、相手の癖と自分の癖の読み合いが深くなる
- 注意: 「重力フリップ」と操作感が近い。フェイントの読み合いを主役にできるかで判断する

## 選び方

| 案 | スルメ度 | 実装コスト | 既存との被り |
| --- | --- | --- | --- |
| 未知語de交渉（保留） | 高 | 中 | 低 |
| 効用関数を読め | 中 | 中 | 中 |
| 観測者（採用中） | 高 | 低〜中 | 中 |
| 毎日シードの一筆書き | 中 | 低 | 低 |
| 配合と醸造 | 高 | 中 | 低 |
| 一つのボタン、一つの嘘 | 中 | 低 | 高 |

判断の理由は、採用時に `docs/decisions/` へ残します。
