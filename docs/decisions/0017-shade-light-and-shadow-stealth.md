# 0017 SHADE を「光と影のターン制ステルス」として実装する

- Status: Accepted
- Date: 2026-11-25

## Context

ゲーム案「影渡り / SHADE」は、ステルスゲームの前提を1つ壊す案です。通常は「暗がりに隠れて光を避ける」ものですが、この案ではプレイヤー自身が光源を動かし、壁の影を伸ばして安全な道を作ります。

光源を自由に動かせるようにすると操作が重くなり、逆に固定するとただの迷路になります。また、見張りの視界と光源の明るさを別々に持つと、「なぜ今見つかったのか」が読みにくくなります。短いターン制パズルとして、判断の理由が毎手見える必要がありました。

## Decision

プレイヤーの光源操作と見張りの視界を、同じ光源に結びつけます。

- 盤面は13×9のグリッド。1手につき「1マス移動」か「光源を次のソケットへ切替」のどちらか
- 光源から各マスへレイを飛ばし、壁を横切るマスを影にする。明るさは光源の位置だけで決まる
- 見張りは90度のコーンと射程を持ち、「光が当たっているマス」かつ視線が通るマスだけを見る
- 赤い視界に入った状態で手番を終えると見つかり、残影を1つ失ってステージをやり直す
- 出口は「開始ソケットでは見張りに露出し、壁の影になる別ソケットへ切り替えると安全」になるよう生成する。これで光源切替が必ず必要になる
- 10ターン以内に出口へ到達すればクリア。5部屋を抜ければ ESCAPED、残影は3つ
- 生成した各面はBFSソルバで解けることを確認してから採用する。手詰まりはUNDOで戻せる

## Consequences

良い面:

- 「光を動かす」という1つの操作が、危険の発生源と安全な道の生成を同時に担う
- 出口が赤く露出しているかどうかで、光源を切り替える理由が常に画面に出る
- ソルバで解ける面だけを出すため、生成に依存しても理不尽な面になりにくい
- ターン制なので、キーボード・パッド・タップのどれでも同じ判断を共有できる

トレードオフ:

- 見張りが静的で巡回しないため、レベルによっては光源切替のタイミング要素が薄い
- ソルバは最短解を返すだけで、プレイヤー向けのヒントや「別解の面白さ」は評価していない
- 盤面生成とソルバをクライアントで行うため、起動時にわずかな計算コストがある

## Follow-up

- 見張りの巡回や回転を入れる場合は、次の手番の視界をプレビュー表示して理不尽さを避ける
- 手作りの固定面やデイリーシードを追加し、生成面との手触りを比較する
- ソルバの解をヒントとして段階表示する
