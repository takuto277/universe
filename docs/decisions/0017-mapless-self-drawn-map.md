# 0017 MAPLESS を「手描き地図と泥」で設計する

- Status: Accepted
- Date: 2026-11-26

## Context

ゲーム案「地図は自分で描く / MAPLESS」は、迷路の前提を1つ壊す案です。普通の迷路ゲームはマップが与えられますが、この案では**見えない迷路を有限インクの手描き線だけで進みます**。

素直に実装すると、自動ミニマップや探索済みの可視化を入れたくなります。しかし、それを入れると「自分で描く」という核が消えます。一方で、完全に何も残さないと迷路が広すぎて、記憶だけでは遊びになりません。視界・インク・濁りのバランスを決める必要がありました。

## Decision

次の方針で実装します。

- **自動マップは作らない**。プレイヤーがキャンバスに描いた線だけが外部記憶になる。
- 迷路は13×9 / 15×11 / 17×13の完全迷路。出口はスタートからBFSで最も遠い袋小路。
- 視界は円形で3.3 / 3.0 / 2.8マス。灯りの外はほぼ見えない。
- インクは100 / 110 / 120。描いた距離に比例して減る。瓶（各階2 / 2 / 3）で32回復。
- 同じ場所に重ねて描くと「泥」が増え、紙に茶色い滲みが広がる。CLARITYが下がり、スコアにも泥×4のペナルティ。
- 出口の方向は教えない。BFS距離が近いときだけ、灯りの脈とHUDの5ピップで「近さ」を伝える。
- スコアは 基本1000 + タイムボーナス最大600 + 残インク×3 + 瓶×300 - 泥×4。3階合計でS〜D。
- 自動プレイは出口へのBFS経路を辿り、通った道をインクで描く。3階完走のスモークテストに使う。

## Consequences

良い面:

- 「描く」「残す」「捨てる」が毎フロアの判斷になり、他の迷路ゲームと体験がはっきり違う
- 泥とインクの2資源が、描きすぎ・描かなさの両方を罰する
- 出口の気配は方向ではなく近さだけなので、最後は自分の地図を信じるしかない
- シード固定で迷路・出口・瓶が再現でき、テストとリプレイが安定する

トレードオフ:

- マップの自動化・消しゴム・フロア間の持ち越しはない。描きすぎたときの救済はフロアやり直しのみ
- 完全迷路なのでループがなく、袋小路の探索が主体になる
- 携帯ではキャンバスが小さく、指で描く精度はPCより落ちる（D-padとPEN切替で補助）
- スコアはローカルの自己ベストのみ

## Follow-up

- フロアごとのギミック（動く壁、インクを吸う床など）を足す場合は、手描き地図の価値を下げない範囲で検討する
- 消しゴムを入れるなら、インクを返さず泥だけ増やすなどのコスト設計が必要
- モバイルの描画精度をプレイテストで確認する
