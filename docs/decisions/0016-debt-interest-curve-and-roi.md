# 0016 DEBT を「金利カーブと必要ROI」で設計する

- Status: Accepted
- Date: 2026-11-25

## Context

ゲーム案「借金で強くなる / DEBT」は、資源を増やすのではなく前借りして育てる経済ゲームです。5ラウンドで借金を返し、残金を競います。素直に実装すると、資産のROIが金利を上回る限り全力で借りるのが最適になり、判斷が消えます。一方で、金利が高すぎると借りた瞬間に破綻し、遊びになりません。

## Decision

次の3点で、借りる量と返す量の間に意味のある幅を作ります。

1. **金利を借金比率に連動させる**
   - 金利 = 10% + 10% ×（借金 / 借入枠）。借入枠は700。
   - 全力で借りるほど利ざやが薄くなり、適度なレバレッジに最適点が生まれる。
2. **必要ROIを畫面に出す**
   - 残り日数と金利から、借金を償却するのに必要なROIを年金式で計算する。
   - 終盤のオファーが割高になる理由を数字で示し、「買わない」判斷を正当化する。
3. **回収日数で直感を補助する**
   - `ceil(価格 / 当日の実効売上)` を表示し、残り日数と比較できるようにする。

オファーは1日4件、ROIは約25〜65%、価格と売上にばらつきを持たせます。市場イベント（FOOD/STREET/TECHの倍率）で当日の実効売上が変わるため、同じオファーでも買うべき日が変わります。資産の売却は実装せず、終盤は「返済」に寄せる設計です。

## Consequences

良い面:

- 借りる量・買うオファー・返すタイミングの3つが毎日絡み、単純な全力投資にならない
- 必要ROIと回収日数で、上級者は計算でき、初心者は赤い警告で直感できる
- シード固定のオファー/イベントで、テストと再現ができる
- 自動プレイは必要ROIと借入枠を見て買い、最終日に返済して完走する

トレードオフ:

- 序盤に買えないと巻き返しが難しい（借入枠とオファー運の影響が大きい）
- 資産の売却がないため、終盤のオファーは基本的に「買わない」が正解になる
- 金利・日数・枠のバランスは固定で、難易度設定は未実装

## Follow-up

- 資産の売却や「借り換え」を入れる場合は、返済判斷の価値を上げる方向で検討する
- イベントの偏りと、初心者がデフォルトしやすい局面をプレイテストで確認する
