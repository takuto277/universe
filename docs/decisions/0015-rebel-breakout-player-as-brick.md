# 0015 REBEL BREAKOUT を「ブロック側」から遊ぶ逆転として実装する

- Status: Accepted
- Date: 2026-11-25

## Context

ゲーム案「逃げるブロック / REBEL BREAKOUT」は、ブロック崩しの前提を1つ壊す案です。通常はパドルを動かしてボールでブロックを消しますが、この案ではプレイヤーがブロック側に立ち、AIのボールから逃げます。

そのまま「動くブロックが弾を避ける」だけにすると、ただの回避アクションになり、ブロック崩しらしさが残りません。また、ボールが一度も自分へ来ないと緊張が生まれず、逆に完全に追尾すると避けられないゲームになります。

## Decision

プレイヤーを「壊される側の1ブロック」として実装し、ボールとシールドの関係を資源にします。

- 60秒間、ライフ3でボールをかわす。時間経過でボールは235→470px/sへ加速する
- ボールは壁で反射し、すでに自分へ向かっているときだけ弱く進路を補正する（過剰な追尾はしない）
- シールドはボールが当たると消える。減るほど終盤に隠れ場所がなくなる
- `SWAP` は2.6秒クールダウンで、最も安全なシールドと位置を入れ替えて消費する。シールドを逃げ道にするか、隠れ場所として残すかの判斷が生まれる
- 22秒と42秒にボールを追加し、最大3個にする。14/29/44秒には4秒間のSURGEで加速する
- 被弾時は全ボールを上へ戻し1.3秒の無敵を置く。連続被弾で理不尽に終わらせない
- ぎりぎりをかわすとGRAZE +25点。60秒生存はCLEARで、残ライフに応じたS〜B評価

## Consequences

良い面:

- 「ブロックを壊す」ではなく「ブロックとして生き残る」という逆転が、操作とスコアの両方に出る
- シールドが隠れ場所と移動資源を兼ねるため、同じ回避でも使うほど終盤が難しくなる
- 速度上昇・SURGE・追加ボールで、60秒の間に難易度の山を作れる
- 乱数シードを固定すれば、テストで同じ初期配置と速度を再現できる

トレードオフ:

- シールドが多い序盤はボールが上で跳ね、プレイヤーが暇になりやすい
- SWAPの安全判定が強いため、シールドが残っている間は緊急回避に頼れる
- シールド配置はシード乱数で穴が変わるが、ステージ構成は固定

## Follow-up

- 序盤の緊張を作るため、低い位置のシールドや定期的な奇襲を検討する
- SWAPのクールダウンとシールド枚数で難易度を調整する
- 自動プレイは最寄りボールから離れる貪欲法なので、GRAZEを狙う評価関数は未実装
