# 0014 OOPS の時計を「誤答予算」として実装する

- Status: Accepted
- Date: 2026-11-24

## Context

ゲーム案「間違えると時が進む / OOPS」は、早押しクイズの前提を1つ壊す案です。素直に作ると、制限時間が常に減る普通の4択クイズになります。一方で、案の核は「時計は止まっていて、失敗したときだけ進む」という逆転にあります。

制限時間を常に減らすと、スキップと誤答の差は「減る量」だけになり、スキップが常に安全な正解になります。逆に時計を完全に止めると、時間の圧力が消えてダレます。この2つを両立させる必要がありました。

## Decision

時間を「ミスの予算」として実装します。

- 開始時は90秒。**時間は通常止まっている**
- 正解しても時間は減らない。スコアとコンボだけが増える
- 誤答すると残り時間が10秒進む。9回で0になりゲームオーバー
- スキップは時間を減らさないが、得点もコンボもない
- 速さは時間ではなくスコアで評価する（FLASH / FAST / OKの速答ボーナス）
- 出題は25問プールから18問。全問回答でクリア、残り時間はタイムボーナスに変換する

これにより、迷ったときの選択は「安全なスキップ」か「時間を賭けた回答」になり、時計は失敗の重みだけを表します。

## Consequences

良い面:

- タイトルの「間違えると時が進む」が操作と表示の両方で一致する
- スキップに意味が生まれ、1問ごとに賭けの判斷が入る
- 速答ボーナスでテンポを保ちつつ、時計の比喩を壊さない
- 出題がシード固定なので、テストで同じ問題順を再現できる

トレードオフ:

- 時間切れが「操作の失敗」に限定されるため、何もしない時間は罰にならない
- 問題の正誤がそのまま難易度になる。問題プールの品質管理が必要
- 90秒・10秒・18問のバランスは固定で、難易度調整は未実装

## Follow-up

- 問題プールの拡充とカテゴリの偏り確認
- 連敗時の救済（スキップ回数制限や時間回復）を検討する場合は、時間＝ミス予算の原則を崩さない範囲で行う
