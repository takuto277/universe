# 0013: ボクセルサンドボックスにThree.jsをvendored

## 背景
`block-craft` は、一人称視点でボクセルを掘って積むサンドボックスゲーム。大量のブロック描画と三人称/一人称カメラ、ライティングが必要になる。

## 決定
Three.js 0.160.0のminified buildを `projects/_labs/block-craft/vendor/three.min.js` にvendoredし、実行時に外部CDNへ依存しない。MITライセンスを同梱する。

## 理由
- ボクセル地形をInstancedMeshで効率よく描画できる
- 一人称カメラ、レイキャスト、ライティングをゲームロジックから分離できる
- GitHub Pagesの静的配信を維持し、実行時ネットワーク依存を増やさない
- 既存の3Dアプリと同じThree.jsバージョンを使い、保守をそろえる

## 影響
- アプリ容量が約650KB増える
- WebGL非対応環境では3D描画が無効になる
- ブロックは画像テクスチャではなく、ジオメトリと頂点色で表現する
