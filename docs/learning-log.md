# 学習ログ

アプリを作りながら学んだことを、後から読み返せる形で残します。完璧な文章より、次に同じ問題に当たったときに思い出せることを優先します。


## 2026-10-21 graph-cross

- やったこと: x が自動で進むグラフ上で、関数を切り替えながら自分の曲線を描き、敵の曲線と交差させて爆発させる「グラフクロス」を追加した。プレイヤーの曲線は画面座標の点列として保持し、スクロールさせながら新しい点を足すことで、描いた形がそのまま罠として残る。8種類の関数から3つを選ぶデッキ、x^p (p=2〜4) / 波(sin/cos/三角/角丸/減衰)のスライダー調整とリアルタイム軌道プレビュー、交差角度ボーナス、敵と同じ系統で交差する弱点ボーナス、ボスとステージクリア、クリア後の関数強制入れ替えと3択アップグレード、連続交差MULTIとアイテムで追加される非対称グラフ、上昇/下降/その他のジャンルを保つデッキ入れ替え、ライフ無限のストレス解消モード(最大ライフ/判定/コンボ/スコア/ボス弱体化/4枠目)、コンボで層が増えるBGM、スマホの画面タップ操作も入れた。
- 学んだこと: 曲線同士の交差は、両方を y = f(x) のサンプル点列として同じ x で比べると、線分交差の総当たりより単純で安定する。関数を「速度・加速度」に翻訳すると、y=x² や sin x の形をそのまま操作に使える。接線の角度から得点倍率を出すと、同じ当たりでも「どう当てたか」がスコアに出る。曲線の点に描いた時のモードを残すと、後から色分けも弱点判定もできる。
- 詰まったこと: 何もしないプレイでもウェーブが自動で当たってしまい、ゲームが勝手に進む感じになった。`y=0` のキープモードを追加し、初期モードを固定にしたことで、操作しないとすぐミスするようになった。
- 次に試すこと: 敵曲線のパターン追加(連続サイン・閉曲線)、ボスの攻撃パターン、リプレイ共有。

## 2026-10-21 gravity-flip

- やったこと: タップだけで遊べる1ボタン2Dアクション「重力フリップ」を追加した。重力反転で床と天井を行き来し、トゲを避けながら距離とコインを稼ぐ。速度・トゲ間隔・導入パターンをエンジン側で数値管理し、Canvas 2D でネオン調の描画とパーティクルを付けた。
- 学んだこと: CPU の読み合いではなく、速度と障害物間隔を距離の関数にすると難易度をシミュレーションで検証しやすい。自動プレイbotが60秒生存し、放置すると数秒で終わることをテストにすると、理不尽さと簡単すぎる状態の両方を同時に防げる。
- 詰まったこと: 画面幅が広いとトゲが右端から届くまで時間がかかり、開始直後が退屈になった。導入用のトゲとコインを最初から置き、自然生成の開始距離を導入パターンの右端から逆算して調整した。
- 次に試すこと: 効果音、パターンのバリエーション(動くトゲ・連続反転)、スマートフォンでの操作感の確認。

## 2026-10-20 janken-game

- やったこと: 心理戦じゃんけん「手を読め!」を追加した。生 WebGL のミニ 3D で手を描き、連勝ボーナス・見切りゲージ・先読み必殺と、プレイヤーの出しグセ(直前の手→次の手)を学習する CPU を組み合わせた。
- 学んだこと: レンダラを独立させ、WebGL が使えない環境では `create()` が null を返して描画だけスキップする設計にすると、スモークテストのスタブ環境でもゲーム進行をそのまま検証できる。読みの学習を遷移表の確率として持つと、固定乱数と組み合わせて挙動を数値で検証しやすい。
- 詰まったこと: テストで読み判定の乱数消費数を読み違えて失敗した(遷移データがないラウンドは読み判定の乱数を消費しない)。乱数消費は分岐の短絡まで含めてテストを書く必要がある。
- 次に試すこと: CPU クセの追加、演出(カメラワーク・パーティクル)の強化、対戦履歴の保存。

## 2026-10-19 baseball-game

- やったこと: 守備中の自分の投球傾向と、CPU に読まれている度合いを表示した。タイミングバーに単打・二塁打・ホームランの目安を追加した。
- 学んだこと: 読み精度の計算を `readAccuracy` として副作用なしで切り出すと、CPU の判断と表示で同じ値を使え、テストもしやすい。UI の表示は、ゲームの状態から毎回組み立てる方が状態の二重管理を避けられる。
- 詰まったこと: 投球履歴の更新と読み精度の計算が同じ関数に混ざっていた。計算だけを先に切り出すことで、表示用の値と実際の判断がずれないようにした。
- 次に試すこと: スマートフォンでの操作確認、キーボード操作の抜け漏れ確認、試合結果の保存。
