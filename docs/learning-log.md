# 学習ログ

アプリを作りながら学んだことを、後から読み返せる形で残します。完璧な文章より、次に同じ問題に当たったときに思い出せることを優先します。

## 書き方

```markdown
## YYYY-MM-DD アプリ名

- やったこと:
- 学んだこと:
- 詰まったこと:
- 次に試すこと:
```

## 2026-10-19 baseball-game

- やったこと: 守備中の自分の投球傾向と、CPU に読まれている度合いを表示した。タイミングバーに単打・二塁打・ホームランの目安を追加した。
- 学んだこと: 読み精度の計算を `readAccuracy` として副作用なしで切り出すと、CPU の判断と表示で同じ値を使え、テストもしやすい。UI の表示は、ゲームの状態から毎回組み立てる方が状態の二重管理を避けられる。
- 詰まったこと: 投球履歴の更新と読み精度の計算が同じ関数に混ざっていた。計算だけを先に切り出すことで、表示用の値と実際の判断がずれないようにした。
- 次に試すこと: スマートフォンでの操作確認、キーボード操作の抜け漏れ確認、試合結果の保存。
