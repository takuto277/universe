# 9球種を読め!

3回勝負の野球ゲームです。9球種の駆け引き、カウント制、配球のクセ読み、タイミングバーによる長打判定を組み合わせています。依存ゼロの静的ファイルで動きます。

## 遊ぶ

universe のルートで次を実行し、http://localhost:8000/baseball-game/ を開きます。

```sh
python3 -m http.server 8000
```

## ルール

- 3ストライクでチェンジ、4ボールで四球
- CPU ピッチャーの持ち球は5球種。配球メモと得意/苦手バッジからクセを読む
- 攻撃: 球種を予想し、ゾーン球ならタイミングバーを Space かタップで止める
- 予想を外しても、ゾーン率50%以下の明らかなボール球ならボール。際どいボール球やゾーン球で外すと空振り
- 守備: 自分の投球のゾーン率/ボール率を見て球種を選ぶ。同じ球の連投は読まれる
- 全3回、得点の多いチームの勝ち

## 構成

| ファイル | 役割 |
| --- | --- |
| `engine.js` | 試合の状態遷移、判定、CPU の意思決定。描画に依存しない |
| `game.js` | 画面描画、入力、効果音、Canvas アニメーション |
| `index.html` | 画面の骨格とルール説明 |
| `style.css` | レイアウトと見た目 |
| `test-engine.js` | エンジンの仕様テストとバランスシミュレーション |
| `test-smoke.js` | 1試合を自動プレイするスモークテスト |

## テスト

universe のルートで実行します。

```sh
./tools/run-tests.sh
```

個別に実行する場合:

```sh
cd baseball-game
jsc test-engine.js
jsc test-smoke.js
```

`jsc` が PATH にない場合は、macOS 標準の `/System/Library/Frameworks/JavaScriptCore.framework/Versions/A/Helpers/jsc` を使うか、`JSC` 環境変数で指定してください。

## 設計メモ

- ゲームの判断と状態は `engine.js` に寄せ、`game.js` は表示と入力に徹する
- 乱数は引数で差し替えられるようにし、テストでは固定する
- スモークテストは `tools/harness.js` で DOM / Canvas / タイマーをスタブ化し、仮想時間で試合を完走させる
- バランスは大量シミュレーションの結果を見て調整する。特定の1試合の結果だけに合わせない
- 広い画面では配球メモ/守備パネルをフィールド右のレールに置き、パネルが伸びてもフィールドの大きさが変わらないようにする
- Canvas のサイズは `ResizeObserver` でステージに追従させ、CSS の `max-height` だけで潰れないようにする

## 既知の制限

- 保存機能はないため、リロードすると試合は消える
- サウンドはブラウザの自動再生制限により、最初の操作後に有効になる
- 画面サイズによっては一部の情報が折り返される
